专业级正五行择日软件 · 手机版（v2.2.1）安装说明
================================================================

一、适用设备
  · 安卓手机 / 平板（Android 7.0 及以上）；不支持 iPhone / iPad。

二、安装步骤（约 3 分钟）
  1. 在手机应用商店或官网安装 Pydroid 3（Python 3 集成环境，免费）。
  2. 把本压缩包解压到手机存储，例如：
         /storage/emulated/0/择日大师/
     解压后应能看到 run.py、启动择日软件.py、主程序.py、modules 文件夹、docs 文件夹。
  3. 打开 Pydroid 3 → 左上角菜单「Open」→ 选择刚解压的 run.py。
  4. 首次运行若提示缺少 sxtwl：
        点左下角「Terminal」→ 输入  pip install sxtwl  → 回车等待安装完成。
  5. 回到编辑器，点右下角 ▶ 运行，即可进入主界面。

  注意：不要在文件管理器里直接点击 .py 文件打开，必须经 Pydroid 3 的 Open 加载。

三、常见问题
  · 界面空白 / 闪退：确认 Pydroid 3 已授予「存储」权限；确认 run.py 与 modules 在同一目录。
  · 提示 No module named 'xxx'：在 Pydroid 3 的 Terminal 里  pip install xxx 后重跑。
  · 中文显示为方块：系统设置 → 显示 → 字体，选择任一含中文的字体（如思源黑体）。
  · 屏幕太小：把手机横屏使用；平板体验更好。
  · 保存的事主方案与择日记录：保存在程序目录下的 data 与 择日记录.json，卸载前请自行备份。

四、随包文档
  · docs/择日大师_完整说明书_v2.2.1.pdf           （150 页，五篇合一的完整版，推荐）
  · docs/择日大师_完整说明书_v2.2.1.docx          （Word 版，可在 WPS 里搜索/批注）
  · docs/择日大师_用户操作手册_v2.2.1.pdf         （17 页，面向使用者）
  · docs/择日大师_算法与典据白皮书_v2.2.1.pdf     （131 页，面向资深择日师与维护者）
  手机可用 WPS / 系统 PDF 阅读器直接打开；Word 版需 WPS 或 Office。

五、版本
  · 程序版本：v2.2.1（与桌面版同一套算法与神煞规则）
  · 内核依赖：Python 3 + tkinter（Pydroid 3 自带）+ sxtwl（需联网安装一次）
