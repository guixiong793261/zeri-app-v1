                    手机一键部署包 - 使用说明

这个部署包已经将所有模块文件整合在一起，不需要 modules 子目录！

一、目录结构

手机存储/
└── 默认目录/
    └── 手机一键部署/          ← 整个文件夹复制到手机
        ├── 择日软件_完整单文件版_小窗口_优化版.py  ← 运行这个！
        ├── 四柱计算器.py
        ├── 评分器.py
        ├── 黄道.py
        ├── 喜用神计算器.py
        ├── 二十四山.py
        ├── 电子罗盘.py
        ├── 日课评分系统.py
        └── ... (其他模块文件)
        └── data/
            └── shensha.json

================================================================================
二、部署步骤

方法 1：直接复制整个文件夹（推荐）
----------------------------------------
1. 将"手机一键部署"整个文件夹复制到手机
2. 放在 Python 编辑器的默认目录下
3. 完成！

方法 2：只复制文件
----------------------------------------
1. 在手机上创建文件夹：默认目录/手机一键部署
2. 将所有 .py 文件复制到该文件夹
3. 创建 data 子文件夹，复制 shensha.json
4. 完成！

================================================================================
三、运行程序

1. 打开 Python 编辑器
2. 进入：默认目录/手机一键部署
3. 打开：择日软件_完整单文件版_小窗口_优化版.py
4. 点击运行

================================================================================

运行后应该看到：
✓ 界面正常显示
✓ 四柱计算成功（不显示"计算失败"）

================================================================================
六、与原版的区别

原版（电脑用）：
- 需要 modules 子目录
- 导入方式：from modules.四柱计算器 import ...

优化版（手机用）：
- 所有文件在同一目录
- 导入方式：from 四柱计算器 import ...
- 自动检测路径
- 兼容手机和电脑

================================================================================
七、常见问题

Q: 为什么创建了两个版本？
A: 原版保持电脑兼容性，优化版专门优化手机部署。

Q: 可以只保留优化版吗？
A: 可以！删除原版文件即可。

Q: 还需要 modules 文件夹吗？
A: 不需要！所有模块文件都已经复制到主目录了。

Q: 如果还是提示导入失败怎么办？
A: 请检查：
   1. 所有 .py 文件是否都在同一目录
   2. data/shensha.json 是否存在
   3. 文件名是否正确（包括中文字符）
