# 手机部署指南

## 目标
让 `择日软件_完整单文件版_小窗口.py` 在手机上完全正常运行，包括评分系统。

## 手机目录结构

在手机上创建以下目录结构（以 Python 编辑器为例）：

```

│   ├── 择日记录.json                       ← 历史记录（可选）
│   └── modules/                            ← **必须创建此文件夹**
│       ├── 四柱计算器.py                   ← 核心模块
│       ├── 评分器.py                       ← 评分核心

│       ├── 二十四山.py                     ← 二十四山理论
│       ├── 电子罗盘.py                     ← 电子罗盘功能
│       ├── 日课评分系统.py                 ← 评分系统界面
│       ├── 八字排盘.py                     ← 八字排盘
│       ├── 八字可视化模块.py               ← 八字可视化

│       └── 日期测试窗口.py                 ← 测试窗口（可选）
```

#### 1.3 data 目录

### 步骤 2：在手机上创建目录

1. 打开手机的 Python 编辑器（如 Python 编程学习、Pydroid 3 等）
2. 进入"默认目录"或项目根目录
3. 在 `src` 文件夹旁边创建新文件夹，命名为 `modules`
4. 在根目录创建 `data` 文件夹

### 步骤 3：复制文件到手机

#### 方法 A：使用 USB 数据线
1. 用 USB 线连接手机和电脑
2. 在电脑上打开手机存储
3. 找到手机 Python 编辑器的默认目录位置
4. 复制文件到对应位置

#### 方法 B：使用云存储
1. 将所有文件上传到百度网盘、腾讯微云等
2. 在手机上下载并解压
3. 移动到正确的目录

#### 方法 C：使用微信/QQ 文件传输
1. 将文件打包成 ZIP
2. 通过微信/QQ 发送到手机
3. 在手机上解压并移动到正确位置

### 步骤 4：验证安装

1. 在手机上打开 Python 编辑器
2. 找到 `src/择日软件_完整单文件版_小窗口.py`
3. 运行程序
4. 测试以下功能：
   - ✓ 择日计算
   - ✓ 打开评分系统
   - ✓ 导入评分系统
   - ✓ 显示详细评分

### 步骤 5：故障排除

#### 问题 1：提示"找不到模块"
**解决方案**：检查 modules 文件夹是否创建在正确位置

#### 问题 2：评分系统不可用
**解决方案**：
1. 检查 modules 目录下是否有 `日课评分系统.py`
2. 检查是否有所有依赖文件（四柱计算器.py、评分器.py 等）

#### 问题 3：提示"找不到 shensha.json"
**解决方案**：在根目录创建 `data` 文件夹并复制 `shensha.json`

1. **不要复制 .pyc 文件**：只需要 .py 源文件
2. **不要复制子文件夹**：modules/rules 和 modules/shensha 文件夹不需要

4. **确保编码为 UTF-8**：所有文件都应该是 UTF-8 编码

## 常见问题

**Q: 手机上运行速度慢？**
A: 第一次运行时会有缓存，之后会快一些。

**Q: 显示字体太小？**
A: 可以在程序代码中调整字体大小。

**Q: 提示导入错误？**
A: 检查 modules 文件夹是否在正确位置，文件名是否正确。
