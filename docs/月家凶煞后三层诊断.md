## 三、轻重层（分值梯度）初判

协纪卷十未给分值，仅给"忌/止不忌/与德合并犹忌"。分值梯度需从忌项范围与德合条件推断：

| 神煞 | 忌项范围 | 德合条件 | 轻重初判 |
|------|---------|---------|---------|
| 月破 | 极广（~50项） | 与德合并犹忌（天赦天愿不并） | 最重 |
| 月厌 | 极广（~50项，比月破更多） | 无明确德合豁免 | 最重（阴气尤毒） |
| 月刑 | 广（~45项） | 与德愿并可化凶为吉 | 重 |
| 四废 | 广（~45项） | 无德合豁免（止不忌有限项） | 重 |
| 三煞 | 同月破+3项 | 与德合并可减（止忌军事疗病） | 重 |
| 大时/天吏 | 中（~30项） | 无明确德合豁免 | 中重 |
| 月害 | 较少（~25项） | 无明确德合豁免 | 中 |
| 五墓 | 中（~30项） | 无明确德合豁免 | 中 |
| 往亡 | 较少（~17项） | 无明确德合豁免 | 中 |
| 大煞 | 极少（2项军事） | 与德合并犹忌 | 中（专忌军事） |
| 八专 | 少（5项） | 与德合并犹忌；天愿并可减 | 中轻 |
| 四击 | 极少（2项军事） | 无 | 中轻 |

**分值合理性待 (c) 全量裁断**：当前软件分值梯度（月破 -30~-40 > 三煞 -25 > 月刑/月害/月厌 -15 > 大时/五墓/四击 -12）整体方向合理，但大煞 -12、八专 -15、四击 -12 的注册事项范围需先收口（见上）。

## 四、制化层

协纪卷十德合并条件：
- **月破**：与天德月德天德合月德合并犹忌之（天赦天愿不得与月破并）→ **不可制化**（德合不能解）
- **月厌**：无德合豁免条文；"值灾煞又值月厌虽与德合并仍诸事皆忌" → **不可制化**
- **月刑**：与德愿并可化凶为吉 → **可制化**（德愿）
- **四废**：止不忌固定项，无德合豁免 → **不可制化**
- **三煞**：与德合并可减（止忌军事疗病）→ **部分可制化**
- **大煞**：与德合并犹忌 → **不可制化**
- **八专**：与德合并犹忌，天愿并可减 → **部分可制化**（仅天愿）
- **四击**：无德合条文 → **不可制化**（待考）
- **月害/大时/天吏/五墓/往亡**：无德合豁免条文 → **不可制化**（待考）

软件现状：所有月家凶煞均无豁免逻辑，与"不可制化"判定一致。月刑、三煞、八专的部分可制化在软件中未实现，但这属于"典据支持可制化而软件未实现"，需单独拍板是否补豁免逻辑。
