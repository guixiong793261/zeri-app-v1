| 6 | **多实现一致的结构性抄错** | **红纱孟仲对调、劫煞水火对调** | **只能与口诀对照** |

## 跟踪项 21：金神"年支对照表"更正——年金神只按年干分组（**2026-09-21 更正**）

### 更正事项

上一轮口径讨论中曾给出一张"**年支 → 金神方位**"对照表（按子、丑、寅…
十二地支年排列"某些年份金神在午未申酉、某些年份在辰巳"等）。**该表有
误，作废。**

- **错误性质**：那张表的内容实际是把《协纪》年表中按甲子序排列的若干
  年份的金神方位，误当成了"年支 → 方位"的通用映射。
- **正确口径**：金神方位只随**年干五合组**变化，与年支无关：

  | 年干 | 金神方位 |
  |------|----------|
  | 甲、己 | 午、未、申、酉 |
  | 乙、庚 | 辰、巳 |
  | 丙、辛 | 子、丑、寅、卯、午、未 |
  | 丁、壬 | 寅、卯、戌、亥 |
  | 戊、癸 | 申、酉、子、丑 |

  同组两年干可各配五个不同年支（如甲年可遇子/寅/辰/午/申/戌等任意
  年支），方位完全相同——"按年支查表"无法复现此规律。

### 落库证据

- 实现：`神煞基类._get_jinshen_positions(year_gan)` 单一年干入口；
  日家桩 `_is_jinshen`（按日干、恒 False、概念误为六甲旬空亡）已删
  （commit `0a8bc9f`）。
- 验证：`tests/verify_jinshen.py` 中 AUTH_JINSHEN **五组年干口诀
  硬编码**（不从软件读取），10 干逐一比对 0 差异；立春年界交叉断言
  2026-02-03（乙巳，金神辰巳）/02-04（立春换丙午，金神子丑寅卯午未）。

### 教训

**年神不都按年支取数**：三煞/岁破等按年支，金神按年干；同类神煞的
取数维度须以《协纪》年表原文逐年核对，不可凭"12 行排列很整齐"外推
为年支映射。与跟踪项 18"多实现一致不构成正确性证据"同源——排列规律
同样不构成口径证据。
