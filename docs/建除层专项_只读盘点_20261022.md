## 2. T3b 触发层：星名 ≠ 实际建除星

### 2.1 开业神煞：4 个伪建除谓词（364 天次/年）

`v3b_trigger_errors.json` 共 **364 条**，全部落在「开业」：

| 星名 | 声称 | 实际实现 | 全年误标天数 |
|------|------|----------|--------------|
| 满日 | 满 | 固定地支名单（非 offset 计算） | **168 / 183 次发射** |
| 成日 | 成 | 固定地支名单 | **111 / 121** |
| 闭日 | 闭 | 固定地支名单 | **85 / 93** |
| 破日 | 破 | 直接等于「月破」（`day_zhi` 冲 `month_zhi`） | 31 / 31（此 31 天**恰好正确**，因月破≡破日） |

- 后果：开业在**非满/成/闭日**也发射「满日/成日/闭日」并计分（+12/+10/-15），
  条目文案直接写「满日：宜开业」但当日并非满日 → **用户可见的确定性错误**。
- 唯一正确的「破日」反而与月破重复（见 §2.2）。

### 2.2 破日 ≡ 月破（同一个 `day_zhi` 冲月支）

开业同日发射 `月破 -30` 与 `破日 -20`，全年 **31 天**，单日建除/月破合计 **-50**。
两者是同一历法事实的两种命名（卷十月破即破日），属 **J4 双计**（实质唯一一处）。

### 3.3 改造难度评估（回答「有多大、影响哪些接口」）

**难度：低（谓词层），中（口径层）。** 理由：

1. 六路公式完全同型且 144×6 零差异 → 抽一个 `modules/建除.py` 纯函数即可，
   新模块不改任何现有签名，采用**委托式替换**（`return 建除.is_jianchu_ri(...)`），
   输出逐字不变，可用现有 144 格 + 哨兵 + 15 通道总分三重回归门禁。
2. 需新增的接口（建议）：

```python
# modules/建除.py（新文件，单点）
STARS = ('建','除','满','平','定','执','破','危','成','收','开','闭')
def star(month_zhi, day_zhi) -> str            # 唯一公式 (日支序-月支序)%12
def star_by_sizhu(sizhu) -> str                # 取 sizhu['month_zhi'], ['day_zhi']
def is_jianchu(sizhu, name) -> bool            # 制化矩阵 #4/#8/#9/#16/#17 用
def is_jianchu_date(date_obj, name, hour=12) -> bool  # rules 兜底/显示用，显式 hour
```

3. 受影响接口（**只加委托、不改签名**，共 7 类）：
   `黄道计算器._calculate_xiao_huang_dao`、`今日黄历.calc_jianchu`、
   `marriage_shensha.get_jianchu`、`通用神煞._get_xiao_huangdao`、
   `修造神煞扩展._check_jianchu`、rules `fallback_get_jianchu`（3 份）、
   开业神煞 4 个伪谓词（**这 4 个是唯一需要改写逻辑、非纯委托的**）。
4. 真正的难点不在谓词而在**口径**：11 份宜忌表 + 五行择日法白名单 + 事项标准键
   （§4），属决策项，不是技术项。
5. 时柱口径必须在接口上显式化：`hour=None`（按日）与 `hour=HH`（按时辰）在
   10 个交节日不同（§1.3），不能靠隐式 12:00 默认掩盖。
