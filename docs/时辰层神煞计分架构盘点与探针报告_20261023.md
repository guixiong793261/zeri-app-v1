## 二、架构耦合结论

**没有统一的 `check_shichen` 入口**。时辰层发射分散四处：

```
总分通道：
  通用事项 → 通用神煞._check_hour_shensha（黄道时/日破时）
  全事项   → 评分器三煞按柱分级（时柱临煞）
  修造类   → 修造扩展._check_hour_shensha_ext（10 项，L148 调用）
  婚嫁     → （时辰评分已删，仅时干间接进夫星等判定）
吉时推荐：
  嫁娶/修造 get_lucky_hours 两套独立十二时辰遍历（推荐时柱.py 统一构造）
展示层：
  今日黄历 tags（独立实现）
```

- 分值口径半统一：`_hour_delta`（神煞基类 L1850-1864）实现「同名项走 SHENSHA_SCORES、时辰专属项回退默认值」——但贵人时/禄神时/时冲主命/红鸾时/天喜时均未入统一表，实际分值散落在硬编码；
- 婚嫁「单一权威规则源」声明（L65）名不副实——其余三份贵人表未引用它；
- 各表值一致，**当前无算错风险，只有维护性债务**（改口诀需同步 4 处）。

### 4.3 结论

1. **无漂移 bug**：晚子时（23-24 时）＝日柱不换日＋按当日日干五鼠遁；子正（0 点）换日。与 [tests/test_core.py L84-105](file:///d:/自编择日软件/专业级正五行择日软件/tests/test_core.py#L84-L105) 断言（23:30→日柱当日/壬子时/is_late_zi=True）一致，防护到位（is_late_zi 标记＋单测锁定＋弃用 sxtwl 子初派）。
2. **立春/节气交节不影响时柱**：五鼠遁仅依赖日干，交节只切年柱/月柱——交节日无时柱漂移。
3. **唯一口径分歧（摊开不改）**：晚子时日干基数——软件取「当日派」（23:30 用当日日干遁时干），部分通书/命理派取「次日派」（23 点即换日）。影响面＝所有「时干×日干」类判定（五不遇时、未来的福星食神判定）：同一时刻 23:30，当日派判乙日丙子时（非五不遇），次日派判丙日丙子时（非五不遇）——具体差异需逐日核对；贵人时/禄神/黄道时/日破时按时支判定，**不受此分歧影响**。时辰推荐表（get_lucky_hours）遍历的子时干用 wushu_dun[day_gan] 推（甲己日甲子起），与四柱计算器同派自洽。
4. **全链一致性**：嫁娶 L113 wushu_dun、修造 L1146 推子时干、今日黄历独立五鼠遁表，与四柱计算器算法值一致——实测无漂移。
