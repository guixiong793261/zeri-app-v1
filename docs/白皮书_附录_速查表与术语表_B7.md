> 本册为《算法与典据白皮书》B7 分册。

> 数据源：`modules/事项标准.py` 的 `SHENSHA_SCORES`（191 个唯一注册名）+ `DISPLAY_ONLY_REGISTRY` + `黄道.py` 正表。
> 分值与否决状态以**代码为单一真源**；若本表与代码冲突，以代码为准，并回填本表。

## 附录 A · 神煞速查总表（191 项）

### A.0 读表说明

| 列 | 含义 |
| --- | --- |
| 神煞 | 注册名（已按 `_SHENSHA_ALIAS_KEY` 归一正名） |
| 族 | 神煞族，用于族内对照 |
| 分值 | 命中后进入 `五行评分` 的分值；跨通道不同者列差异 |
| 否决 | ◉ = 该神煞在对应通道可触发 HARD_VETO；空白 = 只扣分 |
| 状态 | 「仅展示」= `DISPLAY_ONLY_REGISTRY` 置 0；「已删」= 注册保留但发射已撤；「挂账」= 待清理/待证 |

### C.2 三个「绝不」

1. **绝不**让负分自动产生否决——否决必须能指向具体判据。
2. **绝不**把德神当万能解药——五墓限月、厌对全免，其余多为「止忌子集」。
3. **绝不**把方位神的忌借给日辰用——岁破、太岁、年三煞四柱，都是这一类错。
