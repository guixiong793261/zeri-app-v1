## 2. 关键发现：权威表修正

脚本初版内置的权威表假设"每个日干恰有 1 个五不遇时"（共 10 个）。首次运行后发现软件命中 12 个，经逐干核对发现该假设本身错误。

**五不遇时定义**：时干克日干，且阴阳属性相同。

**为何不是 10 而是 12**：
- 10 天干配 12 时辰（五鼠遁），时干会循环一次，导致部分日干有 2 个时辰的时干相同。
- **己日**（甲己组起甲子）：子时起甲子，时干序列为 甲乙丙丁戊己庚辛壬癸甲乙 → 乙出现在丑、亥两时 → **乙丑、乙亥** 均为五不遇时（阴木克阴土）。
- **庚日**（乙庚组起丙子）：子时起丙子，时干序列为 丙丁戊己庚辛壬癸甲乙丙丁 → 丙出现在子、戌两时 → **丙子、丙戌** 均为五不遇时（阳火克阳金）。
- 其余 8 干各 1 个。

**修正后的权威真值表**（共 12 个）：

| 日干 | 五不遇时 |
|------|----------|
| 甲 | 庚午 |
| 乙 | 辛巳 |
| 丙 | 壬辰 |
| 丁 | 癸卯 |
| 戊 | 甲寅 |
| 己 | 乙丑、乙亥 |
| 庚 | 丙子、丙戌 |
| 辛 | 丁酉 |
| 壬 | 戊申 |
| 癸 | 己未 |

> 脚本断言总数 = `EXPECTED_TOTAL = sum(len(v) for v in WUBUYUSHI_TRUTH.values())` = **12**。

## 3. 验证方法

脚本穷举 `TIAN_GAN(10) × HOUR_ZHIS(12) = 120` 组合，对每个组合：
1. 用五鼠遁推出时柱天干；
2. 调用软件判定函数，记录"是否命中五不遇时"；
3. 与权威表对照，统计命中数 / 误命中 / 漏命中；
4. 断言：命中数 = 12，误命中 = 0，漏命中 = 0。

**三处实现入口**：

| 入口 | 类型 | 实现位置 |
|------|------|----------|
| `modules.今日黄历.is_wubuyu` | 独立函数 | [modules/今日黄历.py:457](../modules/今日黄历.py#L457) |
| `修造神煞扩展.get_lucky_hours` | 端到端（经 `_is_wubuyu`） | [modules/shensha/修造神煞扩展.py:802](../modules/shensha/修造神煞扩展.py#L802) |
| `嫁娶神煞扩展.get_lucky_hours` | 端到端（经 `_is_wubuyu`） | [modules/shensha/嫁娶神煞扩展.py:354](../modules/shensha/嫁娶神煞扩展.py#L354) |

三处实现核心判定逻辑均为"日干索引 + 6 ≡ 时干索引 (mod 10)，且阴阳相同"：

- 今日黄历：`(d + 6) % 10 != h → return False`（[L461](../modules/今日黄历.py#L461)）
- 修造神煞扩展：`(day_idx + 6) % 10 == hour_idx`
- 嫁娶神煞扩展：`(hour_idx - day_idx) % 10 == 6`（[L367](../modules/shensha/嫁娶神煞扩展.py#L367)，Phase 1 由差 4 修正为差 6）
