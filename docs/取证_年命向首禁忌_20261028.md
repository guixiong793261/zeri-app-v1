2. **p635（入火安神，入宅归火邻接）**：「**凡人火安神要坐向中宮利宅主年庚不相沖尅**。如坐向不利…亦必要中宮空方可安神…日月忌日晦日與本命相沖尅日…」

4. **p588（竪造宅舍）**：「…**本命相合不相冲尅，又合得祿馬貴人極妙**；宅主命刄忌…只論坐向利…」

### 3.1 口径落差（必须与结论同权重呈报）

1. **载体是「坐向／山向」，不是「大门朝向」**：五条有效条无一以「大門／門向／門楼」为主语；p166「開門放水」一句讲的是先后天卦位，不含年命。
2. **关系是「冲克」泛称，不是「年支六冲」**：典文未限定为「生肖地支相冲」，更接近纳音/五行生克体系；软件若实现为「年支六冲 向首支」，属**口径收窄**，非典载原样。
3. **分域差异**：p166 明分「男用坐为主、女用向为主」；p635 只涉安神坐向；p96 只涉移徙。**不能合并成一条全域「年命×向首」规则**。
