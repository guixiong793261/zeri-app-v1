## 一、典载原文

### 1. 协纪卷十·宜忌（279228 页）

**大煞**
> 大煞　忌安抚边境选将训兵出师　与德合并犹忌【赦愿不得与大煞并】　按旧本并忌进人口纳财竖柱上梁其义不伦故删

同页兵禁按语互证：
> 按兵禁取逆义故忌军事虽与德合赦愿并无解於其逆也故犹忌**大煞仿此**

**八专**
> 八专　忌安抚边境选将训兵出师结婚姻纳采问名嫁娶　与德合并犹忌　与天愿并止忌安抚边境选将训兵出师余不忌　按八专自以干支取义与德合义不相属故与并犹忌……又按八专之忌婚嫁取隂阳同居而无别为义……故不忌婚嫁也【天愿并时】

**四击**
> 四击　忌安抚边境选将训兵出师　与德合天愿并犹忌【天赦不得与四击并】　按四击为四时旺土之冲故所忌如此与德合天愿并而犹忌者慎战也

### 2. 协纪卷十一·用事（279229 页，以事为纲逐事项忌列）

| 卷十一事项 | 忌列是否含本三煞 |
|-----------|----------------|
| 安抚边境 / 选将训兵 / 出师 | **含**：「忌……四击四耗四废四忌四穷五墓兵禁大煞往亡八专专日伐日」 |
| 结婚姻 / 纳采问名 | **含八专**（无四击、无大煞） |
| 嫁娶 | **含八专**（「忌……五墓往亡八专亥日」；无四击、无大煞） |
| 兴造动土【修造同】 | 无三煞 |
| 竖柱上梁 / 修仓库 / 开市 / 立劵交易 / 纳财 | 无三煞 |
| 般移【移徙同】 / 安牀 / 营建宫室 / 破土 / 安葬 / 入学（忌无）/ 求医疗病 | 无三煞 |

结论：卷十一逐事忌列中，大煞/四击**仅**出现在三个军事事项；八专出现在军事三事项 + 结婚姻/纳采问名/嫁娶。民用事项（修造、动土、安葬、入宅类、作灶类等）忌列均无此三煞。

### 3. 考原互校（卷六·逐事宜忌，359081 页）

> 出师　历例曰：「凡选将训兵、出师征讨等事宜……忌月虚、大时、大败、大杀、劫杀、死气、死神、天狱、天火、兵禁、五墓、往亡、四废、四离、四绝、四穷、四耗、**四击**、八专、九丑、月刑、月害、伐日、专日及四杀日。」

与协纪一致：军事事项忌四击/八专；民用事项无此二煞忌列。

### 4. 陈书第三参照

陈子性藏书全书无「八专」「四击」二词（穷尽检索 1130 页零命中）；「大煞」命中均为年神方位/逐日神煞表等异实概念（p146 飞宫、p826 逐日凶神、p859 将军大煞表），与月家大煞非同一神煞。第三参照不提供反证。

## 二、语境判定

- **大煞**：月支冲年支之神，专忌军事（与兵禁同义）。协纪编者已删旧本「进人口纳财竖柱上梁」诸忌（「其义不伦故删」）。
- **八专**：干支同气阴阳不备，忌军事与婚嫁两类；与天愿并则婚嫁不忌。
- **四击**：四时旺土之冲，专忌军事。
- 软件事项集（嫁娶/修造/动土/拆舍/入宅/开业/出行/安床/作灶/移徙/入学/求医/签约/安葬/通用）中**无军事事项**，故「军事」忌项在软件无对应注册位。
