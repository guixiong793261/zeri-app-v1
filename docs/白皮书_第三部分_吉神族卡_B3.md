> 本册为《算法与典据白皮书》B3 分册。卡片粒度遵循拍板①：**每神煞族一卡，族内差异以表格列出**。

> 典据引用遵循拍板③：正文以卷次为主；重大争议点另附原文短句（见 B6）。

## 3.0 卡片读法

| 字段 | 含义 |
| --- | --- |
| 起例 | 该神煞在何年/月/日/时成立。月一律指**节气月建**（寅月=立春至惊蛰前），非公历月。 |
| 分值 | 命中后进入 `五行评分` 的分值；跨通道不同者列差异表。 |
| 适用 | 该神煞实际参与评分的事项通道。未列事项即为不参与。 |
| 制化豁免 | 其它吉神/德神并临时，凶煞是否可解。**无典据明文者一律不放宽**。 |
| 典据 | 主锚《协纪辨方书》卷次；互校《御定星历考原》；第三参照《陈子性藏书》。 |
| 边界与坑 | 软件实现中容易误判、易被误读的口径。 |

> **总原则**：吉神分值不是“越多越好”的线性叠加。同一族内多位吉神并临时，按表列分值累加，但**制化豁免只按明文矩阵生效**，不自动延伸。

## 3.1 德神族（天德 / 月德 / 天德合 / 月德合 / 岁德 / 岁德合）

> **一句话**：德神是软件的“第一吉神团”，既是加分项，也是唯一合法的制化主体。

### 3.1.1 族内差异表

| 神煞 | 起例（节气月建） | 分值 | 说明 |
| --- | --- | --- | --- |
| **天德** | 正月丁、二月申（坤）、三月壬、四月辛、五月乾、六月甲、七月癸、八月寅（艮）、九月丙、十月乙、十一月巽、十二月庚 | **+20** | 四维月（二、五、八、十一）天德落在维方，以“维”论，不取干支 |
| **天德合** | 与天德相合之干/支（丁壬合→壬；申合巳；等等） | **+15** | 与天德同日成立时分别计分，不合并 |
| **月德** | 寅午戌月丙、申子辰月壬、亥卯未月甲、巳酉丑月庚 | **+18** | 三合局之阳干 |
| **月德合** | 与月德相合之干（丙辛合→辛；壬丁合→丁；甲己合→己；庚乙合→乙） | **+15** | 轻重层按“天德合月德合与旺气作五合，皆上吉之日”调至 +15 |
| **岁德** | 年干 → 应比**日干**：甲甲、乙庚、丙丙、丁壬、戊戊、己甲、庚庚、辛丙、壬壬、癸戊 | **+20** | 年家德神，取岁干之德比日干 |
| **岁德合** | 岁德干之五合，亦比日干：甲己、乙乙、丙辛、丁丁、戊癸、己己、庚乙、辛辛、壬丁、癸癸 | **+15** | 年家德神 |

> 天德/月德的实际取用：**月德只取天干，天德天干与维方并存**。软件按月建查表，闰月归节气月建，不另立闰月表。

### 3.1.2 分值

| 项 | 值 |
| --- | --- |
| 天德 | +20 |
| 天德合 | +15 |
| 月德 | +18 |
| 月德合 | +15 |
| 岁德 | +20 |
| 岁德合 | +15 |

### 3.1.3 适用

全通道通用（嫁娶/修造/动土/拆舍/入宅/移徙/开业/出行/安床/作灶/入学/求医/签约/安葬）。

### 3.1.4 制化豁免（德神族是全软件唯一合法的制化主体）

**参与制化的吉神集为六神**：天德、月德、天德合、月德合、天赦、天愿。

| 被制化凶煞 | 条件 | 结果 |
| --- | --- | --- |
| 月破 | 德神并 | **犹忌**（仅“止不忌”15 项，不可反向实现为全免） |
| 月破 | 德并 + 子午月灾煞 / 未申月月刑 | 不忌祭祀等，仍忌解除/疗病/破屋 |
| 月刑 | 德愿并（巳月相日六合） | **化凶为吉**（止忌军事、疗病） |
| 月刑 | 德神并（辰酉亥建日 / 丑戌收日） | 吉凶相抵（回常例） |
| 月刑 | 德神并（子/卯/未申月） | 如常例 |
| 三煞 | 德神并 | **可减**（止忌军事、疗病） |
| 大时 | 二德并（丑未月） | 止忌军事 |
| 大时 | 德神并（子午卯酉月） | 吉凶相抵 |
| 天吏 | 德神并（同大时） | 止忌军事疗病 / 相抵 |
| 八专 | 德并 | **犹忌** |
| 八专 | 天愿 | 止忌军事 |
| 厌对 | 天德/月德/天德合/月德合/天赦 | **不忌（全豁免）** |
| 游祸 | 德合/天赦 | **犹忌** |
| 五墓 | 月德（仅五月、十一月） | 不忌（限两月） |

**禁区**：
- 天恩**不在**德神集内，不得自动延伸参与制化。
- 天赦/天愿不得与月破并；天愿不得与厌对并（禁并排除对）。
- “犹忌负条款族”在德神前照忌：归忌、反支、飞廉、大煞、游祸、月破通用支、八专德并支、月厌、四废、往亡、月害。

### 3.1.5 典据

- 《协纪辨方书》卷四·义例二「天德」「月德」「天德合」「月德合」。
- 《御定星历考原》互校，逐字无分歧。
- 制化矩阵见《协纪》卷五、卷六相关条按语；全表见 B5。

### 3.1.6 边界与坑

1. **天德落维**：二/五/八/十一月天德在坤/乾/艮/巽，软件按“维”判，不能拿天干硬套。
2. **月德合分值**：注册表已 +15，基类旧发射 +12 会被 `shensha_score()` 查表覆写为 +15；排查时不要被基类常量误导。
3. **德神不是万能解药**：月破、八专、游祸在德神前仍忌，报告措辞不能写“德神到，百无禁忌”。

## 3.2 赦愿族（天赦 / 天愿）

> **一句话**：天赦是“大赦之日”，天愿是“合天心之愿”，二者均可参与制化，但都受禁并排除约束。

### 3.2.1 族内差异表

| 神煞 | 起例 | 分值 | 制化 | 典据 |
| --- | --- | --- | --- | --- |
| **天赦** | 春戊寅、夏甲午、秋戊申、冬甲子（按节气四季） | **+25** | 与厌对并 → 不忌；不得与月破并 | 《协纪》卷四·义例二 |
| **天愿** | 逐月取日干：正月甲、二月乙、三月丙、四月丁、五月戊、六月己、七月庚、八月辛、九月壬、十月癸、十一月甲、十二月乙 | **+12** | 八专并 → 止忌军事；不得与厌对并、不得与月破并 | 《协纪》卷四·义例二 |

> 天赦四日：**春戊寅、夏甲午、秋戊申、冬甲子**。注意“春”按节气立春起算，不按正月初一。

### 3.2.2 适用

- 天赦：全通道通用。
- 天愿：通用，但主要作为制化神出现。

### 3.2.3 制化豁免

| 场景 | 结果 |
| --- | --- |
| 天赦 + 厌对 | 厌对不忌（全豁免） |
| 天愿 + 八专 | 八专止忌军事 |
| 天赦/天愿 + 月破 | **禁止并论**（结构排除，不产生豁免） |
| 天愿 + 厌对 | **禁止并论**（结构排除） |

### 3.2.4 边界与坑

1. 天赦是**日级**神煞，不是“年”或“月”级；每年约 4–5 日。
2. 天愿逐月表易与“天德合”混淆：天愿取月建合神，天德合取天德之合，二者不同源。

## 3.3 三合族（三合 / 六合 / 半合 / 五合 / 山家三合 / 时与坐山三合）

> **一句话**：三合族是“地支抱团”的吉神，分值中等，但在修造/安葬中会与坐山发生二次关系。

### 3.3.1 族内差异表

| 神煞 | 起例 | 分值 | 适用 | 备注 |
| --- | --- | --- | --- | --- |
| **三合** | 日支与月支/年支成三合局（申子辰、寅午戌、巳酉丑、亥卯未） | +10 | 通用 | 三合局成局即计 |
| **六合** | 日支与月支六合（子丑、寅亥、卯戌、辰酉、巳申、午未） | +12 | 通用 | 六合最亲 |
| **半合** | 三合局中两支（生旺/旺墓）成半合 | +6 | 通用（地支关系通道） | 不与三合并计重复 |
| **五合** | 天干五合（甲己、乙庚、丙辛、丁壬、戊癸） | +10 | 通用 | 天干层面 |
| **五合日** | 日干与月干/年干五合 | +8 | 通用 | 日级五合 |
| **山家三合** | 日/月/年支与坐山三合 | +15 | 修造/安葬 | 山家专用 |
| **时与坐山三合** | 时支与坐山三合 | +15 | 修造/安葬 | 时家专用 |

> 说明：`半合`在总评分中走“地支关系”通道（+6），三合族卡只作归类展示，避免与“地支关系”重复计分。

### 3.3.2 制化豁免

三合族本身是吉神，不承担制化；但与德神并临时按德神规则处理。

### 3.3.3 典据

- 《协纪辨方书》卷四·义例二「三合」「六合」「五合」。
- 山家三合见《协纪》卷九、卷十修造/安葬条。

### 3.3.4 边界与坑

1. **三合与半合不重复计分**：半合已归入地支关系通道，不要再叠加。
2. **山家三合要看坐山**：坐山不在三合局内则不成立，不能只看日支。
3. 六合分值高于三合，是因为“合”比“局”更直接，勿误以为三合一定更强。

## 3.4 建除十二神族（建 / 除 / 满 / 平 / 定 / 执 / 破 / 危 / 成 / 收 / 开 / 闭）

> **一句话**：建除是“月建起十二辰”的日级吉凶序列，是本软件日课“骨架分”的来源之一。

### 3.4.1 族内差异表（注册表口径）

| 建除 | 分值 | 吉凶 | 备注 |
| --- | --- | --- | --- |
| 建 | 修造 -15 / 出行 +5 | 平（事项差异） | 建日宜出行、上任，忌动土、安葬 |
| 除 | +5 | 吉 | 宜扫除、清洁，忌嫁娶、安葬 |
| 满 | -5（另有 `满日 0`） | 凶 | 宜祭祀、祈福，忌动土 |
| 平 | -5 | 凶 | 宜修饰垣墙，忌嫁娶安葬 |
| 定 | +5 | 吉 | 宜嫁娶、立约，忌出行 |
| 执 | +5 | 吉 | 宜修造、动土，忌嫁娶 |
| 破 | -15 | 大凶 | 诸事不宜 |
| 危 | +10 | 吉 | 宜祭祀、祈福，忌嫁娶、动土 |
| 成 | +5（另 `成日 +10`） | 吉 | 诸事皆宜；卷四与天医天喜同位 |
| 收 | -5 | 凶 | 宜收敛，忌嫁娶 |
| 开 | +5 | 吉 | 诸事皆宜 |
| 闭 | -15（另 `闭日 -15`） | 凶 | 宜闭门静养，忌嫁娶、出行 |

> **两套表并存**：`黄道.py` 的小黄道正表（建 -10/除 +5/满 -10/平 -10/定 +5/执 +5/破 -10/危 +5/成 +5/收 -10/开 +5/闭 -10）与 `事项标准.py` 的建除注册表存在幅度差。**实际计分以 `shensha_score()` 查表为准**；B7 已标注“正表/注册幅度”两栏。

### 3.4.2 适用

全通道通用；建日/破日在修造、安葬中权重更高。

### 3.4.3 制化豁免

- 建除本身不参与制化。
- 建日/收日与德神并时，按“月刑相抵”条款处理（回常例），见 B5。

### 3.4.4 典据

- 《协纪辨方书》卷五·义例三「建除十二神」。
- 卷四《天宝历》成日同位【天医天喜】、满日同位【福德天巫天狗】。

### 3.4.5 边界与坑

1. **建除按月建起**：月建为建，顺行十二辰；闰月仍用节气月建。
2. **破日 ≠ 月破**：建除的“破”是十二神之一（-15），月破是月建所冲之支（-30），两者不可混用。
3. 成日/满日与天喜/福德是“同位异名”，软件已归并，不再单独注册，避免双计。

## 3.5 黄道十二神族（青龙 / 明堂 / 金匮 / 天德 / 玉堂 / 司命 / 天刑 / 朱雀 / 白虎 / 天牢 / 玄武 / 勾陈）

### 3.5.3 适用

- 日黄道：全通道通用，进入总分 `黄道` 分项。
- 时黄道（黄道时-青龙 +8）：主要用于择时/红帖时辰。

### 3.5.4 制化豁免

### 3.5.5 典据

- 《御定星历考原》互校。

### 3.5.6 边界与坑

1. **同名陷阱**：黄道“天德”是十二神之一，不是真正的天德贵人；不要拿它去解月破。
2. 黄道按日支起时支，**不是按日干**；起法错一位，整日黄道全错。
3. 朱雀/白虎在嫁娶中另有“时辰级”含义（见 B4/B6），与黄道凶神同名不同域，不可混算。

## 3.6 命局贵人族（天乙贵人 / 文昌贵人 / 福星贵人 / 禄神）

> **一句话**：命局贵人是“事主年命/日主”与日课天干地支的贵人关系，属“相主”范畴，不是通用日家神煞。

### 3.6.1 族内差异表

| 神煞 | 起例 | 分值 | 适用 | 典据 |
| --- | --- | --- | --- | --- |
| **天乙贵人** | 甲戊庚→丑未；乙己→子申；丙丁→亥酉；六辛→午寅；壬癸→卯巳 | 命中 +10（命局通道） | 相主/嫁娶/入宅 | 《协纪》卷七·义例五 |
| **文昌贵人** | 甲巳、乙午、丙申、丁酉、戊申、己酉、庚亥、辛子、壬寅、癸卯（食神临官） | +10 | 相主/学业 | 《协纪》卷七 |
| **福星贵人** | **日干生时干**曰福星贵人（协纪食神派） | +10 | 相主 | 《协纪》卷七·义例五 |
| **禄神** | 甲寅、乙卯、丙巳、丁午、戊巳、己午、庚申、辛酉、壬亥、癸子 | +10 | 相主 | 《协纪》卷七 |

> **福星曾经历重大修正**：旧谓词“年支+6 冲位查日支”与最凶神岁破同构，2026 实测岁破日白送 +10。现改为协纪食神派“日干生时干”，发射侧整链重建。

### 3.6.2 适用

- 命局贵人：作为“事主信息”列与详情“吉神”段展示；主评分走命局/相主通道。
- 天乙/文昌/福星/禄神 4 项为“核心吉神”列恒入列项（不论分值）。

### 3.6.3 制化豁免

命局贵人不制化凶煞，只作“相主得贵”加分；不得拿来解月破/三煞。

### 3.6.4 边界与坑

1. **福星不是“福星贵人”旧法**：旧法实为岁破同构，已删；现法只论“日干生时干”。
2. **禄神按日干**，不按年命；事主年命禄另有“岁禄/岁禄到山”。
3. 天乙贵人是“命局贵人”，不是日家“天乙”通用神煞，二者同名不同域。

## 3.7 恩喜族（母仓 / 天恩 / 天医 / 天喜）

> **一句话**：恩喜族是“养育、医药、喜庆”类吉神，分值中等，适用面窄，最容易被误当成万能吉神。

| --- | --- | --- | --- | --- |

## 3.13 吉神使用的三条铁律

1. **德神不万能**：月破、八专、游祸、月厌在德神前仍忌；报告不得写“德神到，百无禁忌”。
2. **同名不同源**：黄道“天德”≠德神“天德”；“天乙贵人”≠日家天乙；“禄神”≠“岁禄”。
3. **分值不叠加无据**：同一吉神在不同通道分值不同，以 `shensha_score(事件, 名)` 查表为准，不得手工相加。
