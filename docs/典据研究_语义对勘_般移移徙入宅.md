## 二、逐库典载原文与语境判定

### 2.1 般移＝移徙：协纪官方自注同义（✅ 全等）

- **卷十一·用事**（279229 L381）：「**般移【移徙同】**⏎宜天德月德天德合月德合天赦天愿月恩四相时德民日驿马天马成日开日⏎忌月破平日收日闭日劫煞灾煞月煞月刑月厌**大时**天吏四废**五墓**归忌**往亡**」
  ——协纪官方明注般移与移徙同条同义；**该条忌列明文含大时、五墓、归忌、往亡**。
- 考原卷六不用般移而径用「移徙」作词目（359081 L187），宜忌口径与协纪般移条同（宜驿马月恩四相，忌归忌九丑建破平收月厌）——互校一致（考原无大时五墓于移徙条，系其用事篇从简，非分歧对立，标注）。
- 陈书全文无「般移」一词。

### 2.2 入宅与移徙/迁移并列连用：主锚反证不同目（关键证据）

1. **协纪卷四·义例二·大小会所领日**（279222 L391，曹震圭曰）：「以上诸日虽遇天德月德玉堂生气黄道吉星值日亦不可用……忌兴造嫁娶上官赴任**入宅迁移**出行交易合药问病百事不宜」——忌列中「入宅」「迁移」**并列**。
2. **协纪卷八·义例六·天上三奇**（279226 L209，通书曰）：「……能制煞发祥中宫坐向得之上官嫁娶**入宅移居**修造营葬并吉」——宜列中「入宅」「移居」**并列**。
3. **考原卷五·立成**（359080 L393，转引曹震圭，与协纪卷四同文）：「忌兴造、嫁娶、上官赴任、**入宅**、迁移、出行、交易、合药、问病，百事不宜」——同样并列。
4. 陈书 p131 天赦条：「宜踈獄施恩祀神賽愿修造起工**入宅移居**百事吉」；p149 天刑条：「忌詞訟上官嫁娶**入宅移居**修舍宇」——三库一致并列。

**语境判定**：若入宅＝移徙，四处并列连用皆不成文。并列本身说明两库编者视为**两个事目**。

### 2.3 入宅的独立语义重心：迁入＋香火归位（与归火配套）

- **协纪卷三十三·利用**（279251 L379）：「凡移徙而修者必待修完後方可择吉**入宅**或岁官交承亦可」——移徙（迁居过程）与入宅（迁入动作）**先后衔接**，非同义替换。
- **协纪卷三十五·附录**（279253 L431/445/447）：「俟工作完备别择吉年月**入宅歸火**」「論**入宅**法山向中宮並無凶煞惟大門微有凶神……」「論**歸火**與豎造同日惟推吉時家主先移祖先福神香火**入宅**俗謂先過香火俟畢工後再擇吉日同家眷從吉方**入宅**」——入宅是修造完成后**携家眷迁入＋祖先香火归位**的成家动作，与归火配套。
- 陈书 p34 目录：「**入宅歸火**」独立词目（与分居、造作牛屋并列）；p622「安香火周堂……其例載在**入宅歸火門**」；p593/p647 多处「俟工夫完備另擇吉年月曰方可人宅歸火」。
- 陈书 p634「**八宅歸火** 謂八宅安祖先福神香火等事」、p638「逐月**入宅**吉日**移徙居處同看**」。

### 2.4 陈书第三参照与主锚的分歧（仅标注不取舍）

- **陈书 p638**：「逐月**入宅**吉日**移徙居處同看**横天朱雀二十五日忌移徒」——陈书操作层将入宅吉日与「移徙居处」**同看**（互看选日），此为支持「入宅归移徙族」的最直接明文。
- 但陈书入宅歸火門自建忌列（p635 归火条）：「忌月厭歸忌陰陽錯空……**氣往亡**天瘟受死火星天火正四廢四忌**五窮**冰消瓦解披麻殺天空滅没等曰」——**忌列无大时、无五墓**（「五窮」≠「五墓」，系另一煞）；「氣往亡」系协纪卷十「往亡【气往亡】」同条口径（279228 L122：「往亡　气往亡⏎忌……般移……」），非本条独立立义。
- 分歧实录：陈书「同看」提示操作等同；协纪并列连用提示事目区分。**两库口径不一致，按层级规则标注，不自取**。

### 2.5 附带澄清（不改既有判定，仅注记证据链）

d6 往亡×入宅「有载」判定所引陈书 p635，经本次逐字核读实为**归火条**（非入宅条）且煞名为**氣往亡**（协纪卷十往亡条含气往亡同条）。即该判定系两级借证：入宅→入宅歸火門配套条目、氣往亡→往亡同条口径。按协纪主锚（往亡条含气往亡同列忌）判定可维持，**判定不变（保留），证据链注记如上**。

## 五、待拍板（两案并列，分歧不取舍）

**裁断问题**：软件事项「入宅」可否归入典载「般移【移徙同】」事族？

### 方向①：入宅不可归入般移 → 大时×入宅、五墓×入宅列删除候选
- 依据：协纪主锚卷四「入宅迁移」、卷八「入宅移居」并列连用（不同目反证）；通书六十事/民用三十七事有移徙无入宅；陈书入宅歸火門自建忌列无大时五墓。
- 执行：与 P2 同款三步走（隔离→快照→删除），影响面另做快照；归忌×入宅、往亡×入宅不受影响（另有明文）。
- 连带问题：若严格执行，般移忌列其余条目（月破/劫煞/灾煞/月煞/月刑/月厌/天吏/四废）在入宅通道的同源性同受质疑——但其中多数另有陈书归火条忌列独立支撑（月厌/归忌/四废明文），需逐条复核后才能定删除面；**此方向工作量与波及面显著更大**。

### 方向②：入宅归移徙族 → 保留大时×入宅、五墓×入宅，注明「依般移条」
- 依据：陈书 p638「逐月入宅吉日移徙居處同看」（第三参照互看明文）；软件入宅发射面与般移忌列 12/12 系统重合（设计事实）；入宅与移徙语义同族（迁居）。
- 执行：两处描述串加限定词（如「大时咸池，移徙族忌」→ 建议改为在入宅通道描述注明依般移条），概念卡落档；零分值零判定变化。
- 风险：与主锚「并列连用」证据相悖，属依第三参照放宽映射，需在概念卡明确标注「依陈书互看＋语义同族，非协纪明文」。

### 倾向说明（供参考，非结论）
- 按「无证据不放宽」字面：本例并非典型放宽（般移忌列本身有载，问题在事目映射），方向②的「放宽」性质是**把有载条目映射到现代事名**，与 P2「无载删除」性质不同。
- 方向②改动最小且与软件既有设计自洽；方向①典据最纯但波及面大（连带月破/劫煞等同源条目复核）。
- **两案均不立即执行，等拍板**。拍板后：②走描述串限定＋概念卡（参照 z1 土瘟模式）；①走三步走＋逐条同源性复核清单。
