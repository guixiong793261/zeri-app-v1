## 二、判据逐条（三条红线已拍板）

### 判据 1：向方月破
- 以《协纪》"月破"条及方位禁忌条的**坐/向分述明文**为准。
- 若三库有"向方犯月破"明确严重档位明文 → 记**档位来源+卷页**，给出否决/扣分（-N）建议，**不动软判定**。

- 若三库对"坐/向"有明确对举 → 记 ⚠️/✅ 档，提出向方月破补入设计方案候选。

### 判据 2：太岁方位死链复活
- 三库对"太岁方"的**适用事项**与**严重档位**。
- 现 `get_taisui_fang` "太岁可坐不可向" 语义 → 比对三库，判 ✅/⚠️/❌。
- 死链定位采用**全库引用核查（断言清零）**；`return False`/`pass`/"保留供未来启用" 占位 → 标记为**待复活项**，逐条梳明原语义、死链点、复活与否候选、三库支撑档位，**不擅自复活/删除**。
- ⚠️ **红线（死链不擅自复活）**：pass/return False 很可能是前人发现逻辑不对而刻意屏蔽，必须查明原因，不盲目接活。

### 判据 3：方位神日辰化扫尾（三煞坐山 vs 向方）
- 三库对三煞（年/月/日）的**坐山与向方**分述档位（软件现：坐山/修方犯三煞一票否决；山向年三煞-25/月-20/日-15）。
- 逐维（年/月/日 × 坐山/向方）比对三库明文 → 五档标注。
- 三库无向方分述、软件却向方扣分 → 判 ❌/⚠️ 记候选修；三库有向方档、软件无 → 判缺失断层，记补入候选。
- **全部只记不改**，汇总"坐山×向方"断层矩阵。
