## 1. T7：新建 `modules/建除.py`（单一事实源）

### 1.1 导出面

```python
ZHI_ORDER   # ('子','丑','寅','卯','辰','巳','午','未','申','酉','戌','亥')
STARS       # ('建','除','满','平','定','执','破','危','成','收','开','闭')
JIXIONG     # {星: '吉'|'凶'}，吉=除危定执成开，凶=建满平破收闭（J2）
JI_STARS    # frozenset 吉星
XIONG_STARS # frozenset 凶星

star(month_zhi, day_zhi) -> str          # 非法地支 raise ValueError
star_by_sizhu(sizhu) -> str              # 月支取 month_zhi/月支/月柱[1]；日支取 day_zhi/日支/日柱[1]
is_jianchu(sizhu, name) -> bool
is_jianchu_date(date_obj, name, hour=12, minute=0) -> bool   # 内部延迟 import 四柱计算器
```

### 1.2 口径

- **按日判（默认）**：`is_jianchu_date` 默认 `hour=12`，与现有 `calculate_sizhu(date, 12, 0)` 口径一致。
- **按时辰判（交节日特判）**：调用方传入真实 `hour`；评分链路内部优先用 `star_by_sizhu(sizhu)`（`sizhu` 已含真实时柱月支），不得再回落 12:00。
- 非法输入（空串/非十二支）：`star` 抛 `ValueError`，各委托方保留自己原有的兜底文案（`未知`/`''`），**不得静默按索引 0 计成「建」**。
- 模块底部导入自检：`len(STARS)==12`、`set(STARS)==set(JIXIONG)`、`JI_STARS|XIONG_STARS==set(STARS)`、两者不相交，违例 `raise RuntimeError`。
