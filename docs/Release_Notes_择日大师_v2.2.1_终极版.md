- 发布批次：2026-11-09（累计 35 个核心提交）
- 适用对象：一线择日师、择日馆、需要移动端现场出帖的使用者

## 一、版本定位

v2.2.1 是正五行择日主线的首个「可交付终端用户」终极版，核心解决三件事：

1. **榜单可信**：极品的称号不再虚高，榜单与详情页顶部结论完全同源；
2. **动土可用**：承认修造动土“难有全白之局”的实战现实，用「上品」承接可制化小煞；
3. **独立成器**：精准择时独立版完成入口、事主、农历、择日贴的闭环，可单独发给客户使用。

## 三、核心升级明细

### 3.1 极品 / 上品分档（001 §245）

**问题**：旧口径下，「极品」只校验日课是否有警告，出现“榜单标极品、点开详情顶部是黄牌”的撕裂感。

**新口径**：

- **吉事（入宅、嫁娶、安葬、出行、开业等）**
  - 极品 = 日课校验无警告 **且** 详情页顶部决策面板为绿灯（吉课可用）。
  - 宁缺毋滥：入宅 2026 年 65 天、嫁娶（1–4 月）7 天。
- **动土事（修造、动土、装修、拆舍）**
  - 极品仍要求绿灯（2026 年实测为 0 天）；
  - 另设 **「上品（动土可制化）」**：校验无警告 + 无否决 + 无伐日 / 克山 / 三煞临山 / 金神到山；
  - 鲁班煞、土王用事、向方三煞、五行偏枯等“动土常态小煞”允许带黄牌入榜，并在悬停中逐项说明制化理由。

**界面表现**：

- 极品：金底 + 悬停「顶部决策绿灯（吉课可用）」；
- 上品：浅绿底 + 悬停「本日含动土常态小煞……可经现场祭拜制化后安全使用」；
- 结果表筛选下拉新增「上品(动土可制化)」一档。

### 3.2 偏枯程度分级（001 §246）

- 评分器新增落库「偏枯计数」（四柱八字中火系 / 水系字数）；
- 吉事：火 / 水 ≥ 4/8 即黄牌（维持原口径，人和之事不容燥热）；
- 动土事：火 / 水 = 4/8 视为**轻度偏枯**，可入上品，悬停注明「火气稍旺，有助生扶山家，动土无妨」；≥ 5/8 判**重度偏枯**，踢出上品。
- 影响：修造·坤山（飞星）上品由 30 天收敛为 18 天，纯正五行由 50 天收敛为 29 天；吉事极品数量不变。

### 3.3 专家决策分析面板（001 §238.12 / §238.15 / §238.15c / §242）

- 日课详情顶部新增红绿灯裁决面板：综合裁决 → 裁决依据 → 对坐山影响 → 对事主影响 → 结论；
- 修复面板重复渲染 Bug；
- 重煞改为分级硬触发：真重煞（伐日 / 克山 / 临山 / 金神到山）才黄牌，向方三煞可豁免；
- 高分阶梯豁免：分数越高，可容忍的煞扣分越多，避免“高分好课被小煞一刀切”；
- 婚嫁事项补齐事主影响逐条说明，详情窗自适应放大。

### 3.4 精准择时独立版闭环（001 §238.11 / §238.14 / §238.17 / §238.19）

- 新增独立入口 `精准择时版_主程序.py`，与主程序共享同一套底层评分，无独立计分逻辑；
- 反推详情新增「事主」页签，事主四柱实时回显 + 八字详情弹窗（纯展示，不改分）；
- 接入择日贴：反推右键可加入择日贴 / 生成红帖；
- 补齐农历输入（公历 / 农历切换 + 闰月负数）；
- 修复“事主已加载却被误报未输入”（姓名为空导致）；
- 与主程序榜单结果逐字对拍的校验脚本 `verify_standalone_consistency.py` 随版本维护。

### 3.5 反推榜单增强（001 §241）

- 榜单时辰精筛：在 Top-N 结果上再做推荐时辰复核，避免“日子吉、时辰凶”；
- Top-N 相关 UI 全部中文化（数量、档位、排序说明不再出现英文术语）；
- 「吉日优先 / 纯总分排序」切换保持二次确认，纯总分模式下慎用日红字标注扣分主因。

### 3.6 相主与冲主（001 §238.18）

- 统一 HARD_VETO：封死“冲主只扣 3 分”的历史漏洞，日支与任一福主生肖六冲一律一票否决；
- 辅助者不再豁免冲主，与主事主同权；
- 年支冲福主维持扣分口径（正五行主宽，遵《协纪辨方书》「选择亦无专取本命年支一字之例」）。

### 3.7 详情与保存修复（001 §238.13 / §243 / §244）

- 三煞总扣分与明细对不上：补「另计项」对账展示；
- 极品筛选失效修复：补齐 lucky_hours / bride_year_zhi，筛选真实生效；
- 详情窗「保存 / 关闭」按钮被挤压不可见 → 修复布局；
- 保存内容补齐顶部决策分析面板与【重要警示】块，txt / json 双格式同步。

### 3.8 延续能力

真太阳时回显、四柱联动、红纸帖三态分流（吉帖 / 慎用 / 否决）、核心吉神列与 Tooltip、玄空飞星加权（正五行 0.7 + 飞星 0.3）等 v2.2.1 既有能力全部保留。

## 四、口径变化提醒（请一线择日师注意）

1. **「极品」含义已收紧**：不再是“分数高”，而是“日课校验无警告 + 顶部决策绿灯”。看到极品，点开详情顶部一定是绿色。
2. **修造查不到极品属正常**：修造动土在 2026 年没有全绿之日，请使用「上品(动土可制化)」筛选；上品日必须按悬停提示完成现场祭拜制化。
3. **偏枯按事项区别对待**：同一火 4/8 的日子，入宅会被黄牌，修造可作为上品。这是有意为之，不是 Bug。
4. **冲主为一票否决**：任何事项，日支六冲任一福主生肖即弃用，不再有“扣分后仍可用”的空间。

## 五、实机试用建议

1. 先用各自门派法本复核 3–5 个已用过的历史日课，核对分数与吉凶结论是否与师承一致；
2. 修造类请重点验证「上品」日的制化说明是否与实际操作习惯吻合；
3. 嫁娶请验证事主双方年命录入后，顶部决策面板的事主影响段是否逐条可读；
4. 精准择时独立版请验证农历输入、事主页签、右键生成红帖三条链路；
5. 如遇可疑结论，请保留「日期 + 四柱 + 山向 + 事主 + 事项 + 详情截图」五要素反馈，便于逐条复核。
