## 一、版本定位

v2.2.1 是正五行择日主线的首个「可交付终端用户」终极版，核心解决三件事：

1. **榜单可信**：极品的称号不再虚高，榜单与详情页顶部结论完全同源；
2. **动土可用**：承认修造动土“难有全白之局”的实战现实，用「上品」承接可制化小煞；
3. **独立成器**：精准择时独立版完成入口、事主、农历、择日贴的闭环，可单独发给客户使用。

## 三、核心升级明细

### 3.1 极品 / 上品分档（001 §245）

**问题**：旧口径下，「极品」只校验日课是否有警告，出现“榜单标极品、点开详情顶部是黄牌”的撕裂感。

**新口径**：

- **吉事（入宅、嫁娶、安葬、出行、开业等）**
  - 极品 = 日课校验无警告 **且** 详情页顶部决策面板为绿灯（吉课可用）。
  - 宁缺毋滥：入宅 2026 年 65 天、嫁娶（1–4 月）7 天。
- **动土事（修造、动土、装修、拆舍）**
  - 极品仍要求绿灯（2026 年实测为 0 天）；
  - 另设 **「上品（动土可制化）」**：校验无警告 + 无否决 + 无伐日 / 克山 / 三煞临山 / 金神到山；
  - 鲁班煞、土王用事、向方三煞、五行偏枯等“动土常态小煞”允许带黄牌入榜，并在悬停中逐项说明制化理由。

**界面表现**：

- 极品：金底 + 悬停「顶部决策绿灯（吉课可用）」；
- 上品：浅绿底 + 悬停「本日含动土常态小煞……可经现场祭拜制化后安全使用」；
- 结果表筛选下拉新增「上品(动土可制化)」一档。

#### 3.1.1 极品门槛「三取二」放宽（001 §256，2026-11-11）

**问题**：§253 起「六维核验（得令/合局/德神/专属项/相主/硬忌）全过才能列极品」的口径下，
2026 下半年真实反推（甲戌福主，修造甲山庚向 / 入宅卯山酉向 / 嫁娶）**0 极品、0 上品**——
高分日课全部卡在「得令/合局/德神」三格局项全空，门槛脱离实战，极品沦为理论存在。

**新口径（三取二）**：

- **硬忌**（零警告无重煞）+ **相主**（有事主时相主≥0、无硬性门槛、无负分条目）：**必选**；
- **得令 / 合局 / 德神**：三项中**任意两项过**即可（三取二）；
- **专属项**（修造=扶山补龙、嫁娶=利月吉日、入宅=全家相合、安葬=仙命相合、出行=出发方向）：**保留必选**；
- 文案区分：必选缺项 →「必选核验缺『X』」；仅格局不足 →「格局『得令/合局/德神』三取二未达」。

**真实数据验证（甲戌福主，2026 下半年 184 天）**：极品从「全年 0 个」放宽为「每月可达」——
修造极品 1（11-25 上吉 250 分）、入宅极品 13（07-15 221 分起）、嫁娶极品 3。

**同批澄清——「总分 0」排查**：曾出现 250 分上吉日课在分档判定中读到「总分 0」，
经查为**测试脚本喂错对象**（把 search_top_n 返回的精简行当完整评分器 result 喂入），
评分器与排序键本体无 bug。改喂 scan_day 返回的完整 best_r 后正常。

**回归**：verify_245 重冻 4 处（断言口径随三取二更新），全量 run_all 151/151 PASS；
排序键六副本 SHA 一致；双 exe 重建 + PYZ 取证 PASS。

### 3.2 偏枯程度分级（001 §246）

- 评分器新增落库「偏枯计数」（四柱八字中火系 / 水系字数）；
- 吉事：火 / 水 ≥ 4/8 即黄牌（维持原口径，人和之事不容燥热）；
- 动土事：火 / 水 = 4/8 视为**轻度偏枯**，可入上品，悬停注明「火气稍旺，有助生扶山家，动土无妨」；≥ 5/8 判**重度偏枯**，踢出上品。
- 影响：修造·坤山（飞星）上品由 30 天收敛为 18 天，纯正五行由 50 天收敛为 29 天；吉事极品数量不变。

### 3.9 相主红线与上品兜底（001 §247）

**问题**：旧版「极品 / 上品」只看校验与决策，不看事主。修造·乾山一例：总分 407、顶部决策绿灯，但相主得分 -13（子酉破 -15 / 子未害 -5 / 流年冲太岁 -8），对事主影响明确打红叉，仍被标成极品。全量体检发现 2026 年入宅 48 个极品中有 6 天相主为负；修造上品 39 天中有 24 天相主为负；2021 年更有一天总分 **-34** 仍列上品。

**新口径**：

- **相主红线**：填写了真实事主且「相主得分 < 0」（冲 / 克 / 刑 / 害 / 破任一扣分，哪怕只扣 1 分），当日直接失去极品与上品资格；
- **上品兜底**：上品另须满足「总分 > 0」且「等级不含凶」，杜绝负分课混入推荐位；
- **只摘牌、不作废**：被剔除的日子仍按原总分与等级留在普通吉日池，不影响其可用性判断。

**界面表现**：悬停首行直接写明原因——

- `⚠️ 本日得分虽高，但冲克事主（相主得分 -X），已被剥夺极品/上品资格。`
- `上品兜底拦截：本日总分 N 分（等级），未达「总分>0 且等级不含凶」的上品门槛。`

**影响面（2026 全年）**：入宅极品 48 → 42（单事主）／33 → 30（双事主）；修造·坤山上品 39 → 12；修造·乾山上品清零；2021 修造·乾山上品 29 → 5。

### 3.10 校验器 E001 误报修复（001 §248）

- **现象**：向方三煞等场景下，报告顶部综合裁决为「吉课可用」，但紧接一行 `⛔ 本报告未通过日课校验（ERROR 项见文末）`，整份报告被判不可交付。
- **根因**：评分器总分并入 11 个分项，而校验器 E001 的恒等式只汇总 7 项，漏掉「向方扣分」「出行方位得分」「仙命坐山得分」「仙命冲坐山六冲」，导致 238 分被误判为应为 258 分。**评分本身正确，是校验器误报**。
- **修复**：E001 与总分公式同源汇总，附加项存在即计入；校验强度未放宽——总分一旦被改动仍立即报错（反向断言锁定）。
- **影响面**：仅消除误报，任何一课的分数、等级、极品/上品判定均不变。

### 3.11 天乙贵人入计分（001 §250）

- **现象**：日课【吉神】段显示「天乙贵人」，但【神煞信息·吉神(加分项)】没有这一条、也不加分；条件择日里勾「天乙贵人」等于勾了个空选项。
- **根因**：天乙贵人此前只在八字「吉神」展示段写入，神煞计分层从未发射同名条目，展示与计分两套口径分裂。
- **修复**：
  - 神煞基类新增天乙贵人口诀单一表源与谓词，日干查四柱地支，任一柱命中即贵，发射「天乙贵人 +15」，同名去重只计一次；
  - 评分器展示段改引用同一常量，杜绝双表分叉；
  - 通用、动土两条不调父类的手工副本补齐同口径发射，15 个事项通道全部生效。
- **分值**：15 分，次于天德 20、月德 18，与天德合、三奇同档。
- **影响面**：2026 全年 156 天命中（42.7%），各通道全年总分整齐 +2340；多柱同时命中只计一次，不叠加。

### 3.12 五行偏枯分级与偏向分析（001 §251）

- **新增【五行偏枯分析】模块**：日课详情、评分详情窗、导出文本、精准择时反推详情四处同步展示，让择日师不用自己数八字。
- **五行统计**：四柱天干 + 地支本气共 8 字，逐行列出金木水火土数量。
- **偏枯分级**（四档）：极度偏枯（某行 ≥5 或 ≥2 行缺失）/ 偏枯（某行 =4，火标「过燥」、水标「过寒」）/ 缺项 / 平衡。
- **格局解析与调候建议**：直接给出解药——如「缺水：急需时辰补水（用亥/子时）」「火旺：建议用水旺之时调候制衡」。
- **纯展示层**：不影响任何分数、等级、否决与黄牌判定；火/水计数与既有过燥/过寒预警同源同值。

### 3.13 三元合参面板（001 §252）

- **新增【三元合参：日课 · 山家 · 事主】模块**：紧接【五行分析】之后，把天（日课）、地（坐山）、人（事主）三者的生克关系一次摊开，不必再翻相主 / 仙命 / 三煞各段。
- **⛰️ 日课与山家**：给出课生山（扶山 / 补龙）、比和（旺山）、课克山三类结论；叠加扶山宜项，以及「山被支克 / 合局克山 / 克山运」三类克山忌项（有制化者不判凶）；顺带提示坐山是否犯年三煞、岁破。
- **👤 日课与事主**：汇总喜用神补益与相主冲合——解毒为「补益事主喜用神」，被冲则标明硬门槛六冲（不可用）或刑害破小冲，有冲有补标 ⚠️。
- **🧭 山家与事主**：安葬取仙命，其余事项取事主年命纳音，与坐山五行比对生克（如「坐山生主命」「坐山克主命，主耗费气力」）。
- **📌 综合结论**：一句话分级——相主硬门槛冲主「必须换日」> 课克山且主凶 > 课克山「动土如伤根基」> 山克主 > 课主小冲 > 全吉「三元相生」> 无坐山「人和天时兼得」> 平和。
- **纯展示层**：只读既有计分明细，不产生新分值，评分总分 / 否决结论 / 等级判定逐字未动；出行事项的「方位」为出发方向而非坐山，该维度自动旁路。

## 四、口径变化提醒（请一线择日师注意）

1. **「极品」含义已收紧**：不再是“分数高”，而是“日课校验无警告 + 顶部决策绿灯”。看到极品，点开详情顶部一定是绿色。
2. **修造查不到极品属正常**：修造动土在 2026 年没有全绿之日，请使用「上品(动土可制化)」筛选；上品日必须按悬停提示完成现场祭拜制化。
3. **偏枯按事项区别对待**：同一火 4/8 的日子，入宅会被黄牌，修造可作为上品。这是有意为之，不是 Bug。
4. **冲主为一票否决**：任何事项，日支六冲任一福主生肖即弃用，不再有“扣分后仍可用”的空间。
5. **相主为负只摘牌，不作废**：相主得分 < 0 的日子不会被系统判死，只是拿不到「极品 / 上品」牌子；是否采用由择日师结合门派法本决定。
6. **上品必须总分 > 0 且等级不含凶**：历史上出现过负分课混入上品的漏洞，本次已封堵。

### 8.2 入宅通道剥离「修造逻辑越权」（001 §273）
