## 六、周堂与动作级弱相关条目（本批唯一"动作级"痕迹）

1. **协纪卷三十五 附录·嫁娶周堂**：起例「大月从夫顺数，小月从妇逆数，遇第、堂、厨、灶日用之」；按语「…岂得有吉凶生於其间耶？…因载在时宪书，故存其旧，**第勿拘忌可耳**」⇒ 协纪**明确不认**周堂吉凶（辨讹性质）。
2. **考原卷六 嫁娶**：把「周堂值第、堂、厨、灶日」列**宜**，「周堂值夫妇日」列**忌**（L2 与 L1 相抵，属"存其旧"）。
3. **陈书 p791**：「周堂值厨灶第吉（值第乃第宅之第）…**值堂宜帐客、香火，次早拜堂则吉**；值翁姑，**归门时翁姑少避**」⇒ 这是三库中**唯一**把周堂落到"拜堂／归门"动作时点的文字，属**时刻级民俗**（L3），且与"改日择吉"不同，是"同日内避让"。
4. **陈书 p800**：「月家天地官符、大小月建占中宫，及日家大杀、雷霆、白虎占中宫亦忌，鼓乐在香火堂起奏在大门外奏进吉，**若新妇拜堂…则不忌**」⇒ 动作级"仪式位置"避让（中宫／门），属**方位**，非时辰。

> 判定：动作级"时刻"记载仅陈书 p791 一处（L3，单典据），**不足以支撑评分**；可作为 M2 的**提示层**（"若周堂值堂，可次早拜堂"）。
