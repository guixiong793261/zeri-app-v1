## 一、典据取证（只读、全卷扫）

### 1.1 陈书 p788（本次挂账的直接来源）

> 經嘴朱雀丁卯丙子乙酉甲午癸卯壬子辛酉日并**不可安床在乾方**

- 位置：陈书 p788，月令逐日宜忌表（该月「安床」栏的忌例条）。
- OCR 变体：`經嘴朱雀`（= 紅嘴朱雀）；同页同栏另列四離/四絕/九土鬼/㓕没等。
- 语义：七日的安床忌，**带明确方位限定「在乾方」**。

### 1.2 陈书 p890（九宫起例，已在用）

> 乾宮：丁卯、丙子、乙酉、甲午、癸卯、壬子、辛酉七日在乾宮，忌修床（朱雀歌「乾上一辰莫安床」）

- 语义：以**日干支归宫**的方式给出日类忌（修床＝安床），**无方位限定语句**。

### 1.3 同源旁证与排除

| 页 | 原文要点 | 与本议题关系 |
|---|---|---|
| p96 | 「不可安在中宮……切不可犯紅嘴朱雀入中宮，犯者不吉、屢見甚驗」（入宅/归火语境） | 入宅已按 §192 升否决；中宫为每宅必有，无需方位输入 |
| p157 | 「系工嘴朱雀……忌入火、安神」、起工架馬/修木料 | 非安床，排除 |
| p574 | 通书某工事忌例中并列「受死、荒蕪、月破、紅嘴朱」 | 无方位限定，非安床专属 |
| p601 | 「紅嘴朱雀作水溝凶日：辛未、庚辰、己丑、戊戌、丁未、丙辰」（放水） | 另一事类、另一日组，排除 |
| 协纪 40 卷 / 考原 7 卷 | 「嘴」**零命中** | 本煞**单一典据**（仅陈书） |

### 1.4 五档判定

- 「安床忌带方位限定（乾方）」：**⚠️ 部分匹配**——p788 有明文方位，p890 起例为日类忌、无方位；两说并存，属**同一煞的两种落地形态**（日类 vs 方位），非矛盾但必须择一或分层。
- 「中宫/坤宫/乾宫/震宫四宫各配事类」：**✅ 全等**（陈书 p96/p890/嫁娶坤宫/作灶震宫，代码 `_HONGZUI_PILLARS_BY_GONG` 已对齐）。
- 「无典据即放宽」：本议题**不适用**——p788 恰是有典据指向“限定”，不属凭空放宽。

## 三、影响面（2026 全年实测）

以 `安床`、`chuangwei='西北'` 计：

| 指标 | 数值 |
|---|---|
| 全年带「红嘴朱雀 -30」的天数 | **43**（乾宫 7 日 / 60 日循环） |
| 其中总分 <60 | 11 |
| 其中 60–99 | 7 |
| 其中 ≥100（仍被推荐为吉日） | **25** |
| 若豁免（+30）后跨入 ≥100 | 7 |
| 若豁免后由 <60 升入 ≥60 | 2 |

判定：

- **误伤方向是“好日被压低”，不是“凶日被抬高”**——红嘴只扣分、从不否决，故豁免不会放行危险日，只会让非乾方床位的好日不再被误扣。
- 25 天即便被误扣 30 分仍 ≥100，说明误伤**不改变多数日的结论**，仅影响 7+2 天的档位。

## 四、问题判定

**问：安床通道的红嘴朱雀是否必须与「乾方」等具体方位绑定？**

答：**典据上必须绑定（p788 明文）；实现上没有绑定（日类全量 -30，取 p890 起例口径）**。现状属“两条典据只落地了不带方位的那一条”，对**床位不在乾方**的日课构成系统性误扣（43 天/年）。但需注意：本煞**单一典据**、且 p788 属月表条文（非通例卷文），p890 起例同样成立，故不能简单判“现状错”，只能判“现状不完整”。

## 五、立项建议（三案，供拍板）

### 案 A：维持现状 + L4 标注升级（零分值变化）
- 在 `安床神煞` 的 L4 标注中补记：陈书 p788「并不可安床在乾方」指向方位限定，本实现按 p890 起例取日类忌、**未做方位门控**。
- 成本：1 处文案；风险：0；收益：读者不再误以为已含方位判定。

### 案 B：方位门控（推荐，需拍板）
- 改造：`评分器` 在 `安床` 路径把 `chuangwei` 透传给神煞检查器（`check(sizhu, owners, chuangwei=...)`，仅安床传值，其余事项保持空）；`安床神煞` 依据床位朝向分派：
  - 床位朝向 = **西北** → 维持 -30，文案改为「红嘴朱雀临乾宮，忌安床于乾方（陈书 p788）」；
  - 床位朝向 ≠ 西北（已填） → **0 分**，另出提示「该日红嘴朱雀在乾方，非乾方安床不犯（p788）」；
  - **未填** → 保守维持 -30，提示「未填床位朝向，按最严口径（p890 日类忌）计」——沿用 §192「未填向首→不放宽」的容错先例。
- 影响：43 天/年中有 26–43 天（取决于填写率）由 -30 转 0；7 天跨入 ≥100、2 天跨入 ≥60；六副本重建 + 新增 `tests/verify_安床红嘴乾方.py`（断言西北扣、非西北免、未填扣、其他事项不受影响）。
- 风险：引入“填了才生效”的不对称，必须在忌项文案与产品说明中显式标注，避免用户误以为红嘴消失（与制化空集豁免同类警示要求）。

### 案 C：全事类降级为提示（0 分）
- 与 p890 起例直接冲突（起例为日类忌，无方位限定），**不建议**。
