## 建议补充优先级

### 高优先级（核心缺失）
1. **年神类凶煞**：丧门、吊客、病符、官符、五鬼、大煞
2. **嫁娶专用**：益后、续世、阴德、阳德、吉期、要安、五离
3. **修造专用**：土王用事、刀砧煞、斧头煞、木马煞、月虚、八专
4. **入宅专用**：岁德、丧门、吊客、病符
5. **通用吉神**：鸣犬日、鸣犬对日、天赦日（补齐各模块）

1. **年神类吉神**：岁德、岁德合、岁合、五富、天恩
2. **修造专用**：天地转煞、山曜、岁德
3. **作灶专用**：灶君朝天、火忌
4. **日神类**：魁罡日、上朔日、反支日
