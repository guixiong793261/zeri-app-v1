## 一、受死日

### 1.1 典载原文（逐条核读）

**① 陈书 p54（总论）**

> 「一論**受死凶曜也，喪塟卽不忌**，如槩云凡事皆忌者非。」

**② 陈书 p152（逐月受死条）**

> 「**受死　上官起造嫁娶等凶，宜安塟。** 詩曰：正戌、二辰、三亥、四巳、五子、六午、七丑、八未、九寅、十申、十一卯、十二酉。」

（OCR「兎」「雞」为「卯」「酉」）

**③ 陈书 p748（安葬总论）**

> 「土府、土瘟、土符止忌破土，**不忌安塟；卽受死日亦不忌安塟。吉事凶。**」

**④ 陈书 p793（逐月嫁娶凶日表）**

> 「受死　戌辰亥巳子午丑未寅申卯酉」
> 「紅沙殺　曆不忌　巳酉丑（循环）」

**⑤ 陈书 p791 / p792（嫁娶忌项）**

> p791：「……決不可犯**歸忌紅紗**等殺，避盡諸煞……」
> p792：「……忌亥日、陰將陽將、陰陽俱將、氣往、四離四絶、月厭、厭對、歸忌、天賊、八龍、**受死**、徃亡、**正紅紗**、人民離日、月忌、晦日、沖尅本命日、正伏斷日……」

**⑥ 协纪 p279224（卷六·九神总论，唯一「受死」命中）**

> 「……或又以寅月从巳午戌起，如例历十二辰者为龙虎、为罪至、**为受死**，皆为凶神……**若夫龙虎、罪至、受死三辰，并仍旧历从删**，夫既以九神为吉，则余三不用可知，不必重立名目也。」
> 「其戌之为受死者，亥为阳气剥尽之会……故以戌为受死也。然此特以六阳六阴十二辰从寅轮转而命之云尔，**若自寅而卯以至于丑，逐月论之，则义并不可通**。」

**⑦ 考原**：全卷**无**「受死」命中（0/0）。

### 1.2 命题判定

| 命题 | 判定 | 依据 |
|---|---|---|
| **P1 边界**：受死日是否「凡事皆忌」 | **⚠️ 部分匹配（明限）** | 陈书 p54 反对「凡事皆忌」；p748 明言「丧葬不忌、吉事凶」；p152 明列「上官、起造、嫁娶等凶」。故**不是凡事皆忌，但吉事确忌** |

| **P3 嫁娶条款**：受死日是否忌嫁娶 | **⚠️ 部分匹配（仅陈书明文）** | 陈书 p152「嫁娶等凶」＋ p791/p792 嫁娶忌项列受死＋ p793 逐月嫁娶表列受死。**主锚/互校均无载、亦无相反明文** |
| **P4 起例**：逐月受死表三库是否一致 | **✅ 全等（陈书内部一致；主锚/互校无载）** | 陈书 p152 诗诀「正戌二辰三亥四巳五子六午七丑八未九寅十申十一卯十二酉」与 p793 表「戌辰亥巳子午丑未寅申卯酉」完全一致；软件 `_SHOUZI_ZHI_BY_MONTH` 与之一字不差 |

### 1.3 对「是否冤枉受死日」的直接回答

- **不冤，但 p54 被误读了。** p54 的原句是「受死凶曜也，**丧葬即不忌**」——它限定的对象是**丧葬**，并反对由此推成「凡事皆忌」。它不是「受死日对吉事也不忌」。
- 同书 p152 紧接着说「上官、起造、**嫁娶**等凶，宜安塟」；p748 更明确「即受死日亦不忌安塟。**吉事凶**」。
- 三条合并起来的完整边界是：**丧葬不忌；嫁娶及其它吉事凶**。因此：
  - **安葬**：不注册受死 —— 与三库一致，正确；
  - **嫁娶**：忌 —— 有陈书明文，**不是被冤枉**；
  - **入宅 / 移徙**：陈书 p152 未列名，仅能由 p748「吉事凶」**外推**，属单库泛化，存疑（见 1.4）。

## 二、红纱日

### 2.1 典载原文（逐条核读）

**① 协纪 p279217（乾隆四年奏请改驳条）——主锚最强明文**

> 「一**红沙日忌嫁娶**、上兀下兀、四不祥日忌上官，**选择通书皆不载，万年书亦不载红沙**。【臣】监旧例注时宪书时按期添入。查**红沙乃己酉丑金局日：孟月巳日、仲月酉日、季月丑日**，相传又误以为孟月酉日、仲月巳日，**甚属无当**……**应请一并删去**。」

**② 协纪 p279254（卷三十六·辨讹「红沙」条）**

> 「**转神历曰：红沙者，孟月酉、仲月巳、季月丑，其日忌嫁娶。**○储泳袪疑说曰：己酉丑之所以为煞者，先天数之四冲也……○**按：红沙即身壬煞**，储华谷以为极数，然驿马亦是极数，是不得以极为凶也……若四季月丑日，则真建破魁罡，不待以红沙而后为忌也。**又一本孟月取巳、仲月取酉，皆与季月例同，通书万年书皆不用，故今仍之，不以转神为据云。**」

**③ 协纪 p279228（卷十·用事宜忌·月破按语）**

> 「旧本不忌嫁娶……盖嫁娶旧止宜不将日，又忌**章光、无翘、伏断、归忌、红沙**，若再忌月破等日，恐致无日可用，是不得已为权宜之术耳。今按**章光、无翘等皆俗说**，拘于俗忌而不避大凶，其所为权宜者殊为未当。」

**④ 协纪 p279223（卷五·月德合按语，异名互证）**

> 「……巳酉丑谓之三煞，又谓之破碎，**又谓之红沙**。」

**⑤ 考原**：全卷**无**「红沙 / 紅紗 / 红纱」命中（0/0）。

**⑥ 陈书 p799（論紅紗殺）**

> 「**論紅紗殺：四孟金雞、四仲蛇、四季丑日是紅紗是也。或書以戌、寅、巳、卯、庚、申、辛、酉為紅紗者非。**」

（四孟金鸡＝酉，四仲蛇＝巳 → 陈书此处为**孟酉、仲巳**）

**⑦ 陈书 p791 / p792（嫁娶忌项）**

> p791：「……決不可犯歸忌**紅紗**等殺……」

**⑧ 陈书 p793（逐月嫁娶凶日表）**

（表行按正/二/三……循环为 巳、酉、丑 → **孟巳、仲酉、季丑**，与 p799 **自相矛盾**；且明注「曆不忌」。）

### 2.2 命题判定

| 命题 | 判定 | 依据 |
|---|---|---|
| **P1 存在性**：三库是否收录「红纱日」独立条目 | **⚠️ 部分匹配** | 协纪有「红沙」但**定性为无当、请删**；考原无载；陈书有「紅紗殺」并列入嫁娶忌。词条名「红纱日」三库零命中 |
| **P2 权重**：是「忌嫁娶」还是「起例之误」 | **❌ 不符（主锚否定）** | 协纪 p279217 明言「选择通书皆不载，万年书亦不载红沙」「甚属无当」「应请一并删去」；p279228 把红沙与章光无翘并称「皆俗说」。主锚不是批起例，而是**否定红沙作为嫁娶禁忌本身** |
| **P3 起例**：孟巳仲酉季丑是否为三库一致 | **⚠️ 部分匹配（库内/库间冲突）** | 软件＝孟巳仲酉季丑，与协纪 p279217 所述「己酉丑金局」**一致**；陈书 p799 为孟酉仲巳（相反），陈书 p793 表为孟巳仲酉（与软件同）。陈书**同书自相矛盾**，且 p793 注「曆不忌」 |
| **P4 注释归属** | **❌ 不符（表述不准确）** | 软件注释称「《协纪辨方书》辨讹正解：孟月巳、仲月酉……『四孟金鸡四仲蛇』为相传之误」。辨讹篇（p279254）实际以**转神历（孟酉仲巳）**为引，并明言「通书万年书皆不用」「不以转神为据」；「相传之误」的定性与「请删」出自 **p279217 奏疏**，非辨讹篇。归属需正名 |

### 2.3 红纱是否「真的该被一票否决」

- **主锚：否。** 协纪在奏疏中把「红沙日忌嫁娶」列为**应删条目**，理由有三：①选择通书、万年书皆不载；②起例本身有两说互相矛盾；③「甚属无当」。卷十按语又把红沙归入「皆俗说」。
- **互校：无载。** 考原全卷没有红沙条目，既无支持也无相反。
- **第三参照：有明文忌嫁娶，但内部矛盾。** 陈书 p791/p792 把「紅紗」列入嫁娶忌项；然而同书 p799 的起例（孟酉仲巳）与 p793 的表（孟巳仲酉）相反，且 p793 明注「曆不忌」。因此陈书对红纱的禁忌**强度不可靠**。
- **冻判据下的结论**：
  - **删除门槛不成立**——陈书有「忌嫁娶」明文，第一条「三库全无忌嫁娶明文」即失败；
  - **降级门槛成立**——主锚有「甚属无当、应请删去」的明斥（强于「明限」），足以支持**撤否决、保留扣分**；
  - 若要**彻底删除**（连 -20 也去），需用户**破格拍板**，因为冻判据的删除门槛被陈书明文挡住。
