## 编写原则（全文贯穿，先在序章声明）

1. **三库主锚**：以《协纪辨方书》为官方主锚，《御定星历考原》互校，《陈子性藏书》第三参照；三库分歧只标注、不自行取舍。
2. **无证据不放宽**：无典籍明文支持的规则，不放宽、不新增；宁可保留展示、不参与计分。
3. **五层验证**：表源层 → 触发层 → 口径层 → 轻重层 → 制化层，逐层给证据。
4. **双通道去重**：神煞通道与建除/宜忌通道不得重复计分（H1 红线）。
5. **识别展示 ≠ 计分**：`score=0` 的展示项必须写明“为何保留展示”，避免读者误以为漏算。
6. **证据分级标注**：✅ 全等 / ⚠️ 语义等价 / ⚠️ 部分匹配 / ❌ 不符 / — 无载。
