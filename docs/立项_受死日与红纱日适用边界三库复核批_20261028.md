## 一、立项事由

### 1.1 受死日

现行软件：受死日在**嫁娶**（§194）与**入宅/移徙**（§195 C1）均为 HARD_VETO（一票否决，
0 分纯展示），依据为陈书 p152「上官起造嫁娶等凶」。

但陈书同书 p54 明言「受死凶曜也，喪塟卽不忌，如槩云凡事皆忌者非」——即受死日对
**丧葬反而不忌**，且反对「凡事皆忌」的泛化。两条典文同出一书，可能存在：
- 适用事项分野（p152 列举上官/起造/嫁娶等，p54 限定丧葬）；
- 或 p152 的「嫁娶凶」为后人误抄、p54 为正解。

**需三库复核：受死日对嫁娶/入宅究竟是「大忌」还是「不忌」？**

### 1.2 红纱日

现行软件：红纱日在嫁娶为 HARD_VETO（veto_keywords 含 '红纱日'）。

协纪 p279217 明言「红沙日忌嫁娶……选择通书皆不载，万年书亦不载……甚属无当」，
p279254「辨譌」篇亦列「红沙」。主锚明确否定。

**需三库复核：红纱日对嫁娶是否真为禁忌？若否，撤除否决。**

### 3.1 证据层级

1. 《协纪辨方书》——官方主锚
2. 《御定星历考原》——互校
3. 《陈子性藏书》——第三参照

**层级硬约束**：陈书为第三参照，其单库明文不足以单独支撑删除或降级；须满足
「主锚或互校有明载」或「主锚/互校无相反明文 + 陈书有明限」的组合条件。

### 3.2 命题拆解（受死日与红纱日分别独立取证，不得合并）

**受死日**
- P1 边界：受死日的适用事项，是「上官起造嫁娶等凶」还是「惟某事忌、某事不忌」？
- P2 丧葬条款：陈书 p54「喪塟卽不忌」是否成立？是否影响安葬？
- P3 嫁娶条款：陈书 p152「嫁娶凶」上下文是否真包含嫁娶？协纪/考原是否载「忌嫁娶」？
- P4 起例：受死日逐月口诀三库是否一致？

**红纱日**
- P1 存在性：三库是否收录「红纱日」独立条目？
- P2 权重：若收录，是「忌嫁娶」还是仅「起例之误」？协纪 p279217「甚属无当」
  是批起例还是批神煞本身？
- P3 起例：红纱日（己酉丑金局：孟月巳、仲月酉、季月丑）三库是否一致？

### 3.3 五档四分法

| 档位 | 含义 | 后果 |
|---|---|---|
| ✅ 全等 | 明文与本事项禁忌完全一致 | 维持 |
| ⚠️ 语义等价 | 表述不同但覆盖同一情形 | 维持，正名 |
| ⚠️ 部分匹配 | 仅覆盖某事项/某层 | 评估收窄或降级 |
| ❌ 不符 | 明文有相反表述 | 降级/删除候选 |
| — 无载 | 全卷无 | **未填不放宽**：维持现状 |

### 3.4 决策门槛（按事项分别裁断，禁止一刀切）

- 维持：主锚/互校有「忌嫁娶/入宅」明文，或三库无载（未填不放宽）。
- 降级为扣分：主锚/互校有明限（「某事不忌」）或两库无「忌嫁娶」明文 + 陈书有明限。
- 删除（扣分也去）：仅在「三库全无忌嫁娶明文」+「主锚/互校无相反明文」+
  「陈书明限」三者同时成立时才可提出。
- **单条陈书明文不足以删除**（层级硬约束）。

### 3.5 冲突处理

- 三库分歧：标注双方原文与卷页，不自行取舍，呈报拍板。
- 陈书 p54 vs p152 同书冲突：照录两条原文与上下文，不自行取舍，呈报拍板。
- 协纪批起例 vs 批神煞：逐字核读，区分「起例之误」与「神煞本身无当」。
