## 4. 五档判定

**先答拍板 §10.2-1 两问：**

**问一：「动土」是否涵盖破土/穿井/开渠/筑墙？**
典籍中「动土」是土工营缮类**总目**：总要历以「破土、穿井、开渠、筑墙」4 事
列土符所忌；协纪宜忌/用事系扩为 16 事并以「兴造动土【修造同】」为其中之一
总条；考原直书「**修造、动土并忌土符**」；陈书歌诀「月建土府土符忌动土」。
破土/穿井/开渠在协纪、考原中均另有专条且条条同忌土符。
结论：软件以「动土」一词注册**方向是收窄**（典籍土工清单 16 事 ⊃ 软件 3 事），
不构成外推；「忌动土」表述有明文，成立。

**问二：「入宅」有无典据明文？**
三库全卷扫：土符 44 命中，**0 处与入宅族词共现**；「入宅」一词三库共出现
42 次（协 14／考 1／陈 27），**无一处列于土符所忌**。
结论：**— 无载。按 §10.2-1 判定为零典据**；「土符日不宜入宅」、
「入宅搬动家具亦忌」（待证事项）、入宅规则.py「入宅大忌…土符」自述，
均无典据支持。
