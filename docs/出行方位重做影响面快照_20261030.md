## 五、否决差 81 → 31（50 课）逐一归因

对 50 个"否决状态改变"的日期，用 `_p201_vetodiff.py` 在基线仓与改后仓各重算一次，
抓取 `veto_reasons` 原文：

| 项 | 结果 |
| --- | --- |
| 否决状态改变课次 | 50 |
| 基线否决原因（去重） | **仅 1 条**：`三煞大忌：年三煞(月柱)（一票否决）` |
| 改后否决原因 | 无（50 课全部解除否决，0 条新增否决） |
| 日期分布 | 2026-11-08 ～ 2026-11-30、2026-12-01 ～ 2026-12-31（连续 50 课，全部落在**亥月／子月**） |

原因解析：2026 为丙午年（寅午戌三合），年三煞在**亥子丑**。旧版出行通道用
"月柱支是否落年三煞支"作一票否决（与坐山无关的四柱内证），亥／子月整月被误杀；
该规则随 `_TRAVEL_SANSHA_KEYS` 旁路一并失效。**差额 50 与月份分布完全自洽**，
无其他否决来源混入（1–10 月否决数逐月相等，可作反证）。
