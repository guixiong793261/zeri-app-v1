## 四、结论与定性

1. **量级**：12 年 × 两通道共 8,766 个「事件-日」中被否决化 815 天（入宅 469 ＋ 移徙 346），其中 381 天原为 ≥100 分的上吉/大吉。该量级与「升一票否决」的定性匹配，不是微弱调整。
2. **口径一致**：移徙与入宅同权（同一 canonical 门控）；嫁娶/安床/作灶 0 变化（A4 断言）。
3. **容错有效**：未填山向时向首规则 0 天触发（B3、B8）；无年支 0 触发（B7）；修造/安葬 0 触发（B9）。
4. **判定不变项**：红嘴朱雀神煞分值仍 −30、发射天次不变；神煞通道总分对拍无变化（既有 `verify_hzzq`/`verify_shie_dabai_delete` 等仍 PASS）。
5. **回归**：全量 120/120 PASS（新增 `tests/verify_入宅红嘴_向首否决.py` 17 项断言全过，原 119 脚本零失败，无需重冻任何既有断言基线）。
