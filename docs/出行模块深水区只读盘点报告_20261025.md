## 二、问题① 时辰煞生效情况（核心发现）

### 2.1 截路空亡 —— 选日生效 ✅ / 选时漏发 ❌

- **选日通道**（出行神煞.py L223-225）：`_add_shensha('截路空亡', -15, ...)`，谓词 L325-349 按《历例》「甲己日申酉时，乙庚日午未时，丙辛日辰巳时，丁壬日寅卯时，戊癸日子丑戌亥时」。
  - 实测：全年每支 73 命中（乙/庚日→午未、戊/癸日→子丑戌亥…，命中数与典载概率完全吻合），实扣 -15。✅
- **选时通道**（推荐时柱 `build_checker('出行')` → 修造神煞扩展 `get_lucky_hours`）：**全仓无截路空亡发射**（修造神煞扩展.py 0 命中）。
  - 实测样例日 03-01 申时 -15、巳时 -15 的扣分原因为「刑月支/刑害月支」，**无任何一日含截路空亡**。
  - **后果**：推荐吉时可能落在截路空亡时（如 2026-03-01 出行吉时申时同时是丁壬日截路空亡时，选时通道照推）。

### 2.2 日破时 —— 选时生效 ✅ / 选日漏发 ❌

- **选时通道**（修造神煞扩展 L1154-1157）：`hour_score += self._hour_delta('日破时', -20)`。
  - 实测：06-07 午时「日破时」在说明中（-26 = 日破时 + 自刑年支/月支）；03-01 辰时「日破时」-10。
  - 分值解析：事项标准 **无 `('出行','日破时')` 专属键** → 走 `('*','日破时'):-10` 通配兜底。**注意**：修造族专属 -20，出行只能拿通配 -10（口径见 事项标准 L387-390、L1561）。
- **选日通道**（出行神煞.py 时块 L215-225）：只发射 出行吉时/截路空亡；基类时块（神煞基类.py L1902-1904）为 `pass`。
  - 实测：时辰煞逐支统计**无日破时条目**（4380 样本 0 命中）。
  - **后果**：日课评分/选日不受日破时影响——同一时辰，选日时不扣、选时却扣，两通道口径分裂。

### 2.3 出行吉时 —— 仅选日通道 ✅

- 出行神煞.py L219-221 发射 +8，实测 365 天全命中（子寅卯巳午酉六支）。
- 选时通道无「出行吉时」概念，靠修造扩展通用黄道时/贵人时等独立打分，**不叠加出行吉时**（属通道差异，非故障）。
