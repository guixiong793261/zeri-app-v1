## 1. 典载原文（制化词共现条目全核读，无抽样）

**制化词表**：制 / 化 / 解 / 赦 / 愿 / 德 / 天乙 / 贵人 / 并犹忌 / 不能化解。
**44 命中含制化词共现 22 条**，逐条语境判定如下：

1. **协纪·卷十·宜忌**（279228 L839/L841）——【主锚·不可制化】
   「土符、地囊　忌营建宫室…破土，**与德合、赦、愿并犹忌**。」
   九坎条按语：「九坎九焦忌见义例，与德合义不相属，故与并犹忌，**非谓其日之凶德神不能化解也，土符、地囊、归忌、血忌仿此**。」
   ——协纪明文：土符与德合/赦/愿并列**仍忌**，德神**不能化解**。此为三库唯一直接论述土符制化问题的典据，方向明确为**不可制化**。
2. **协纪·卷十一·用事**（279229 L445 等 14 条）——【佐证】
   14 条土符所忌事项（营建宫室、修宫室、缮城郭、筑堤防、兴造动土、修仓库、
   修置产室、开渠穿井、安碓磑、修饰垣墙、平治道涂、破屋坏垣、栽种、破土）
   之「宜」列虽含天德/月德/天德合/月德合/天赦/天愿，但「忌」列**直接平列土符**，
   无「与德合并则不忌」之结构（对照九空条「与德合并则…不忌」为可制化范例）。
   ——协纪用事体例如是区分：可制化者注明「与德合并则不忌」，土符条均无此注。
3. **协纪·卷六·义例四·土符条**（279224 L271/L273）——【伪制化排除】
   曹震圭曰：「土符者，乃土地握符信之神…假令春木旺土受其克，故**托子金以制之**，是春三月历巳酉丑也…」
   ——此「制」为**五行生克制化义**（解释土符所历三合推排由来：春木旺克土，
   土生子金，金制木以护土），**非制煞方法**。协纪按语已批「以夏为土休、秋为土相，
   则于五胜之义舛焉」，明确不采纳曹氏五行义解释。故本条不构成「土符可制化」证据。
4. **考原·卷四**（359079 L217）——【伪制化排除】
   曹震圭同文「托子金以制之」。与协纪同源，为五行义非制化方法。
5. **考原·卷六**（359081 L303）——【佐证】
   破土条「忌密日、重日、复日、**土符**、地囊、建、破、平、收日…并太岁同支干日、土王用事后」——
   与土王用事后、太岁同支干日等**不可制化项**并列，间接佐证土符不可制化。
6. **陈书·安碓条 / 论土王用事条**——【佐证】
   安碓条：「忌建破平收日…土符土府地囊凶日…**吉多则亦不忌**」——
   此「吉多则亦不忌」为陈书整体择日原则（吉凶相抵），非土符专属制化法；
   且陈书同页「土府土瘟土符止忌破土不忌安葬」明定土符所忌范围，未提制化。
7. **三库穷尽声明**：44 命中**0 处**「土符可制」「土符可化」「土符可解」
   「土符可禳」「土符遇××则不忌」之明文方法；唯一制化论述为协纪卷十
   「德神不能化解」。

## 2. 语境判定

- 「制」6 处：全部为曹震圭五行生克义（托子金以制之），**非制煞**，协纪按语已否定其义。
- 「化」2 处：协纪卷十「德神不能化解」（反义，证不可制化）；考原卷六「化」字
  出现在他条语境，非土符制化。
- 「解」5 处：协纪卷六「曲为之解而愈不能通」（指考辨历法讹误，非化解凶煞）。
- 「赦/愿/德」共现：协纪卷十「与德合赦愿并犹忌」——证不可制化；协纪卷十一
  各条「宜」列含德神但「忌」列土符无豁免结构——佐证不可制化。
- 协纪内部制化范例对照：九空条「与德合并则…不忌」（可制化）vs 土符条
  「与德合赦愿并犹忌」（不可制化），体例区分明确。
