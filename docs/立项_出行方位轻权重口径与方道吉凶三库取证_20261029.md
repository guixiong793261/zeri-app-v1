# 立项：出行方位轻权重口径与方道吉凶三库取证（001 §199 P1 专项）

> 立项日期：2026-10-29　来源：`docs/全系统终极大考与全渠道发布验证报告_20261029.md` §四 P1
> 关联改动：Commit 1（`8c386fe`）/ Commit 1-补（`469614e`）——出行已移出山家封禁否决通道
> 本立项为**只读取证 + 口径设计**，成稿即停，等待用户拍板；拍板前不改任何计分与文案。

## 一、问题陈述

1. **概念错位**：出行的"山向"实为**出发方向**，不是固定建筑的坐山。现行系统把出行
   纳入 `SHAN_UI_EVENTS`（UI 渲染"坐山/兼向/罗盘"），并把该值送入
   `_get_sansha_info` 的山向通道，产生三煞（山向/向方）与向方月破扣分。
   Commit 1-补 已切断"封禁否决"，但**扣分通道仍在**：
   20 课实测 填山向总分 1322 vs 不填 1682（差 360），且无非否决日分数相同。
2. **UI 误导**：主程序在出行分支仍显示"坐山"字样，用户会以为填的是坐山。
3. **古法口径未落地**：古法出行择日看的是**方道吉凶**（天德方/月德方/岁破方/太岁方、
   日游神方位、鹤神方位、往亡日、四离四绝、杨公忌等），并非坐山三煞；本系统尚无
   出行方位通道。

## 二、目标与非目标

**目标**
- G1 查明三库（协纪辨方书 / 御定星历考原 / 陈子性藏书）关于"出行择方"的原始条文，
  确定可落地的方位吉凶项清单与力度档位。
- G2 给出"轻权重"计分口径设计（候选：方向吉神 +5~+15、方向凶煞 −5~−15、
  仅极端项保留否决），并与现行三煞/向方通道的取舍关系说清。
- G3 给出 UI 改造方案（"坐山"→"出发方向"，字段复用还是新增）。

**非目标**
- 不改三库之外的派别口径；不引入无典据的方位表（无证据即不放宽/不新增）。
- 不在本立项内改码；不改其他四通道行为。

## 三、判据预冻（先冻后取，事后不得回改）

采用五档四分法（沿用 B-b 四轨结构与 §198 体例）：

| 档 | 含义 | 处置 |
| --- | --- | --- |
| ✅ 全等 | 典载条文与拟落地规则逐字等价 | 可直接落地 |
| ⚠️ 语义等价 | 名称不同、语义同一（正名候选） | 落地并正名 |
| ⚠️ 部分匹配 | 条件/范围部分重合 | 评估影响面后决定 |
| ❌ 不符 | 与典载冲突 | 按典修正候选 |
| — 无载 | 三库穷尽后无记载 | **不放宽、不新增**（不得以通书或网络文章补齐） |

三库层级：**协纪（官方主锚）> 考原（互校）> 陈书（第三参照）**；分歧仅标注，
不自行取舍。通书层仅作"存在性佐证（参考级）"，**不得推翻主锚**。

## 六、拟议口径（候选，待取证确认后才成立）

- C1 新增"方道"输入（出发方向），与"坐山"分离；出行不再使用三煞山向通道。
- C2 方道吉神：天德方、月德方、（如有典据）岁德方 → 轻权重 +5~+15。
- C3 方道凶煞：岁破方、太岁方、往亡日、（如有典据）日游神/鹤神 → 轻权重 −5~−15。
- C4 仅"岁破方 + 往亡日"等极端叠合考虑降档，**不以单一方位一票否决**。
- C5 UI："坐山"→"出发方向"；未填时沿用 §199 P2 的口径（不警示，因不进入坐山通道）。

以上仅为候选，**不代表已确认口径**；最终由取证结果 + 用户拍板决定。
