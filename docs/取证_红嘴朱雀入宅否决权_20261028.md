## 三、语境判定（A-V1～V4 逐条）

| 判据 | 结论 | 依据 |
|---|---|---|
| A-V1 绝对禁用语 | **成立（字面＋语境）** | p96「切不可犯」；全书该词仅 4 处且均为重要禁忌；「犯者不吉，屢見甚驗」为后果语 |
| A-V2 类目归属 | **不成立** | 全卷无「大凶日／極凶日／諸事不宜」类目收录红嘴；p574 是伐木起工忌日清单，非典籍自定类目 |
| A-V3 并列处罚 | **不成立** | p574 与受死／月破同列，但仅有清单表头「忌」，**无共享处罚语**，且属巽宮伐木域，非入宅 |
| A-V4 仅「忌」 | **部分成立** | p890／p601／p631／p157／p784／p788 均为纯「忌」，无后果语 |

### 3.1 三条削弱证据（必须与 V1 同权重呈报）

1. **处罚语仅「不吉」**：p96 原文不是「大凶／损人／立见祸」，而是「犯者不吉」＋「屢見甚驗」。相较 p131「動土極凶」、p148「百事並忌極凶」、p155「修造主殺人大凶」，红嘴的后果语明显轻一档。
2. **p890 主条仍为纯「忌」**：九宫起例全文九宫皆「忌某事项」，无一处写力度；p96 的「切不可犯」是**应用条**而非起例条。
3. **煞为宫位限定，不是全域否决**：p788 明写「不可安床**在乾方**」——即乾宮红嘴只禁「床在乾方」，不是「此日不可安床」。若入宅升否决而不加方位限定，会把「归火不在中宮」的情形也一律否决。

### 3.2 预承诺执行

冻结预承诺：A-V1／V2／V3 任一成立 → 建议升否决。本批 A-V1 成立 → **建议升否决（入宅通道）**。同时按 §3.1 呈报：若以「处罚语须达大凶级」为实质门槛，则应回落维持 `-30`。**两者取舍属口径裁断，不属取证，交出拍板。**
