## 1. 典据层：三个概念的正名（Q1）

### 1.1 概念一：方位三煞（太岁三煞；岁/月/日时三煞是其时间层级）

| 要素 | 典据内容 |
|---|---|
| 定义 | 「三煞者，太岁所杀之三方也」「神隶于地……随太岁之所指挥」（协纪卷33引宗镜）；「劫煞者岁之阴气……所理之方忌有兴造」「岁煞之地不可穿凿修营移徙」（协纪卷3引神枢经/广圣历）；「三杀者，太岁所杀之三方也」（宗镜集卷五） |
| 煞锚（起点） | **太岁年支三合局之冲**：申子辰→巳午未、寅午戌→亥子丑、巳酉丑→寅卯辰、亥卯未→申酉戌；**月三煞、日时三煞推法同**——宗镜集卷十二三杀诀「寅午戌年亥子丑……**月日同**」；陈子性页729「三殺凶方，年月同日看」（独立互证） |
| 所锚对象 | **二十四山空间方位**（坐山/向/方），不锚任何人的命柱。三煞在时间上的层级（岁/月/日时）表达为"占方/占山"，陈子性页892「**月日時三殺占方**」、协纪卷10「岁三煞与岁破同凶而可以吉制，**月三煞义本相通**」 |
| 语域 | 兴造修方、造葬坐向（事×方）；协纪卷11 铺注月劫煞/灾煞为**日神**（事×日） |
| 轻重 | 唯一坐标是**空间**：「在坐则重而难制，在向在方则轻而可降」「太岁可坐不可向，三煞可向不可坐」（协纪卷34、宗镜集卷十二、选择求真卷九同文） |
| 制化 | 占坐山造葬**不可制**（「坐三煞向太岁，此不能制者也」「惟岁煞不可犯」）；占方/向可制但"不易制，不可轻犯"——三合局胜之、三合得令/煞休囚之月、本命贵人禄马/八节三奇/日月照临；**天月德四德"俱走天干不走地支，不能制地支方煞"**（协纪卷34馆臣按） |
| 课式四柱的角色 | 四柱（所择日课的年月日时）是**制煞工具与被检课体**：「以四柱制化之」「必俟凶方休囚之月而以八字克制之」（协纪卷33、宗镜集卷五）；陈书页478「坐三殺忌巳酉丑四柱」、页514/550「坐三殺忌申子辰（亥卯未）四柱」——课四柱会齐坐山煞方三合局为"坐殺"，**仍是课体对方位的关系，不是对事主命柱** |

### 1.2 概念二：本命岁煞（天罡四煞——相主层唯一桥梁条）

| 要素 | 典据内容 |
|---|---|
| 定义 | 「**本命煞惟天罡四煞最凶，造葬皆忌。天罡四煞即岁煞也，修忌宅长，葬忌化命及祭主，吉不能制。**寅午戌生人属火，忌於丑**年月日时**内作甲乙庚辛四向凶【……犯一个丑字亦凶】；申子辰年生人……未；巳酉丑……辰；亥卯未……戌」（协纪卷33 利用一·论相主） |
| 煞锚（起点） | **事主本命生年三合局的岁煞一位**：寅午戌生人→丑、申子辰→未、巳酉丑→辰、亥卯未→戌（注意：只取"岁煞"墓库支，非劫灾岁三支） |
| 所锚对象 | **所择课式四柱的年月日时支**（出现煞支）＋四向条件（甲乙庚辛等，后世仙命通书多作"四山"，异文）；主体区分：修造取**宅长**、葬取**化命及祭主** |
| 语域 | 相主（人×课），独立于方位兴造 |
| 轻重/制化 | 四柱并列、**柱柱皆忌**、「犯一个丑字亦凶」、**「吉不能制」**；传本夹注自相张力（"非此四向则犯丑字不忌" vs "犯一个丑字亦凶"），馆臣保留未改 |
| 方向 | **本命生年局 → 反查课式四柱**（与软件"太岁年三煞方→事主分柱"的设想方向相反，详见 §4） |
| 典据分布（穷尽） | **此命题四书仅协纪卷33 一条**：考原"天罡四杀"是月家兵禁凶日（§2.1）；宗镜集"天罡四煞"精确词 **0**、岁煞×生人 ±60 字共现 **0**；陈子性"天罡四煞"精确词 **0**（45 处"天罡"无一此义，§2.1）。即该桥梁条在高优先级典据中为**孤例单传**（协纪馆臣未注明出处，属通书旧义收录） |

### 1.3 概念三：命理劫煞（命造层，表外旁证）

| 要素 | 典据内容 |
|---|---|
| 定义 | 命理学神煞，亡神劫煞从**命造本人**生年（或日）三合局起：「申子辰年月日时，劫煞在巳，灾煞在午，岁煞在未」（三命通会卷三·亡神劫煞） |
| 煞锚 | 命造生年/日三合局 |
| 所锚对象 | **命造自己的四柱分布**：「日煞克妻，时煞克子」；分劫（散）反轻、聚劫反重——论的是克身与六亲 |
| 语域 | 命理推命，**非选择兴造**；无"与坐山比较"句，无"月柱重"分级 |
| 四书情况 | 选择四书无此语域：宗镜集"亡神"4 处经核全为**出行日家神煞**（卷九亡神煞/卷十一六辛方为亡神），非命理亡神（§2.4） |

## 2. 同名异物与术语负证据（Q3，四书穷尽）

### 2.1 「天罡」一词在典籍中的六个所指（四书 258 处逐条归类）

| # | 所指 | 出处样例 | 与三煞关系 |
|---|---|---|---|
| a | **十二辰/十二将名**：辰曰天罡（与河魁=戌对） | 协纪卷2「辰曰天罡」；走马六壬十二月将"天罡乙辰"（协纪卷35、陈书页362-402、1054） | 无关，辰位别名 |
| b | **月内凶神（丛辰）**：月建前三辰为天罡、后三辰为河魁，所值日百事忌 | 协纪卷4引桑道茂/历例；考原卷4同；陈书页149/157/775/793/817/818 | 月家日禁，非本命岁煞 |
| c | **六壬/雷霆式盘星名**：天罡为十二将星之一（与月孛/奇罗/水潦并列），用于天罡加建、雷霆日家取时 | 协纪卷5「以天罡加於建上」；陈书页324-338/608/610/615/831 | 式法工具星 |
| d | **兵禁凶日"天罡四煞（杀）"**：六月辰为天罡四杀（四季四煞之一） | 协纪卷5「六月辰天罡四煞也」；考原卷4同句 | **与本命岁煞同名的另一神煞**（月家兵禁） |
| e | **本命岁煞"天罡四煞"**：协纪卷33 桥梁条 | 协纪卷33（§1.2） | 概念二（仅此 1 处） |
| f | **"天罡四旺煞"**：修方坐宫煞，紫白不能制（与大月建并列） | 协纪卷34引桑道茂/一行「紫白所到之方……惟不能制天罡四旺煞而已」 | 形近第三物，**非天罡四煞**，属坐山/方凶煞层 |

> 结论：仅协纪一书，"天罡四煞"四字就有 d/e 两义，另加 f 形近第三物；
> 宗镜集、考原、陈书均无 e 义。正名后引用必须带卷次语境，不得只引词名。

## 4. 正名结论与错位清单（Q1–Q3 判定）

### 4.1 Q1：三个概念成立，且边界清晰

典据中方位三煞（含岁/月/日时时间层级）、本命岁煞（天罡四煞，协纪
孤例）、命理劫煞（三命通会）是**煞锚不同、对象不同、语域不同**的
三套东西（§1.4 总表）。同一"煞"字不构成同一命题，正名必须分轨。

### 4.2 Q2/Q3：软件现行实现存在三处命名/概念错位（只陈述事实，不动代码）

**错位 1（最关键）："年三煞(月柱/日柱/时柱)"的月/日/时柱是课式柱，
不是事主出生柱。**
- 证据：`_get_sansha_info(sizhu, …)` 的 sizhu 是所择日课四柱
  （[评分器.py L3754](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L3754)）；
  全仓 owner_sizhu（事主出生四柱）的消费点只取 year_zhi/year_gan
  （冲命、婚嫁生肖/本命三煞）、day_zhi（相主日支冲合，
  [评分器.py L3637-L3655](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L3637-L3655)），
  嫁娶另有 owner 月柱用于阴胎/阳气
  （[嫁娶规则.py L351/L755/L763](file:///d:/自编择日软件/专业级正五行择日软件/modules/rules/嫁娶规则.py#L351)），
  **没有任何"事主出生月/时柱 × 年三煞"比对代码**。
- 开发注释自证：[评分器.py L1942](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L1942)
  「月**建**临年三煞方主一月不利」——月柱即**月建**（课式月柱）。
- 含义：月柱 4,319 条的典据真身是「**年三煞占课式月建**」（概念一
  的时间层级），其典据对应物在四书**有载**：协纪卷10「三煞占月」
  「月三煞义本相通」、陈书页892「月日時三殺占方」、宗镜集卷十二
  「月日同」。姊妹文档四书穷尽的命题"年三煞临**事主（出生）月柱**"
  在典籍 0 载、**在代码中同样 0 实现**——是"事主中心（四柱论命）"
  注释（L1917/L1945）与"年三煞(月柱)"文案造成的命名投影，非软件
  真实行为。

**错位 2："事主中心 vs 山向中心"开关的实质是事项类型差异，不是
命柱 vs 山向。**
- 同一课式事实（年三煞占课月建）在修造葬类（mountain_center）扣分
  不否决（§63 三煞D），在嫁娶/订婚/纳采类置否决
  （[评分器.py L1367-L1377、L1946-L1951](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L1367-L1377)）。
- 即用户 2026-10-10 指出的"三档逻辑不一致"，其真实结构不是
  "月柱保守/日时柱激进"，而是"**同一课式占月命题，按事项类型走
  两套处置**"。事项差异有无典据依据 = B-b 的 Q5。

**错位 3：婚嫁本命三煞方向正确但制化口径与典据相反。**
- 煞锚（新娘生年局）→ 日辰的方向与天罡四煞同向（概念二）；
  五行择日法"年命真三煞"只取岁煞一位，更是与典据同构。

  L1059-L1079）在四书无载，且天/月德解地支煞与协纪卷34馆臣按
  「四德……不能制地支方煞」、卷33 天罡四煞「吉不能制」**直接冲突**。
