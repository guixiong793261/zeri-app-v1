## 第一篇 典据主锚与研究方法论

### 1.1 三库主锚原则

| 典籍 | 角色 | 说明 |
| --- | --- | --- |
| 《协纪辨方书》 | **主锚** | 钦定类书，凡三库分歧以协纪为准 |
| 《星历考原》 | **互校** | 协纪的直接前身，逐字对勘零分歧即"双锚确认" |
| 《陈子性藏书》（陈书） | **第三参照** | 民间通书代表，仅作旁证；协纪"辨讹"判伪时为反面参照 |

**铁律**：
- **协纪主锚不可动摇**。任何"陈书有载而协纪无载"的神煞，不得作为主链路计分依据。
- **三库一致性 > 单库孤例**。协纪、考原、陈书三库同时有载的规则优先采信；仅一库有载者须标注"孤例"。
- **辨讹钦定判伪优先**。协纪卷三十六"辨讹"对神煞的真伪裁定效力最高（如吉庆被钦定判伪 → 全删）。

### 1.2 无证据不放宽

这是贯穿全程的第一红线：

> **无典据明文支撑的规则，一律不得主动放宽；有典据明文否定的规则，必须撤销或降级。**

- **无据 ≠ 必须撤档**，但必须**透明标注**（如占柱层三煞、事项维度被认定为"现代工程构造"，维持现状但标注"无据"）。
- **有典据否定 > 无据**。如嫁娶×三煞被协纪批"其义不伦"，强度高于单纯无据。
- **禁止自动延伸**。制化神煞的适用范围、吉凶方的权重封顶，凡典据未明言的延伸一律禁止（如德神集仅限天德/月德/天德合/月德合/天赦/天愿六神，不得自动加入天恩）。

### 1.3 研究方法论（可复用模板）

源自三煞典据研究（`B-b三煞典据研究_元总结.md`），已复用于所有"名实不符"核查：

| 方法 | 内容 |
| --- | --- |
| **先冻后取** | 判据冻结 → 用户拍板 → 取证 → 成稿 → 停止待拍板；未确认前不检索不改码 |
| **引用链自查** | 直接引文最小片段 → 全语料复搜 → 命中书源核对；未通过者独立成档 |
| **语境三值** | 每条命中标注"占方/占柱/未区分"＋判定依据；>80% 未区分单独成节 |
| **穷尽声明** | 已取得全文 / 未取得 / 0 命中三态明示；0 命中须附检索过的典籍清单 |
| **预登记** | 判定标准/终态分类/跨命题引用禁令事前冻结，防事后合理化 |
| **反向检查** | 不只在框架内找证据，反向查"框架维度本身在古籍是否存在" |
| **预扫** | 完整取证前 15 分钟低成本共现扫描，先判有无迹象再定深度 |
| **孤例研究范式** | 单条精细解读＋词族四书扫（穷尽性确认非判定主证）＋源流链 |

### 1.4 三煞三层框架（Q7 定稿）

三煞研究确立的"空间×工法"二维框架，是所有神煞分层的参照系：

| 层 | 煞锚 | 体系 | 制化 | 典据 |
| --- | --- | --- | --- | --- |
| 本命层 | 生年 | 婚嫁本命三煞＋造葬天罡四煞，同层不同源并列 | **不制** | 陈书／协纪·宗镜 |
| 占方层 | 方位 | 统一忌（无事项分级） | **可制**（占山决不可、惟占方可制而修） | 协纪·宗镜·陈书 |
| 占柱层 | 课式柱 | 上管下三层递查＋severity＋梯度 | — | **无据** → 工程约定类 |

**关键发现**：古籍三煞仅两个差异化维度——**空间层级**（坐/向/方）与**工法层级**（葬/造、单修/连修）。"事项×三煞"维度在古籍**不存在**（卷十一用事卷约 70 事目三煞 0 命中），属现代工程构造。

## 第二篇 神煞五层验证体系

### 2.1 五层定义

每个神煞必须通过五层验证，任一层缺失即登记为 ⚠️ 或 ⬜：

| 层 | 含义 | 验证标准 |
| --- | --- | --- |
| **表源层** | 起例表与典籍一致，全项目唯一正表 | 协纪主锚/考原互校/陈书第三参照 |
| **触发层** | 给定日期正确判定是否触发 | 12 月建×12 日支全遍历或锚点穷举 |
| **口径层** | 所忌事项范围与典籍宜忌/用事卷一致 | 白名单制，白名单外标注"待证" |
| **轻重层** | 扣分/否决力度有典据支撑 | 忌/大忌/不宜/否决分层登记 |
| **制化层** | 制化神煞是否成立、是否适用有典据明载 | 不可自动延伸 |

状态符号：✅ 已验证 ｜ ⚠️ 部分/有挂账 ｜ ⬜ 未验证 ｜ — 不适用。详见 [神煞五层验证体系_总表.md](神煞五层验证体系_总表.md)。

### 2.2 优先级

月家凶煞（土类/月破/月厌/大煞等）> 日家吉神（天德/月德等）> 年家神煞 > 复合规则。

### 2.3 定级标准（P0–P3）

| 级 | 含义 | 处置 |
| --- | --- | --- |
| **P0** | 致死/跨模块一致性级 | 立即修（如坏 import 静默按公历、批量补同步守门） |
| **P1** | 功能缺陷/重要裁决级 | 排期修或独立任务 |
| **P2** | 核查/验证级 | 批次间执行 |
| **P3** | 已知限制/观察级 | 不单独立项，登记备忘；触及所属文件时顺带处理 |

**降级默认原则**：定级不确定时默认降入较低级（P3 侧）登记。

## 第五篇 架构与工程红线

### 5.1 双族计分去重（H1）

同一神煞不得在"神煞通道"与"建除/宜忌通道"重复计分。双族同场计分须有明确的去重门控。

### 5.2 三层验证体系

所有神煞修表必须配套：表源修正 → 触发穷举 → 口径白名单 → 轻重裁断 → 制化核查。任一层缺失不得合入主干。

### 5.3 副本体系

| 表述 | 含义 | 校验时机 |
| --- | --- | --- |
| **3 内层** | 主仓三层（仓根 / `手机一键部署/` / `手机一键部署/模块完整版/`），必须逐字节一致 | 日常改码后立即校验（`check_six_copies.py --main`） |
| **1 统一版仓** | `d:\自编择日软件\专业择日大师_统一版\专业级正五行择日软件_v1.0`，快照仓，允许暂时漂移 | 发布前/主仓连续 3 批无变更/累积漂移 100 件时启动收敛 |

**禁止零散镜像**：统一版仓收敛须整批进行，逐件归因（统一版专属改动不得被覆盖）。

### 5.4 测试基建

- **统一入口**：`tests/run_all.py` 自动发现并子进程执行 `verify_*.py` / `test_*.py` / `check_*.py`，输出 PASS/FAIL/TIMEOUT 汇总，退出码 0/1/2，支持 `--json`；非前缀脚本（如大考探针）由 `EXTRA_SCRIPTS` 显式托管。
- **回归基线**：**134/134 全绿**为发布门槛（131 历史基线 + 2 个 §214 verify + 大考探针托管）。
- **黄金课哨兵**：`test_huangdao_truth.py` 的 35 项断言为评分行为的最终防线，改动评分口径必须同步重冻断言。
- **副本感知**：涉及主程序/评分器/贴类读数的脚本须追加 3 内层 SHA 断言。

### 5.5 事项通道注记

- **移徙事项经入宅通道发射**：`canonical_event('移徙')='入宅'`，移徙专属键休眠。
- **出行通道**：`_is_travel_event` 门控所有坐山类判定（三煞/向方/正体五行/坐山评分），`shan_xiang` 仅作"出发方向"语义。

### 5.6 精准择时反推引擎（§210）

由「正向评一天」升级为「反向找最优时段」。核心契约：

| 模块 | 职责 |
| --- | --- |
| `modules/反推引擎.py` | `search_top_n(...)` 范围扫描 → `meta/all_days/days/vetoed`；逐日 12 时辰实评后择优 |
| `modules/排序键.py` | **排序唯一事实源**：`hour_rank_key` / `classify_day` / `rank_day`；`CAUTION_DEDUCT_THRESHOLD=-20` 界定「慎用」 |
| `modules/反推UI.py` | 三层视图：热力日历 / Top-N 列表 / 最优时间轴；上下文回显、山向校验、双击详情、一键加帖 |

**红线条目**：

1. **候选零伪造**：全范围无可用日时 `days=[]`，不得用低分日凑榜；UI 必须弹窗+红字明示（§214 S3-2）。
2. **排序不降权**：收录层单调，慎用日不提前出榜（`rank_day` 单点实现，禁止在 UI 层二次排序）。
3. **零基漂移**：榜单入选集合与排序口径变更须单独批次 + 全年对拍。

### 5.7 动作时序编排（§213）

把「一日」细化为「一天的动作序列」，并与红帖联动：

| 项 | 内容 |
| --- | --- |
| 纯函数层 | `modules/动作时序.py::plan_actions(...)` → `status ∈ full/partial/insufficient/none`，含 `missing/checks/alt` |
| 嫁娶序列 | `ACTION_SEQUENCES` 三段：「起轿·发轿」「迎娶·进门」「交拜·合卺」 |
| 状态语义 | `full` 三段均有吉时；`partial` 有缺段（必须在动作轴显式黄标）；`insufficient` 仅 1 段；`none` 无 |

### 5.8 红纸帖三态分流（§205 / §214）

`modules/择日贴.py::prepare_entry` 是帖型分流的唯一入口：

| 帖型 | 触发 | 版式要点 |

## 第六篇 维护操作手册

### 6.1 日常改码流程

1. **判据冻结**：先在 docs 写判据冻结提案，用户拍板后再改码。
2. **改码 + 重冻断言**：评分口径变更必须同步 `test_huangdao_truth.py` 断言。
3. **副本同步**：`check_six_copies.py --main` 确认 3 内层 SHA 一致。
4. **回归**：`python tests/run_all.py --json <out.json>`，必须 **134/134 PASS**；发布前另跑大考探针（42 项）。
5. **记账**：001 新增章节记录批次、commit、影响面。
6. **分批 commit**：旧账清理 / 新规落地 / UI / 回归+快照+记账 分独立 commit。

### 6.2 神煞修表标准动作

1. 三库取证（协纪主锚 + 考原互校 + 陈书旁证）。
2. 模块级权威表 + 单点出口函数（`is_xxx_by_zhi` 模式）。
3. 子类同名重加死链删除留墓碑。
4. `verify_xxx.py` 硬锁穷举。
5. 影响面快照（全量 dump 旧 vs 新）。
6. 五层总表回填。

### 6.3 制化落地标准动作

1. 引用制化矩阵行号锚（#1–#17）。
2. 德神封闭集 + 禁并排除对 + 止忌映射表配置化。
3. 同键豁免防死链复活（发射点多处同键）。
4. 全年探针零触发验证（Δ=0）。

### 6.4 副本收敛标准动作（统一版仓）

1. 对账：`check_six_copies.py`（6 份）→ 导出漂移清单。
2. 归因：逐件判定（本批改动 / 历史遗留 / 统一版专属改动），专属改动须先回报用户。
3. 镜像：整批镜像主仓 → 统一版仓。
4. 验证：6 份 SHA 全一致 + `py_compile` 全量 + 统一版仓冒烟。
5. 记账：001 新增条目。
6. commit：主仓与统一版仓分别独立 commit。

### 6.5 常见陷阱速查

| 陷阱 | 表现 | 防范 |
| --- | --- | --- |
| **死链复活** | 活链排除后，子类同名死链成为唯一发射 | 活链排除/删除前必须同步处理死链 |
| **动态派发污染** | 基类 `self._is_xxx` 经 MRO 解析至子类 override | 收敛为基类单点出口，子类 override 删除留墓碑 |
| **名实错制度化** | docstring 自录口诀三库无载 | 修表时同步删除错误 docstring |
| **异名双扣** | 同一神煞两个注册名各扣一次 | 起例归宗后双注册收敛为单口径 |
| **方神误作日辰神** | 方位神（岁破/太岁/飞廉）被注册为日辰神 | 卷四按语"历家特误以年方配日辰耳"为统一判据 |
| **无据自动延伸** | 制化神/宜忌范围超出典据明文 | 德神集仅限六神；宜忌白名单外标注"待证" |
