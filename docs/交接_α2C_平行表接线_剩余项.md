## 二、关键机制（新会话必须知道）

1. **`_add_shensha` 的 score 参数是查表 fallback**：`shensha_score(event, name, default)`
   查 `(canonical,name)`→`('*',name)`→返回 default（=发射分）。**事项标准未配键的
   神煞，发射分非 0 会对全部 15 事项生效**（除神初版发射分 8 曾致 2021-12-03 修造
   36→41 漂移）。⇒ **新神煞发射分一律 0，分值全走事项标准显式键**。
2. **事项全集 15 项**：`*、作灶、修造、入学、入宅、出行、动土、嫁娶、安床、安葬、
   开业、拆舍、求医、移徙、签约`——**无破土/启攒/解除/祈福类目**，配键不得编造事项名。
3. **五副本同步**：神煞基类.py ×5（modules/shensha、手机一键部署/modules/shensha、
   手机一键部署/模块完整版/modules/shensha、手机一键部署/modules、
   手机一键部署/模块完整版/modules）；事项标准.py ×3（modules、
   手机一键部署/modules、手机一键部署/模块完整版/modules）。
   patch 脚本放 C:\Temp 不进 commit，带幂等 SKIP。
4. **验证模板**：`tests/verify_shengxin.py` / `verify_yangcuo.py`（真值表硬编码 +
   sxtwl 独立推导穷举 2025-2027 + 分值锁 + 非目标事项反断言 + 黄金日干支硬锁）。
5. **sxtwl 陷阱**：GZ 对象天干属性是 `tg`（无 `dg`）；月支用节气推导
   （verify_shengxin 的 `_month_zhi_at` 同构），勿用粗月柱。
6. **敏感基准日 2021-12-03（乙酉亥月）**：unittest 基准（圣心+8 已入基准；
   乙酉=除神日发射分 0 不漂移）。
