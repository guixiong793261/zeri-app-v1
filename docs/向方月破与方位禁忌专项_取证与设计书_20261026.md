## 一、子项 ① ②：向方月破（专项核心）

### 1.1 典据原文（逐字核读，含卷页）
- **协纪 279252:163**（月建/月破条按语）：「月建可坐不可向 **月破可向不可坐** 与 太岁岁破同 岁尊而月亲也 通书建破论日而不论方 大小月建论飞宫而不论定位 殊失其旨」
- **协纪 279252:34**（月破条）：「**月破山方皆凶 坐山尤凶** 造葬皆不可犯」
- **考原 359080:42**（月建十二神条）：「建为岁君……可坐不可向……**破为岁破 为大耗 大凶**」
- **考原 359079:43-44**（月破条，日课域）：「月破者 月建所冲之日也 与岁破义同」

### 1.2 语境判定
「月破可向不可坐」「月破山方皆凶坐山尤凶」共同说明：**坐山犯月破最重（一票否决）**；**向方犯月破损一级**（可作"可向"维度，然非无咎——"山方皆凶"含向方）。故向方月破**并非无载（否）**，而是**有载但严重度低于坐山**。此正回答立项书疑点①：向方月破是"另一权重维度"，非简单可修则可坐。

### 1.3 软件现状 → 五档
- 坐山月破：Layer1.1 一票否决（二十四山择吉天机.py L5722-5735），**✅ 全等**。
- **向方月破：全仓零注册，❌ 缺失断层**（三库有载、软件未接）。
- 触发规律（互为对冲，不双计）：以「壬山丙向」样本——坐山壬、向方丙午；月支子冲午→**子月子**仅命中向方丙午月破；月支午冲子→仅命中坐山壬。同一月支只在一侧命中，补全向方后无叠计风险（天然互斥）。

### 1.4 设计候选（待拍板，不改码）
- **候选 A（镜像坐山通道）**：新增「向方月破」shensha/规则键，分值承坐山月破降档（坐山一票否决 → 向 v1 建议重扣分档，如 -20/-25，具体权重待拍板），复用同一月建所冲方位判定。
- **候选 B（并入山家三煞坐向通道）**：向方月破沿用'山家三煞'已有的坐/向分离通道（形态同构，权重复用），避免另起新通道。

- **协纪卷三**：「太岁所在之辰，必不可犯」

### 2.3 五档与设计候选（待拍板）
- **⚠️ 语义等价**：软件有"太岁方位 -10 出行"之注册缘起，但谓词死锁；协纪有"太岁可坐不可向"明文，支撑"太岁方位"作为方位禁忌有载。
- **死链不擅自复活（红线）**：本批不改码。复活与否依赖如下待拍板口径：

  - 结论交由报告拍板，本期只给候选。
