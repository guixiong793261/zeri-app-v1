## 1. 三分钟上手

**最短路径（出一张吉日红帖）**

1. 事项类型选「嫁娶」（默认）。
2. 填开始/结束日期。
3. 点「开始择日」。
4. 在结果表里挑评分最高、等级最高的一行，双击看详情。
5. 点「择日贴」→ 选日期与时辰 → 预览 → 打印或发手机。

> 提示：不填事主信息也能出结果，但**相主（生肖冲、日柱冲刑）不会参与计算**，重要事项建议填全。

## 3. 输入参数逐项说明

### 3.1 事项类型（16 个下拉项）

| 下拉项 | 归入规范事项 | 是否需要坐山 | 说明 |
| --- | --- | --- | --- |
| 嫁娶 / 订婚 / 纳采 | 嫁娶 | 否 | 事主中心，男女命平权 |
| 修造 | 修造 | **是** | 坐山三煞、扶山补龙 |
| 动土 | 动土 | **是** | 破土类，重土府/土王 |
| 拆舍 | 拆舍 | **是** | 拆除类，宜忌收窄 |
| 入宅 / 移徙 | 入宅 | 是（向首） | 受死日、红嘴朱雀、年命冲大门 |
| 开业 | 开业 | 否 | 已旁路三煞月柱否决 |
| 出行 | 出行 | **否（禁止填坐山）** | 看出发方向，不看坐山 |
| 安床 | 安床 | 否 | 看床位朝向 |
| 作灶 | 作灶 | 否 | 灶向、灶位、主事人 |
| 安葬 | 安葬 | **必选** | 仙命、旺命、重丧、四大凶日 |
| 入学 / 求医 / 签约 | 通用 | 否 | 走通用检查器 |

> 关键差别：**出行不看坐山**；**安葬必须选坐山**；其余坐山事项只影响山家相关分项。

### 3.2 日期与时间

- 开始/结束日期决定扫描区间，区间内**每一天**独立评分。
- 时辰用于单日精算与红帖；区间扫描默认取推荐时柱（系统择定），详情里会注明。

### 3.3 宅型与山向

| 字段 | 取值 | 适用事项 |
| --- | --- | --- |
| 宅型 | 阳宅 / 阴宅 | 修造、动土、拆舍、入宅 |
| 山向 | 二十四山（如「坤山艮向」） | 同上 |
| 兼向 | 正中 / 兼左 / 兼右 | 同上，影响分金 |
| 坐山 | 二十四山单字（如「坤」） | 修造、安葬等 |
| 罗盘 | 弹窗点选 | 不确定山向时 |

> 填错坐山会直接改变三煞、扶山、分金的结论，**比填错日期更严重**。

### 3.4 事主信息

- 每个方案可填：姓名、性别、公历/农历、出生年月日（时辰可选）。
- 只填姓名不填生日：该事主**不参与相主计算**，结果照常出。
- 多个事主：系统按「平权」逐人校验，取**最严**结论（详见白皮书第四部分）。

### 3.5 输出模式

| 模式 | 结果表表现 | 用途 |
| --- | --- | --- |
| 正常平分（含扣分） | 显示总分与各分项，凶日保留 | 日常挑选 |
| 不合格输出（仅显示否决/凶日） | 「核心吉神」列改为「不合格原因」 | 复盘“为什么这天被否” |

> 配图 3-1：两种输出模式的对照截图（同一天、同一事项）

### 3.6 结果表的 12 列

| 列 | 含义 | 读法 |
| --- | --- | --- |
| 日期/四柱 | 公历 + 年/月/日/时四柱两行 | 先看四柱是否与事主相冲 |
| 评分 | 综合总分 | 排序主键 |
| 等级 | ★ 档位或「❌ 凶」 | 一票否决会归零 |
| 五行得分 / 月令 / 喜用 / 黄道 | 分项分 | 定位“分从哪来” |
| 地支关系 | 四柱内的合冲刑害（前 2 条） | 看合局与刑冲 |
| 核心吉神 | 命局贵人 + ≥10 分高权重神煞，最多 4 个 | **悬停出完整列表** |
| 利月 | 嫁娶利月标记 | 嫁娶专用 |
| 事主信息 | 参与计算的事主摘要 | 核对是否漏填 |
| 玄空 | 飞星信息（开启时） | 可选 |

`核心吉神` 列的口径：命局贵人（天乙/文昌等）在前，其后按神煞分值降序；≤5 分的点缀型杂神不显示；被截断时列尾有「…」，鼠标悬停弹出「命局贵人」与「神煞吉神（≥10分）」两段完整列表。

## 4. 开始择日与读结果

1. 选事项 → 填区间 → 需要时填山向/事主 → 点「开始择日」。
2. 结果按评分从高到低排序，星级色带区分。
3. 先看**等级**，再看**评分**，最后看分项是否异常（例如五行分很高但黄道 -10）。
4. 双击一行打开日课详情。
5. 需要复核时点「日课评分」把该课带入评分系统。

**读表三条经验**

- 总分高 ≠ 能用：先看等级是否「❌ 凶」、忌项是否有硬门槛。
- 分项为 0 不一定是漏算：可能是当天未触发（如喜用神需事主八字才计）。
- 三煞扣分不否决：月/日三煞柱级是扣分，年三煞犯山向才否决。

## 6. 精准择时（反推）

> 配图 6-1：精准择时窗口（条件区 + 榜单 + 动作时序）

1. 点「精准择时」打开反推面板。
2. 设条件：事项、时间窗、事主、山向/方向（按事项出现）。
3. 生成榜单（Top-N），每行含：日期、评分、等级、推荐时柱、**慎用**标记、入选理由。
4. 展开「动作时序」：如嫁娶的发轿/进门时刻编排。
5. 点「带入红帖」把选中日带入择日贴。

**三个概念**

- **慎用日**：有微瑕但仍在榜，红帖会加黄底警示。
- **全否**：窗口内无可用户外日，榜单为空或全为凶。
- **推荐时柱**：系统择定的最优时辰，可在详情里用十二时辰表复核。

嫁娶民俗时段为**软加权**（不硬排除）：发轿优先辰/巳时（8–11 点），进门优先未/申时（13–16 点），命中者排序加分。

## 7. 红纸帖生成与三态

| 态 | 触发条件 | 牌面 | 注意事项区 |
| --- | --- | --- | --- |
| 吉帖 | 等级为吉且无凶 | 红底吉帖 | 常规宜忌 |

## 9. 完整实战示例

**需求**：2025 年 10 月修造，坤山艮向兼未，用未时。

1. 事项「修造」→ 填区间 → 宅型阳宅 → 山向「坤山艮向」→ 兼向「兼左/兼右（未）」。
2. 开始择日，定位 2025-10-28（农历九月初八）。
3. 读结果：纯正五行评分 **288**，等级 **★★★★★ 上吉**（若启用「正五行+玄空飞星」加权，则综合 **218**）。
4. 双击详情，核对公式：

```text
五行评分 307 + 月令 10 + 喜用 0 + 黄道 -10 + 三煞 -19 = 288
三煞构成：年三煞(向方) -10、月三煞(向方) -6、日三煞(向方) -3
```

5. 看「核心吉神」列：天乙贵人、岁德、日贵人时、时与坐山三合…（悬停可见 11 项）。
6. 看修造段：扶山 +5、补龙 +8、山家六合 +12、山家贵人 +10；时辰吉凶里癸未时 +15 为推荐。
7. 生成红帖。

> 要点：这天总分 288 却仍为上吉，是因为山家吉神与时辰吉神把扣分拉了回来；**三煞是“方道扣分”而非整日否决**。

## 10. 常见问题（FAQ）

| 问题 | 答案 |
| --- | --- |
| 为什么吉神显示不全？ | 结果表只显示命局贵人 + ≥10 分高权重神煞，最多 4 个；悬停看完整列表，详情页看全量 |
| 为什么总分与五行评分不同？ | 五行评分是子分；总分 = 五行 + 月令 + 喜用 + 相主 + 黄道 + 太阳太阴 + 三煞 + 向方 + 出行/坐山等 |
| 为什么三煞扣了 60 分还不判凶？ | 月/日三煞柱级是扣分；只有年三煞犯山向等硬门槛才否决 |
| 为什么填了山向，出行分数没变？ | 出行不看坐山，只看出发方向；填坐山不参与计算 |
| 为什么有吉神仍判凶？ | 硬门槛优先（三煞山向、山家封禁、相主冲命、受死日等），吉神不能抵硬否决 |

| 为什么「日课校验」有「跳过」？ | 跳过表示该规则不适用于当前路径（如非嫁娶），不是失败 |
| 红帖为什么拒绝生成？ | 时辰冲关键事主命，属红线拒绝，换时辰即可 |
| 不填生日会怎样？ | 该事主不参与相主；结果仍出，但少了冲命校验 |
| 玄空飞星为什么不显示？ | 当前为纯正五行模式；切换到「正五行+玄空飞星」 |

# 第二篇 · 历法基石（第 7–10 章）

## 第 7 章 时间基准：真太阳时与晚子时

### 7.1 三层时间

| 层 | 含义 | 实现 |
| --- | --- | --- |
| ① 民用时间 | 用户输入的年月日时分 | UI 输入 |
| ② 真太阳时 | 经度修正 + 均时差 | `modules/真太阳时.py`：基准东经 120°，每偏离 1° 修正 4 分钟，叠加 NOAA 均时差 EoT |
| ③ 命理时间 | 用于定四柱的时辰 | 修正后的时、分（秒归零） |

口径要点（001 §43.9 / §48）：

1. 未填经度或经度 = 120.0 时**不启用**真太阳时。
2. 修正粒度为**分钟**，秒一律归零，避免伪精度。
3. 顺序是「先修正、后判 23 点边界」——真太阳时结果流入晚子时判定与交节比较。

### 7.2 晚子时派（23:00–23:59）

- **日柱**：晚子时**不进次日**，仍用当日日柱。
- **时支**：子。
- **时干**：按**当日日干**五鼠遁推出（不使用 sxtwl 的次日口径）。
- 依据：《三命通会》“子时上半属昨日、下半属今日”，《新唐书·历志》。
- 与 sxtwl 的差异属**派别差异**，本软件固定采用晚子时派，不在运行期切换。

### 7.3 边界案例

| 案例 | 结论 |
| --- | --- |
| 23:00 整 | 属晚子时，日柱当日、时柱子时（当日日干遁） |
| 00:00 | 次日子时（早子时），日柱进次日 |
| 经度修正后跨 23 点 | 以**修正后**时刻判晚子时 |
| 交节时刻 ±1 分钟 | 以精确节气时刻比较，跨过即换月柱 |

## 第 8 章 节气与四柱排盘

### 8.1 年柱：立春换年

- 取当年立春**精确时刻**；早于立春用上一年年柱，晚于用下一年年柱。
- 不以农历正月初一换年。

### 8.2 月柱：十二节定月

| 节 | 月建 | 节 | 月建 |
| --- | --- | --- | --- |
| 立春 | 寅 | 立秋 | 申 |
| 惊蛰 | 卯 | 白露 | 酉 |
| 清明 | 辰 | 寒露 | 戌 |
| 立夏 | 巳 | 立冬 | 亥 |
| 芒种 | 午 | 大雪 | 子 |
| 小暑 | 未 | 小寒 | 丑 |

- 算法取「节」（非「气」）时刻比较；位于立春前时补前一年小寒，落到子月区间。
- 月干由年干五虎遁推出。

### 8.3 日柱与时柱

- 日柱按公历日期推算，晚子时不进次日（见 7.2）。
- 时柱：时支按两小时一段；时干五鼠遁。

### 8.4 派生字段

| 藏干 | 旺衰与十神判断 |
| 十二长生 | 日干在各柱地支的长生旺衰（见 12.2） |

### 8.5 农历与闰月

- 公历/农历双输入；闰月按实际月建换算，不按“闰月算下月”简化。

## 第 9 章 方位体系与三煞三层框架

### 9.1 二十四山、兼向、分金

- 二十四山：8 干 + 12 支 + 4 维。
- 兼向：正中 / 兼左 / 兼右；分金按度数落位，分金五行与正体五行分别参评（分金等级「平」不改变整日等级）。
- 三煞判断以**坐山/修方**为主，向首按各层规则另计。

### 9.2 三煞三层矩阵（现行口径）

| 层 | 论坐山/修方 | 论向首 | 论日/时柱临方 | 否决权 |
| --- | --- | --- | --- | --- |
| 年三煞 | 犯 → **一票否决** | 犯 → 扣 **-10** | **不判**（四柱级全面旁路，001 §211 案 B） | 仅山向否决 |
| 月三煞 | 犯 → 扣 **-20**，不否决（§63） | 犯 → 扣 **-6** | 日柱临方 -20 / 时柱临方 -15（柱级扣分不否决，§64 B3） | 无 |
| 日三煞 | 犯 → 扣 **-15**，不否决 | 犯 → 扣 **-3** | 时柱临方 -10（柱级扣分不否决） | 无 |

**为什么年三煞不判月柱**：三库无「月柱临煞则凶」明文，属把**方位神**当作**日辰神**串用；年三煞的成立面是“山向”，不是四柱干支。故四柱级通道整体旁路，但保留识别展示（墓碑保留说明，001 §211）。

**“可向不可坐”**：三煞为方道神，占山/修方/坐向忌；向首按上表扣分口径处理，不因“可向”而完全免检。

### 9.3 太岁、岁破、月破、暗建

| 项 | 属性 | 现行处理 |
| --- | --- | --- |
| 太岁 | 方位神（年支） | 方位忌；日辰“太岁日”注册已删除（001 §139 系列） |
| 岁破 | 方位神（冲太岁方） | 方位忌；“日课普适岁破日”否决已删除（001 §140） |
| 月破 | 月支冲日支 | 日课凶煞，按月/事项决定扣分或否决 |
| 暗建 | 月建对冲方的十二建隐藏煞 | 方位扣分（示例 -15） |

### 9.4 玄空飞星（可选，仅 feixing 模式）

- 界面默认 `pure`（纯正五行）模式：玄空飞星不参与评分，仅在玄空窗口中作参考展示。
- 选 `feixing`（正五行+玄空飞星）模式、事项已注册飞星、且已填山向时，按坐山方年/月/日/时四盘飞星计分（−20～+20），并**重排总分**：
  - 飞星分映射到 30～70 区间（`50 + 飞星分`）；
  - **综合总分 = int(正五行总分 × 0.7 + (50 + 飞星分) × 0.3)**，即飞星占 **30% 权重**；
  - 仅保留下限 `max(0, ·)`，上限不封顶（与 pure 模式同权）。
- **飞星一票否决**：飞星等级为「大凶」，或断语含「切忌」（如「五黄到山，切忌动土修造」）时，追加「玄空飞星大忌」否决理由，**总分强制归零、等级置「❌ 凶」**，即使加权后的分数仍为正数。
- 范围边界：本模块只提供**日课紫白四盘（年/月/日/时）**辅助吉凶，不含宅运盘（元运、山星、向星）、旺山旺向、上山下水、双星会坐/会向、城门、七星打劫、令星入囚、收山出煞，也不含**替卦（起星）**；兼向仅按 −10 分与文案提示处理（详见 001 §49.5）。

## 4.1 三煞族（年三煞 / 月三煞 / 日三煞 / 劫煞 / 灾煞 / 岁煞）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——仅限「年三煞 × 坐山/修方」。向方、月柱、日柱一律不否决。</span>

> **一句话**：三煞是择日第一凶煞，但“凶”的边界被严格限定在**空间层**；柱层与向层只扣分。

### 4.1.1 起例

| 三合局 | 三煞方位 | 所煞之山 |
| --- | --- | --- |
| 申子辰 | 巳、午、未 | 巳山、丙山、午山、丁山、未山 |
| 寅午戌 | 亥、子、丑 | 亥山、壬山、子山、癸山、丑山 |
| 亥卯未 | 申、酉、戌 | 申山、庚山、酉山、辛山、戌山 |
| 巳酉丑 | 寅、卯、辰 | 寅山、甲山、卯山、乙山、辰山 |

> 三煞**只用地支**，不含天干。三合局的对冲之方即三煞。

### 4.1.2 三层 × 三态矩阵（核心）

| 层 | 坐山/修方 | 向首 | 日柱/时柱临方 |
| --- | --- | --- | --- |
| **年三煞** | <span style="color:#c00000">**⛔ 一票否决**</span> | -10（不否决） | **不判**（§211 四柱级旁路） |
| **月三煞** | -20（不否决，§63） | -6（不否决） | 日柱 -20 / 时柱 -15（不否决） |
| **日三煞** | -15（不否决） | -3（不否决） | 时柱 -10（不否决） |

**叠犯加重**：月、日三煞同时犯时柱，另加 -15。

### 4.1.3 适用

修造、动土、拆舍、入宅、移徙、安葬等**有坐山**的事项。
**整体旁路**：出行、开业不信三煞（详见 B6）。

### 4.1.4 制化豁免

| 条件 | 结果 | 边界 |
| --- | --- | --- |
| 德神并（占方层） | 可减（止忌军事、疗病） | 仅“占方”可制 |
| 坐山层 | **不可制** | 坐山犯三煞，德神不能解 |
| 本命层（造葬天罡四煞） | **不制** | 与占方三煞同层不同源，并列 |

### 4.1.5 典据

- 《协纪辨方书》卷十一·用事卷（三煞用事条目）。
- 《协纪》卷三十六·辨讹（三煞名义辨正）。
- 《御定星历考原》互校。
- 三层框架见白皮书 §1.4；年三煞四柱旁路见 §211。

### 4.1.6 边界与坑

1. **年三煞只否决坐山/修方**：向首只扣 -10，不能误判为否决。
2. **年三煞不判月柱**：§211 已全面旁路，任何“月柱年三煞→否决”的旧逻辑都已删除并留墓碑。
3. **三煞 ≠ 劫煞/灾煞/岁煞**：后三者在神煞通道**仅展示、不计分**（score=0），不要重复扣。
4. **出行/开业无坐山**：三煞整体旁路，填报坐山不影响分数。

## 4.2 月破族（月破 / 月破日）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——嫁娶、安床、作灶、出行四通道；其余通道按 -30 扣分。</span>

### 4.2.3 典据

《协纪》卷五·义例三「月破」；制化条款见卷五按语。

2. **德神不解月破**：报告不得写“有天德可解月破”。

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——安葬通道的复日、三丧日。</span>

- 年重丧 -30 **不否决**，德神不另解。

### 4.4.3 典据

### 4.4.4 边界与坑

1. **嫁娶不再忌重丧**：这是 §212 的核心裁断之一，报告不得再写“重丧日嫁娶大凶”。
2. **年重丧只扣不否**：不要与日重丧、三丧混为一谈。
3. 重丧起例必须用墓库派唯一表，旧多派表已删。

> **一句话**：受死日是“日辰无气”之凶日；入宅按硬否决，其他事项按 -15 扣分。

### 4.5.1 起例与分值

| 项 | 内容 |
| --- | --- |
| 起例 | 逐月六日（正月戌、二月辰……以典表为准，详见 `受死日.py`） |
| 分值 | 安葬/修造类 **-15**；嫁娶/入宅 **0**（改硬否决） |
| 否决 | <span style="color:#c00000">**⛔ 入宅**</span>；嫁娶整日否决清单内含“受死日”关键词 |

### 4.5.2 制化豁免

### 4.5.3 典据

## 5.0 本册读法

### 5.0.1 三套「制化」必须分清

软件里同时存在三套容易混淆的「制化」逻辑，混为一谈就会写出错误的报告：

| 体系 | 所在位置 | 判据 | 输出形态 |
| --- | --- | --- | --- |
| **山家制化** | `二十四山择吉天机.check_mountain_day` | 山家吉神集（天德/月德/岁德/岁德合/天乙/禄马）是否命中 | 条件煞加注「有制化：…」或「无制化」 |
| **仙命制化** | `评分器._detect_wm_resolvers` | 宽集（德神 + 天赦/天愿 + 太阳到山 + 三合/六合） | 真冲/坐山克仙命是否降级为 WARN |
| **通用德神制化矩阵** | 典据层（协纪卷十）+ 事项规则 | 六神并临 + 月支/建除条件 | 不忌 / 止忌子集 / 犹忌 |

> **铁律**：三套的吉神集**互不自动延伸**。山家制化里有天乙贵人，不代表它能解月破；仙命制化里有三合六合，不代表它能解阴府。

## 5.1 制化引擎总览

### 5.1.1 管线：先封禁，后条件，再制化

山家判定是一条**五层顺序管线**，顺序不可颠倒——先判「绝对不能用」，再判「有条件可用」，最后才轮到吉神说话：

```
日课四柱 + 山向 + 事项
        │
        ▼
[门控] 事项是否进入山家通道？（出行整体旁路）
        │
        ▼
Layer 1  绝对禁忌（不可制化）
         年/月/日冲山 · 岁煞 · 双干正阴府(修造/修方) · 五黄到坐山 · 二黑到坐山
         → 任一中标：可用=False，凶煞列表登记
        │
        ▼
Layer 2  条件禁忌（可制化）
         兼向五黄/二黑 · 时冲山 · 劫煞/灾煞 · 阴府单干 · 山方煞 · 星曜煞
         冲丁煞 · 弓箭煞 · 剑锋煞
         → 逐条进入 condition_shas
        │
        ▼
Layer 3  吉神制化检查
         命中「山家吉神集」→ 标注（有制化：…）
         未命中 → 标注（无制化）
        │
        ▼
Layer 4  克山运（日课四柱纳音克山运时输出）
        │
        ▼
Layer 5  日类分类（宝日/义日/制日/专日/伐日/普通日）
        │
        ▼
输出 {可用, 凶煞, 警告, 吉神, 日类}
```

对应实现见 [二十四山择吉天机.py](file:///d:/自编择日软件/专业级正五行择日软件/modules/二十四山择吉天机.py#L5679-L5988)。

### 5.1.2 评分器侧的四行情景

山家管线给出结果后，评分器按四种情形分别处理（`评分器.py` L1895–1960）：

| 情形 | 判据 | 计分 | 展示 |
| --- | --- | --- | --- |
| ① 已制化 | 警告文本含「（有制化：…）」 | **0 分** | 进 `mountain_warnings_mitigated`，「山家警告·已制化」区块 |
| ② 制化不全 | 文本含「制化不全」 | 登记忌项，**不进忌事扣分** | 注明「制化不全，需补制」 |
| ③ 无制化 | 警告含「（无制化）」 | **专项 -10**，登记忌项但忌事通道不再重复 -15 | 忌项列表 |
| ④ 封禁 | `mountain_blocked=True` | **逐项 -15**，并整体置否决 | 硬否决原因 |

> 注意：情形④是「先扣 15 再否决」，扣分仍会写进 `sansha_penalty` 明细，供详情窗口解释「为什么这一天是 0 分」。否决不是简单置零，而是**有账可查的置零**。

### 5.2.1 三条读法

1. **「与德并即全不忌」只有 2 条**：厌对（五神全豁免）、五墓（限五/十一月）。其余都是**部分减禁**。
2. **「犹忌」是负条款**：归忌、反支、飞廉、大煞、游祸、月破通用支、八专德并支——德神在场也照忌。软件在五层总表里登记为「不可制化 ✅」，**禁止**反向实现成豁免。
3. **条件性条款必须三维联判**：月支 × 值日建除 × 德愿是否并。任何「月刑遇德即吉」的通用写法都是误读。

### 5.2.2 禁并排除对

| 排除 | 典载 | 实现含义 |
| --- | --- | --- |
| 天赦、天愿 **不得与月破并** | 卷十月破条括注 | 月破矩阵行中直接剔除这两神 |
| 天愿 **不得与厌对并** | 卷十厌对条括注 | 厌对矩阵行中直接剔除天愿 |

> 排除对是**结构排除**，不是「制化失败」。软件遇到这两组时不应给出「德神已到、可以放心」的文案。

### 5.2.3 参与制化的六神集

**天德、月德、天德合、月德合、天赦、天愿**（六神）。

- 月德合是本批取证确认「同为上吉之日」的德神成员，参与全部「德并」条。
- **天恩不在集内**：卷十明文「不得与德合赦愿比」，不得自动延伸。
- 各条所引德神集不同（如厌对只认天德/月德/天德合/月德合/天赦），**不得自动延伸**。

## 5.5 扶山算法

> **一句话**：扶山是「日课四柱对坐山的五行生扶力量」。软件里有**两套实现**，用途不同，不能混为一谈。

### 5.5.1 工具层权重表（`二十四山.py`）

| 关系 | 方向 | 权重 | 含义 |
| --- | --- | --- | --- |
| 生 | 课生山 | **+10** | 日课五行生坐山（进补） |
| 生 | 山生课 | **-5** | 坐山生日课（泄山之气） |
| 克 | 课克山 | **-10** | 日课五行克坐山 |
| 克 | 山克课 | **-5** | 坐山克日课 |
| 比和 | 比和 | **+8** | 同气相助 |

> 计分方式：四柱**天干 + 地支共 8 字**逐个与坐山五行比对，逐字累加。
> 例：坐山属木，日课 8 字中有 3 字属水（生木）、2 字属木（比和）、1 字属金（克木）→ `3×10 + 2×8 + 1×(-10) = +36`。

对应实现见 [二十四山.py](file:///d:/自编择日软件/专业级正五行择日软件/modules/二十四山.py#L1694-L1713)。

### 5.5.2 UI 筛选条件（`主程序.py`）

**主评分链路不直接加「扶山分」**。GUI 里的「补龙扶山」是一个**筛选条件**（勾选项 `require_longshan`），逻辑是：

```
统计四柱 8 字对坐山：
  同我（同五行）或生我（生坐山） → support_count += 1
  克我（克坐山）或我生（坐山所生，泄气） → attack_count += 1
若 support_count <= attack_count → 该日不通过筛选（pass_conditions = False）
```

即在「生扶字数 > 克制字数」时才放行，**不按权重表加分**。见 [主程序.py](file:///d:/自编择日软件/专业级正五行择日软件/主程序.py#L5248-L5303)。

> **为什么要分两套**：评分链路已由五行评分、神煞、黄道等承担吉凶；若再把扶山权重表整表加进总分，会与坐山五行克泄、分金、飞星重复计分，造成「坐山大吉的日课天然虚高」。筛选条件只做「门槛」不做「加分」，是刻意设计。

### 5.5.3 三处易错

1. **「我生」算泄气**：坐山生课（`山生课`）是 -5，不是 +5。旧注释曾把 `山生课` 当作吉，已修正。
2. **天干山 / 四维山**：八干四维各有独立五行，不按字形套天干五行——乾**金**、坤**土**、艮**土**、巽**木**（`TWENTY_FOUR_MOUNTAINS_DATA`，L218–245）。把「乾」当金、「巽」当木是对的，但把「甲」当地支木之外的其它五行就会错。
3. **兼向**：兼向的坐山五行沿用主山，不另起五行；分金才另算纳音。

## 5.8 仙命 × 坐山判定

> **一句话**：阴宅安葬的核心矩阵。**地生人为大吉，地克人为凶中之凶**，方向敏感，不可对称处理。

### 5.8.1 五级关系

| 关系 | 分值 | 等级 | 说明 |
| --- | --- | --- | --- |
| **坐山生仙命** | **+20** | 大吉 | 地生人 |
| 仙命生坐山 | +10 | 小吉 | 人让地 |
| 比和 | 0 | 平 | 同气 |
| 仙命克坐山 | -15 | 小凶 | 人克地 |
| **坐山克仙命** | **-30** | 凶中之凶 | 地克人，地不容此命 |

对应实现见 [评分器.py](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L196-L230)。

### 5.8.2 三级判定（坐山克仙命 / 仙命真冲共用）

```
命中（-30）
   │
   ├─ 叠三煞 / 岁破 / 月破 / 日破 → ⛔ 直接否决（有制化也不救）
   │
   ├─ 无宽集化解吉神 → ⛔ 一票否决
   │
   └─ 有宽集化解吉神 → 仅扣分（WARN），真冲行标注「有制化：…」
```

**宽集化解吉神**（`_detect_wm_resolvers`）：天德、月德、岁德（含德合）、天赦、天愿、**太阳到山**、三合、六合。

- 三合/六合**不论合化成功与否，见即算**有制化（用户 2026-10-04 拍板「宽集」）。
- **太阳到山**对「坐山克仙命」是**正照对症**，在化解列表中置顶（§59.11）。
- 叠重煞检查（`_check_veto_overlay`）只认 `三煞 / 岁破 / 月破 / 日破`，且**排除向方项**（`向方月破`、「(向方)」子串），防止向侧轻档误触发否决。

### 5.8.3 兼向与双坐山克

| 场景 | 判定 | 结果 |
| --- | --- | --- |
| 主山 = 坐山克仙命，兼向 ≠ | 主山三级判定 | 按 5.8.2 |
| 主山 ≠，兼向 = 坐山克仙命 | **兼向独立否决** | ⛔ 强制否决（制化不豁免） |
| 主山 = 兼向 = 坐山克仙命 | **主兼双坐山克** | ⛔ 强制否决（两边各有制化也 VETO） |
| 日支真冲 + 坐山克仙命同日 | **仙命双凶叠加** | ⛔ 强制否决，不因个别制化降级 |

> 兼向独立否决的典据口径：穴线偏向「地不容命」之山即不可用——这不是「主山吉、兼向瑕」可以折中抵扣的事。

### 5.8.4 仙命六冲坐山（§186）

仙命年支与**坐山支**六冲（仅地支山有六冲概念，天干山/卦山不触发）→ 分值对齐仙命真冲 **-30**，走同一套三级判定（叠忌直否 / 无制化否决 / 有制化 WARN）。

### 5.8.5 仙命冲坐山 vs 仙命真冲

| 项 | 冲的对象 | 分值 | 备注 |
| --- | --- | --- | --- |
| 仙命真冲 | 仙命年支 × **日课日支** | -30 | 亡命不论日柱、不论月时支 |
| 仙命六冲坐山 | 仙命年支 × **坐山支** | -30 | 仅地支山 |

> 亡命（仙命）只论**年命**，绝不拿亡者的日柱去配日课——这是安葬与阳宅相主最大的区别。

### 5.8.6 坐山克仙命的等级封顶

即使「有制化」不否决，等级仍**封顶「❌ 凶」**：

```
❌ 凶（坐山克仙命，有制化：天德、太阳到山）
```

只改等级、不改总分（排序/对比仍按实际分值）。理由：地克人是结构性缺陷，制化只能减凶，不能把「凶中之凶」改写成「上吉」。

## 5.9 分金与正体五行

> **一句话**：分金是「坐山之内再细分金」，以六十甲子纳音论生克；正体五行是坐山本气。
> 二者在 §62（2026-10-09 拍板）后**统一改为强扣分，不再一票否决**。

### 5.9.1 判定链

```
选定山向（且非出行）
   │
   ├─ 有兼向 → 取兼向分金 → evaluate_with_fengjin(use_fengjin_wuxing=True)
   │      └─ 分金纳音受四柱克泄至「大凶」/「凶(犯大煞)」
   │
   └─ 无兼向 → 取正向正体五行 → evaluate_by_name
          └─ 正体五行受四柱克泄至「大凶」/「凶(犯大煞)」
   │
   ▼
强扣分：-abs(通道真实分值)，登记忌项，不置 veto
```

### 5.9.2 分值口径

| 项 | 分值 | 否决 |
| --- | --- | --- |
| 分金大凶 | 取通道真实分值（实测 **-34**） | **否** |
| 正体大凶 | 取通道真实分值 | **否** |

> 旧稿固定写「-25」是下限档；实际扣分是 `-abs(_raw)`，随分金/正体判定得分浮动。
> §62 的审计结论：2024–2027 × 山向 × 7 事项全年扫描中，「仅因分金大凶被否」= **0 天**——否决权与其他门槛完全共线，属冗余。**风险提示**：该结论绑定坤山艮向兼未 × 4 组事主样本，换山向/仙命组合后需复核（`issues_pending` 挂账）。

### 5.9.3 出行的例外

出行无坐山，其 `shan_xiang` 只是「出发方向」，**不得进入坐山五行克泄判定**。§201（2026-10-30）起，分金/正体大凶强扣分对出行整段跳过。

## 5.10 玄空飞星加权

> **一句话**：飞星只在 `feixing` 模式、只在修造/安葬类事项、且无否决时参与，按 7:3 加权。

### 5.10.1 公式

```
综合分 = max(0, int(正五行总分 × 0.7 + (50 + 飞星分) × 0.3))
飞星分 ∈ [-20, +20]  →  (50 + 飞星分) ∈ [30, 70]
```

| 参数 | 含义 |
| --- | --- |
| 正五行总分 | 加权前的 `self.final_score` |
| 飞星分 | `玄空飞星引擎.score_feixing` 输出 |
| 0.7 / 0.3 | 正五行主、飞星辅 |
| `max(0, …)` | 仅保留**下限 0**；**上限已放开**（2026-10-25 W2-a3 拍板） |

> **为什么取消上限 100**：旧 `clamp(0,100)` 使飞星模式「上吉 105」结构性不可达，而 pure 模式本无上限（实测极值 190–359），属两模式天花板错位。取消上限后，仅还原被压线的上吉日，其余等级桶/否决日/低分日零变化（见 `docs/修造W1多坐山采样快照_20261025.md` §二）。

### 5.10.2 飞星否决

飞星等级 = **大凶**，或断语含「切忌」（如「五黄到山，切忌动土修造」）→ ⛔ 一票否决。

- 适用于修造择日（以山家为核心）。
- 与分金大凶口径曾并列；§62 后分金降为强扣分，飞星大凶**仍保留否决**（飞星是「月/年五黄二黑到山」，属绝对禁忌，不同于分金的可折中）。

### 5.10.3 参与事项

由 `事项标准注册表` 的 `feixing` 画像决定，不硬编码在主流程里。非否决课、无山向、pure 模式 → 不参与。

## 5.11 坐向吉凶判定脉络（总图）

把 5.4–5.10 串起来，一次完整的山家判定按下列顺序执行：

```
① 事项门控
   出行？ → 整段山家旁路，走「出行方位」轻权重判定
   其它填山向事项？ → 继续
        │
② 解析山向
   坐山 / 向首 / 兼向；四维宫借兼向消歧
        │
③ Layer 1 封禁（任一命中 → 否决）
   年冲山 · 月冲山 · 日冲山 · 岁煞 · 双干正阴府 · 五黄到坐山 · 二黑到坐山
        │
④ Layer 2 条件煞 + Layer 3 制化
   命中条件煞 → 山家吉神集（德/岁德/贵人/禄马）是否在？
        有 → 0 分展示
        无 → -10
        │
⑤ Layer 4 克山运
   四柱纳音克山运 → 有制化 0 / 无制化 -10
        │
⑥ 坐山五行克泄
   分金（兼向）/ 正体（正向）大凶 → 强扣分不否决
        │
⑦ 玄空飞星（仅 feixing + 修造/安葬）
   max(0, 0.7×五行 + 0.3×(50+飞星))；飞星大凶 → 否决
        │
⑧ 仙命 / 相主
   仙命真冲 · 仙命六冲坐山 · 坐山克仙命 · 主兼双克 · 年命×日支 · 年命×向首
        │
⑨ 等级封顶
   坐山克仙命 → 等级封顶「❌ 凶」（不改总分）
   五行 < 60 → 判凶
        │
⑩ 输出总分 / 等级 / 忌项 / 明细
```

### 5.11.1 为什么顺序不能换

| 顺序 | 若颠倒会怎样 |
| --- | --- |
| 封禁必须在制化之前 | 先制化会把五黄、岁煞「解掉」，出现「封禁山向被判上吉」的荒谬结论 |
| 制化必须在扣分之前 | 先扣 10 分再加回，会造成同日重复记账 |
| 飞星必须在正五行之后 | 飞星公式引用的是加权前的正五行总分，顺序颠倒就是死循环 |
| 仙命必须在山家之后 | 山家已否决的日课不应再算仙命加分，否则明细自相矛盾 |

### 5.11.2 缺山向的警示

凡将进入山家通道的事项（`_SHAN_UI_EVENTS` 剔除出行），**未填山向**时须给顶层红字警示，而不是静默跳过。理由：不填山向不等于「山家无煞」，而是「无法判定」——静默跳过会让用户误以为已通过山家审核。

## 5.12 三条铁律

### 铁律一：制化不是开关，是矩阵

「有德神 → 全部解掉」是错读。协纪 10 条明文里只有 2 条全豁免（厌对、五墓限月），其余都是「止忌子集」或「犹忌」。**报告文案不能写「德神到，百无禁忌」**。

### 铁律二：否决只能来自显式否决点

负分永远不会自动产生否决。所有 ⛔ 都必须能追溯到具体判据：

- `_check_veto_items` / `_HARD_VETO_KEYWORDS`
- `get_sansha_info` 山向级标记
- `_check_owner_xiangshou_chong` / 相主硬门槛
- `check_mountain_day` 的 `可用=False`
- 飞星大凶

**反断言**：若某日被否决，必须在报告里能指出「哪一条否决点」；指不出来就是 bug，不是「玄学」。

### 铁律三：人地不对称

- 坐山生仙命 = **+20 大吉**；坐山克仙命 = **-30 凶中之凶**。
- 仙命克坐山只有 -15、**不否决**；坐山克仙命 -30 且可触发否决。
- 地克人是「地不容此命」，人克地只是「人不服地」。这条不对称是整套安葬判定的价值观底座，任何「对称化」重构都是错的。

## 第 11 章 总分公式与计算顺序

```text
五行评分 = 基础分 100
         + 神煞得分
         + 宜事得分
         + 忌事得分（负）
         + 十二长生得分
         + 地支关系得分
         + 纳音匹配得分

总分 final = 五行评分
           + 月令得分
           + 喜用神得分
           + 相主得分
           + 黄道得分
           + 太阳太阴得分
           + 三煞扣分（sansha_penalty）
           + 向方扣分（xiangfang_penalty）
           + 出行方位得分（仅出行）
           + 坐山得分
           + 克山运得分
           + 玄空飞星（可选）
```

实现定位：`modules/评分器.py` 的 `Scorer.score()`（总分合成行见 L2422；五行评分构成注释见 L2420）。

**计算顺序**（不可颠倒）：

1. 四柱 → 2. 神煞发射与分项 → 3. 五行评分 → 4. 月令/喜用/相主 → 5. 黄道/太阳太阴 → 6. 三煞/向方/出行 → 7. 硬门槛判定 → 8. 等级映射。

**硬门槛优先**：任一硬否决命中 → `final_score = 0`、等级 `❌ 凶`（`评分器.py` L2662–2669）。

## 第 17 章 口径红线与实现边界

1. **双通道去重（H1）**：神煞与建除/宜忌同源项只计一次，禁止重复加分。
2. **无证据不放宽**：三库无明文者，不得新增豁免或降档；只能标“待证”或“仅展示”。
3. **展示 ≠ 计分**：`score=0` 的识别展示项必须写明原因，不得暗中参与总分。
4. **硬门槛优先于宜项**：相主、三煞、山家封禁、建除当日之忌优先；通书宜项不得覆盖硬禁忌。
5. **分值唯一来源**：分值只允许来自 `SHENSHA_SCORES` / `SHEN_SHA_WEIGHT`，规则文件不得内联分值。
6. **等级不改总分**：坐山克仙命只封顶等级、不篡改总分（排序仍反映真实分）。
7. **禁止以“验证通过”迁就表源**：不得改表去迎合实现；表源改动须先取证、后拍板。

## 6.0 裁决的方法论

### 6.0.1 三库主锚与取证纪律

| 层级 | 典籍 | 角色 | 语料规模 |
| --- | --- | --- | --- |
| 主锚 | 《协纪辨方书》 | 官方钦定，判伪效力最高 | 286,084 字 |
| 互校 | 《御定星历考原》 | 与协纪互证，反向不支持即降档 | 71,554 字 |
| 第三参照 | 《陈子性藏书》 | 民间实操参照，单条记载不单独成立 | 740,117 字 |

**四条取证纪律**（B6 全部裁决共同遵守）：

1. **全卷逐字扫描，不抽样**。检索词含繁简/异体近似，命中后逐条人工核读。
2. **伪共现排除**。关键词命中不等于语义命中，必须读上下文；「方道」78 处全为修方，就不能算作出行依据。
3. **无证据不放宽**。三库无载 → 不得新增规则、不得升否决、不得「凭经验补一条」。
4. **穷尽性证明**。每份取证报告必须列出「检索过但无记载」的清单，证明不是没查到，而是确实没有。

### 6.0.2 判伪的效力顺序

```
协纪卷三十六「辨讹」钦定判伪  ＞  协纪正文无载  ＞  考原反向不支持  ＞  陈书单条孤证  ＞  坊刻通书流传
```

- **钦定判伪**：直接删除，永不复用（吉庆、杨公忌）。
- **主锚无载**：降为待证隔离或删除（杀师日、十恶大败、日课岁破）。
- **考原反向**：降档、收窄事项，不升否决（日游方出行）。
- **陈书孤证**：可作第三参照，但不得对抗主锚（红嘴朱雀是「陈书有载 + 主锚无载」的**唯一保留特例**，理由见 6.9）。
- **坊刻流传**：只作「提示性轻扣」，绝不升格为否决（红纱日）。

### 6.0.3 本册的证伪结构

每条铁案都必须回答三个问题：

| 问题 | 若答不上来 |
| --- | --- |
| 这条规则**典出何处**（卷次/页）？ | 只能挂「待证」，不能计分 |
| 它的**适用域**是什么（日辰 / 方位 / 年神 / 时辰）？ | 极可能重犯「方位神误作日辰神」 |
| 它的**力度**有明文吗？ | 只能取下限轻扣，不能否决 |

## 6.1 论杀师日之伪

### 6.1.1 命题

**「杀师日」不是典据神煞，而是两套互相矛盾的口诀拼接物；它不配拥有 -30 的重扣，更不配否决。**

### 6.1.2 典据核查

| 库 | 检索结果 | 说明 |
| --- | --- | --- |
| 协纪 | **零卷页命中** | 无「杀师」条目、无按语、无辨讹 |
| 考原 | **零命中** | 同上 |
| 陈书 | **零命中** | 同上 |

| 口诀 | 内容 | 问题 |
| --- | --- | --- |
| 算法 1 | 春戌、夏丑、秋辰、冬未 | **实为「四击 / 死别」表**，因跨家族污染已废弃 |

| 对照表 | 春卯、夏午、秋酉、冬子 | 被协纪辨讹点名「通书误作大败日」 |

**三代口诀，三种答案，无一有典。** 这不是「流派差异」，是**没有源头**。

### 6.1.3 软件处置

| 动作 | 状态 |
| --- | --- |
| 升 HARD_VETO | **拒绝**（无证据不放宽） |
| 计分 | 降为 **0 分，仅识别展示** |
| 登记 | `DISPLAY_ONLY_REGISTRY['杀师日'] = {'source': 'pending_canon'}` |

| 嫁娶通道 | 整链撤出（与杀师时同批） |

由 `_add_shensha` 统一查表：命中 `display_only_info` → `score = 0` 并追加待证注（见 [神煞基类.py](file:///d:/自编择日软件/专业级正五行择日软件/modules/shensha/神煞基类.py#L2032-L2040)）。

### 6.1.4 反断言

### 6.2.1 命题

### 6.2.2 典据

> **协纪 p279217（奏疏）**：红纱日「**甚属无当**」，「**应请一并删去**」。

- 起例（辨讹正解）：**四孟月巳、四仲月酉、四季月丑**（孟巳、仲酉，旧表曾对调）。
- 月界：**节气月建**，闰月不另立。

### 6.2.3 软件处置

| 通道 | 处置 | 分 |
| --- | --- | --- |
| 嫁娶 | **整链撤出**（§197 D6-Q1 / §212 拍板 1） | 0（不再计分） |
| 修造 / 安床 / 通用 | 保留 | **-15**（轻扣，非否决） |
| 注册键 `('嫁娶','红纱日') = -20` | 成为全年 0 发射的**死键** | 登记 BACKLOG G-1，**禁止顺手删** |

> **铁案一句话**：判「无当」不等于判「不存在」；降格比删除更接近典意。

## 6.7 论福星旧法之误

### 6.7.1 命题

**旧「福星」谓词（年支 +6 冲位查日支）与最凶神「岁破」完全同构，导致岁破日白送 +10 吉分。这是算法层的自相矛盾，必须换派重立。**

### 6.7.2 证据链

| 环节 | 事实 |
| --- | --- |
| 旧谓词 | 年支顺数 6 位（即冲位）查日支 → 命中即「福星」 |
| 岁破谓词 | 年支冲位（+6）查日支 → 命中即「岁破」 |
| 结果 | **同一天，既岁破又福星** |
| 实测 | 2026 年 31 天次 / 事件，岁破日白送 +10 |

**一个谓词不可能同时定义「最凶」和「最吉」。** 这不是巧合，是抄错了表。

### 6.7.3 正派

> **协纪卷七·义例五**：「**日干生时干曰福星贵人**」（食神派）。
> 陈书附录《福星诀》同派互证。

- 只查**时柱**，不查日支。
- `日干生时干`：日干五行生时干五行。
- 14 条通道键按正统加回。

### 6.7.4 软件处置

- 发射侧：旧谓词整链删除，`_build_fuxing_shensha` 按**时辰派**重建。
- 展示侧：同步修正，不再显示「年支冲位」的伪福星。
- 岁破交叉敞口：随重建自动消失（两者不再同构）。

### 6.7.5 反断言

```python
# 岁破日不得有福星
assert not has_fuxing(veto_day_2026)
# 福星只由时柱决定：同日不同时辰，福星状态可不同
assert fuxing(day, hour='甲') != fuxing(day, hour='乙')
```

> **铁案一句话**：吉神与凶神共用同一谓词，必有一错；错的那个，通常是抄表的人。

## 6.8 论大煞 / 飞廉 / 伏断 / 反支之收缩

### 6.8.1 命题

**这四族都「有典」，但典只给极窄的适用域；软件曾把它们扩成全事项凶煞，属超范围注册。处置是「收窄」，不是「删除」。**

### 6.8.2 逐项

| 神煞 | 典载适用域 | 旧实现 | 现处置 |
| --- | --- | --- | --- |
| **大煞** | 协纪仅忌**军事** | 注册为多事项凶煞 | 超范围注册删除 |
| **飞廉** | 卷三：「在岁名飞廉，在月名大煞」——**名/域错配** | 作日辰神发射计分 | 日辰发射与计分全撤，谓词保留 |
| **伏断** | 辨讹：「**伏断本选时之法**」；卷十无条目、卷十一 0 命中 | 作日家神煞发射 | 日家发射全删，谓词保留（选时层） |
| **反支** | 卷十仅忌**帝王用事** | 全事项发射 + 13 键 | 全删发射与键，谓词保留 |

### 6.8.3 为什么「保留谓词」

收窄不等于遗忘。谓词留在代码里，是给未来「选时层」「帝王用事层」留接口；**键与发射删掉，是为了不让它在当前事项层继续误伤**。

### 6.8.4 反断言

```python

assert feilian_day_emission == []                    # 飞廉日辰零发射
assert fuduan_day_emission == []                     # 伏断日家零发射
assert '反支' not in any_channel_keys                # 反支 13 键已删
```

> **铁案一句话**：收窄是「把神放回它的域」，不是「把这个神删掉」。

## 6.9 论红嘴朱雀之降维（唯一保留的陈书孤证）

### 6.9.1 命题

**红嘴朱雀在协纪、考原均无载，仅陈书有九宫起例与一句实操禁令。按「陈书孤证不得对抗主锚」的通则，本应删除；但它被保留并升为入宅 HARD_VETO，理由是「主锚无载 ≠ 主锚反对」，且陈书给出了可执行的九宫定位法与明确后果描述。**

这是全书中**唯一**一次「孤证保留」，必须写清边界，否则会被当成双标。

### 6.9.2 典据

> **陈书 p96**：「**切不可犯紅嘴朱雀入中宮**」，犯者不吉、屢見甚驗。
> 九宫起例见陈书 p890。

- 协纪：无「红嘴朱雀」条目。
- 考原：无。
- 陈书：**有起例、有方位（中宫/震宫）、有效验描述**，但**无分值力度原文**。

### 6.9.3 为什么可以保留

| 条件 | 红嘴朱雀是否满足 |
| --- | --- |
| 第三参照有明确起例 | ✅ 九宫起例 p890 |
| 有明确禁忌对象 | ✅ 入中宫 → 忌入宅、归火 |
| 有后果描述 | ✅ 「犯者不吉、屢見甚驗」 |
| 主锚是否**反对** | ❌ 无反对，仅无载 |
| 是否被用来**放宽** | ❌ 是加严，不是放宽 |

> 关键在最后一条：「无证据不放宽」约束的是**放宽**；对「加严」的孤证，只要起例可执行、后果有描述，可以作为**第三参照的保守条款**保留，但必须标注「典据单一」。

### 6.9.4 软件处置

| 通道 | 处置 | 分值 |
| --- | --- | --- |
| **入宅** | ⛔ **HARD_VETO** | 按典 -30（拒绝 -12 弱化档） |
| 作灶（震宫） | 重度扣分 | -30 |
| 安床 | **方位门控**（仅当红嘴朱雀落宫与安床方位相干才触发） | -30 |
| 嫁娶 | 仅展示 | 0（一票否决另由时辰级白虎/朱雀处理） |

> 入宅硬门槛见 [评分器.py](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L2630-L2700)。
> 分值取 -30 而非 -12：陈书原文是「切不可犯」，语义强度对应最重档；-12 是旧「口舌是非」档，与「入中宫」不是同一件事。

### 6.9.5 反断言

```python
# 入宅遇红嘴朱雀入中宫 → 必否决
assert is_vetoed(2026, d, '入宅') for every 红嘴朱雀入中宫日
# 未入中宫（如仅到震宫）不得误触入宅否决
assert not is_vetoed(2026, d, '入宅') when 红嘴朱雀在震宫
```

### 6.9.6 边界声明

- 这是**唯一**的孤证保留案例。任何后来者想拿陈书单条再开一例，必须先回答：起例是否可执行？后果是否有描述？主锚是否反对？三者缺一，不得保留。
- 陈书 p96 的「入中宮」是**方位条件**，不是「见红嘴朱雀即凶」。忽略方位条件，就是把它又扩回了「全事项凶煞」。

> **铁案一句话**：孤证可以加严，不可以放宽；可以定点，不可以铺开。

## 6.10 论年三煞为何不判四柱

### 6.10.1 命题

**年三煞是「年神 + 方位」的复合煞，其威在「山向」，不在「日柱 / 时柱」。把年三煞铺到四柱，是方位神误作日辰神的又一次重犯。**

### 6.10.2 典据核查

| 检索 | 结果 |
| --- | --- |
| 协纪卷十一「年三煞」事目 | **70 事目 0 命中柱级** |
| 协纪「三煞」柱级忌 | 仅月/日三煞有柱级表述 |
| 考原 | 互校同向 |
| 陈书 | 无「年三煞犯日柱」条 |

> 协纪卷四按语的精神仍是同一句：「**历家特误以年方配日辰耳**」——年三煞本属年方，不是日辰。

### 6.10.3 软件处置（§211，2026-10-31）

| 层级 | 山向 | 向首 | 日柱 | 时柱 |
| --- | --- | --- | --- | --- |
| **年三煞** | -25 + ⛔ 否决 | -25 | **全面旁路（0）** | **全面旁路（0）** |
| 月三煞 | -20 | -20 | -20 | -15 |
| 日三煞 | -15 | -15 | — | -10 |

- 年三煞**只保留山向/向首**判定；四柱级（日柱、时柱）**整段跳过**，不是「降为 0 分」，而是**不进入计算**。
- 月日三煞保留柱级扣分（月三煞日柱 -20、时柱 -15；日三煞时柱 -10）。
- 月日三煞叠犯时柱另加 -15（防「两煞同柱只算一次」的漏扣）。

### 6.10.4 为什么要分年/月/日

| 煞 | 本体 | 应判对象 |
| --- | --- | --- |
| 年三煞 | 年支三合之冲 | **山向**（年方不可动） |
| 月三煞 | 月建三合之冲 | 山向 + 日柱 + 时柱（月内择日，柱级有意义） |
| 日三煞 | 日支三合之冲 | 山向 + 时柱（日内择时，时柱有意义） |

**级别越细，才越配柱级。** 年煞是一整年的方位禁令，拿它去否某一天的某个时辰，等于「用一年的地图找一天的厕所」。

### 6.10.5 反断言

```python
# 年三煞日柱：必须为 0，且不登记忌项
assert year_sansha_penalty(day_pillar) == 0
# 年三煞山向：必须保留否决
assert is_vetoed(shanzuo_in_year_sansha)
# 月三煞日柱仍然扣 20
assert month_sansha_penalty(day_pillar) == -20
```

> **铁案一句话**：年煞管方，月煞管日，日煞管时；越级执法，必生冤案。

## 6.11 论出行为何不看坐山看方向

### 6.11.1 命题

**出行没有「坐山」，只有「出发方向」。三库全卷中「出行坐山」零命中；把修造的山家封禁套到出行，是通道错配。**

### 6.11.2 取证结论（全卷逐字）

| 检索词 | 协纪 | 考原 | 陈书 | 判定 |
| --- | --- | --- | --- | --- |
| 出行方向 / 出方位 | 0 / 0 | 0 / 0 | 0 / 0 | 三库**无此术语** |
| 方道 | 20（**全为修方**） | 0 | 78（**全为修方**） | 出行语境 **0 处** |
| 岁破方 / 太岁方（作出行判据） | 1 / 2（均「必不可修」） | 0 / 0 | 0 / 0 | 出行语境 **0 处** |
| 出行三煞 / 坐山三煞 | 0 | 0 | 0 | **三库无载** |
| 天德方 / 月德方（出行） | 4 / 1（均修方制煞） | 0 | 2（天德含出行） | 仅陈书 1 条 |
| 鹤神 | 7（「出行忌抵向」，判俗信） | 0 | 1 | 仅 2 处，主锚降格 |
| 日游（出行） | 12（条目不含出行） | 6（只忌产室/扫舍/安床） | 1（忌日游方出行） | 考原**反向不支持** |
| 往亡 | 62 | 25 | 18 | 日忌 ✅ 三库一致 |

**穷尽性说明**：以上「0」为全卷逐字扫描（含繁简/异体近似），非抽样；未覆盖清代坊刻通书，结论不外推。

### 6.11.3 唯一可用的方向条文

> **陈书 p757**：「**元旦出行**：宜向天月二德天道及喜神所在之方出行吉；忌截路空亡时；**忌鹤神日游方，不宜从此方出行**。」

这是三库中**唯一**把「出行方向」写成可操作规则的条文，但：

- 场景限定「**元旦出行**」（岁首出行），不能推广为所有出行；
- 方向来源是通用吉方（天德/月德/天道/喜神）+ 忌方（鹤神/日游）；
- **无分值力度**，也无「出发地→目的地」的方位判定法。

### 6.11.4 软件处置（§201–§203）

| 项 | 处置 |
| --- | --- |
| 出行坐山 / 山家封禁（日冲山、岁破、五黄二黑） | **整段旁路**（§199/§201 切断） |
| 出行三煞 / 向方月破 / 分金 / 正体 | **全部取消**（原 20 课差 360 分） |
| 出行日忌（往亡、四离四绝、月厌、破日） | **保留**（三库一致） |
| 天德 / 月德 / 喜神方 | 新增轻权重 **+5 ~ +8**（取下限，不加岁德方） |
| 鹤神方 / 日游方 | 新增轻权重 **-5**（不否决） |
| 岁破方 / 太岁方 | **不纳入**（出行语境 0 处） |
| 方位叠合否决 | **不采纳**（无载） |
| UI 文案 | 「坐山」→「**出发方向**」，加「仅作参考」提示 |

### 6.11.5 反断言

```python
# 出行不得因坐山封禁被否
assert not is_vetoed(2026, d, '出行') for d in 日冲山日
# 出行三煞通道必须为 0

# 往亡仍然生效

# 方位不得单独构成否决
assert all(veto_reason != '出行方位' for veto_reason in veto_reasons)
```

> **铁案一句话**：出行的「山」是方向，不是坐山；方向只能加减分，不能定罪。

## 6.12 论重丧日不忌嫁娶

### 6.12.1 命题

### 6.12.2 典据

### 6.12.3 软件处置（§212 C2）

| 通道 | 处置 |
| --- | --- |

- 复日、三丧、年重丧三键的安葬否决权**保留**，不在本批撤销。

### 6.15.3 判伪的「不可逆」原则

| 类 | 可否恢复 | 条件 |
| --- | --- | --- |
| 钦定判伪（吉庆、杨公忌） | **永不可** | 除非新出土钦定文献推翻辨讹 |
| 主锚无载（杀师日、十恶大败） | 可，但需**三库新增明文** | 且只能从 0 分起步，不得直接升否决 |
| 域错配（岁破日课、太岁日辰） | 可，但需**新证据证明该域适用** | 不得以「通书都这么写」为据 |
| 收窄（大煞/飞廉/伏断/反支） | 可，按原典域恢复 | 不得跨域 |

### 6.15.4 结语：铁案不是终点，是护栏

本册的每一条，都是**用可复核的原文，换掉一句口口相传的「师傅说」**。

- 我们不是在「发明」择日学，而是在**把择日学里被抄错的部分，一页一页抄回去**。
- 每一条裁决都留下了**反断言**：它不是说服读者的修辞，而是防止后来者（包括我们自己）在下一版里悄悄改回去的**护栏**。
- 三库语料永久存放于 `D:\archive\`，任何一条铁案都可重跑取证脚本复核。**结论可推翻，方法不可省。**
