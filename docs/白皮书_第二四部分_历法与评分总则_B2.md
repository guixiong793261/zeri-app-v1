# 第二部分 底层历法机制

## 第 7 章 时间基准：真太阳时与晚子时

### 7.1 三层时间

| 层 | 含义 | 实现 |
| --- | --- | --- |
| ① 民用时间 | 用户输入的年月日时分 | UI 输入 |
| ② 真太阳时 | 经度修正 + 均时差 | `modules/真太阳时.py`：基准东经 120°，每偏离 1° 修正 4 分钟，叠加 NOAA 均时差 EoT |
| ③ 命理时间 | 用于定四柱的时辰 | 修正后的时、分（秒归零） |

口径要点（001 §43.9 / §48）：

1. 未填经度或经度 = 120.0 时**不启用**真太阳时。
2. 修正粒度为**分钟**，秒一律归零，避免伪精度。
3. 顺序是「先修正、后判 23 点边界」——真太阳时结果流入晚子时判定与交节比较。

### 7.2 晚子时派（23:00–23:59）

- **日柱**：晚子时**不进次日**，仍用当日日柱。
- **时支**：子。
- **时干**：按**当日日干**五鼠遁推出（不使用 sxtwl 的次日口径）。
- 依据：《三命通会》“子时上半属昨日、下半属今日”，《新唐书·历志》。
- 与 sxtwl 的差异属**派别差异**，本软件固定采用晚子时派，不在运行期切换。

### 7.3 边界案例

| 案例 | 结论 |
| --- | --- |
| 23:00 整 | 属晚子时，日柱当日、时柱子时（当日日干遁） |
| 00:00 | 次日子时（早子时），日柱进次日 |
| 经度修正后跨 23 点 | 以**修正后**时刻判晚子时 |
| 交节时刻 ±1 分钟 | 以精确节气时刻比较，跨过即换月柱 |

## 第 8 章 节气与四柱排盘

### 8.1 年柱：立春换年

- 取当年立春**精确时刻**；早于立春用上一年年柱，晚于用下一年年柱。
- 不以农历正月初一换年。

### 8.2 月柱：十二节定月

| 节 | 月建 | 节 | 月建 |
| --- | --- | --- | --- |
| 立春 | 寅 | 立秋 | 申 |
| 惊蛰 | 卯 | 白露 | 酉 |
| 清明 | 辰 | 寒露 | 戌 |
| 立夏 | 巳 | 立冬 | 亥 |
| 芒种 | 午 | 大雪 | 子 |
| 小暑 | 未 | 小寒 | 丑 |

- 算法取「节」（非「气」）时刻比较；位于立春前时补前一年小寒，落到子月区间。
- 月干由年干五虎遁推出。

### 8.3 日柱与时柱

- 日柱按公历日期推算，晚子时不进次日（见 7.2）。
- 时柱：时支按两小时一段；时干五鼠遁。

### 8.4 派生字段

| 字段 | 用途 |
| --- | --- |
| 旬空 | 空亡提示、部分神煞触发 |
| 纳音 | 分金/旺命比对、纳音匹配分 |
| 藏干 | 旺衰与十神判断 |
| 十二长生 | 日干在各柱地支的长生旺衰（见 12.2） |

### 8.5 农历与闰月

- 公历/农历双输入；闰月按实际月建换算，不按“闰月算下月”简化。

## 第 9 章 方位体系与三煞三层框架

### 9.1 二十四山、兼向、分金

- 二十四山：8 干 + 12 支 + 4 维。
- 兼向：正中 / 兼左 / 兼右；分金按度数落位，分金五行与正体五行分别参评（分金等级「平」不改变整日等级）。
- 三煞判断以**坐山/修方**为主，向首按各层规则另计。

### 9.2 三煞三层矩阵（现行口径）

| 层 | 论坐山/修方 | 论向首 | 论日/时柱临方 | 否决权 |
| --- | --- | --- | --- | --- |
| 年三煞 | 犯 → **一票否决** | 犯 → 扣 **-25** | **不判**（四柱级全面旁路，001 §211 案 B） | 仅山向否决 |
| 月三煞 | 犯 → 扣 **-20**，不否决（§63） | 犯 → 扣 **-20** | 日柱临方 -20 / 时柱临方 -15（柱级扣分不否决，§64 B3） | 无 |
| 日三煞 | 犯 → 扣 **-15**，不否决 | 犯 → 扣 **-15** | 时柱临方 -10（柱级扣分不否决） | 无 |

**为什么年三煞不判月柱**：三库无「月柱临煞则凶」明文，属把**方位神**当作**日辰神**串用；年三煞的成立面是“山向”，不是四柱干支。故四柱级通道整体旁路，但保留识别展示（墓碑保留说明，001 §211）。

**“可向不可坐”**：三煞为方道神，占山/修方/坐向忌；向首按上表扣分口径处理，不因“可向”而完全免检。

### 9.3 太岁、岁破、月破、暗建

| 项 | 属性 | 现行处理 |
| --- | --- | --- |
| 太岁 | 方位神（年支） | 方位忌；日辰“太岁日”注册已删除（001 §139 系列） |
| 岁破 | 方位神（冲太岁方） | 方位忌；“日课普适岁破日”否决已删除（001 §140） |
| 月破 | 月支冲日支 | 日课凶煞，按月/事项决定扣分或否决 |
| 暗建 | 月建对冲方的十二建隐藏煞 | 方位扣分（示例 -15） |

### 9.4 玄空飞星（可选，仅 feixing 模式）

- 界面默认 `pure`（纯正五行）模式：玄空飞星不参与评分，仅在玄空窗口中作参考展示。
- 选 `feixing`（正五行+玄空飞星）模式、事项已注册飞星、且已填山向时，按坐山方年/月/日/时四盘飞星计分（−20～+20），并**重排总分**：
  - 飞星分映射到 30～70 区间（`50 + 飞星分`）；
  - **综合总分 = int(正五行总分 × 0.7 + (50 + 飞星分) × 0.3)**，即飞星占 **30% 权重**；
  - 仅保留下限 `max(0, ·)`，上限不封顶（与 pure 模式同权）。
- **飞星一票否决**：飞星等级为「大凶」，或断语含「切忌」（如「五黄到山，切忌动土修造」）时，追加「玄空飞星大忌」否决理由，**总分强制归零、等级置「❌ 凶」**，即使加权后的分数仍为正数。
- 范围边界：本模块只提供**日课紫白四盘（年/月/日/时）**辅助吉凶，不含宅运盘（元运、山星、向星）、旺山旺向、上山下水、双星会坐/会向、城门、七星打劫、令星入囚、收山出煞，也不含**替卦（起星）**；兼向仅按 −10 分与文案提示处理（详见 001 §49.5）。

## 第 10 章 黄历辅助体系

### 10.1 建除十二神

- 起例：月建所在为「建」，依次除、满、平、定、执、破、危、成、收、开、闭。
- 宜忌按建除表；示例：**成日 +5**（十二建除吉神加分），破日从忌。
- 建除层与神煞层**不得重复计分**（H1 红线）。

### 10.2 大小黄道

| 项 | 规则 | 分值 |
| --- | --- | --- |
| 大黄道（青龙/明堂/金匮/天德/玉堂/司命） | 吉 | 表值加分 |
| 大黄道（天刑/朱雀/白虎/天牢/玄武/勾陈） | 凶 | **-15** |
| 小黄道（成/开/定/满等） | 吉 | 表值加分（成日 **+5**） |
| 黄道综合分 | 大黄道 + 小黄道 | 例：天刑 -15 + 成 +5 = **-10** |

黄道分**直接进入总分**，不再按“五行大吉+黄道大吉”组合额外升降级（等级 = 总分纯函数，2026-09-02 拍板）。

### 10.3 太阳太阴到山到向

- 太阳/太阴到山、到向按日躔与山向比对；未到山到向计 0 分并明示。

### 10.4 历法派生项

胎神（日/月/时三方）、母仓、土王用事等，按各自表值与事项口径进入神煞层或展示层。

# 第四部分 评分总则与五大核心事项

## 第 11 章 总分公式与计算顺序

```text
五行评分 = 基础分 100
         + 神煞得分
         + 宜事得分
         + 忌事得分（负）
         + 十二长生得分
         + 地支关系得分
         + 纳音匹配得分

总分 final = 五行评分
           + 月令得分
           + 喜用神得分
           + 相主得分
           + 黄道得分
           + 太阳太阴得分
           + 三煞扣分（sansha_penalty）
           + 向方扣分（xiangfang_penalty）
           + 出行方位得分（仅出行）
           + 坐山得分
           + 克山运得分
           + 玄空飞星（可选）
```

实现定位：`modules/评分器.py` 的 `Scorer.score()`（总分合成行见 L2422；五行评分构成注释见 L2420）。

**计算顺序**（不可颠倒）：

1. 四柱 → 2. 神煞发射与分项 → 3. 五行评分 → 4. 月令/喜用/相主 → 5. 黄道/太阳太阴 → 6. 三煞/向方/出行 → 7. 硬门槛判定 → 8. 等级映射。

**硬门槛优先**：任一硬否决命中 → `final_score = 0`、等级 `❌ 凶`（`评分器.py` L2662–2669）。

### 12.1 基础分

- 固定 **100**。

| 状态 | 分值 | 状态 | 分值 |

**月柱 ×1.5**（取整）。示例：月柱戌·衰 +2×1.5 = +3。

### 12.3 地支关系（四柱六对合计）

| 关系 | 分值 | 备注 |
| --- | --- | --- |
| 六合 | +8 | |
| 半合 | +6 | 生地/墓地/拱合同值 |
| 六冲 | **-15** | |
| 六害 | -6 | |
| 相刑 | -8 | 含自刑/恃势之刑 |
| 相破 | -4 | |
| 伏吟（同支非自刑） | 0 | 不计分 |

时柱参与的关系在详情中单列归集，**不重复累加**（全局合计 = 年月日三柱 + 时柱参与）。

### 12.4 月令得分

- 构成：日主在月令的旺衰（旺/相/休/囚/死）+ 月令与日支关系。
- 典型满分区间约 +10（旺衰 +5、支支关系 +5），随月支与日干变化。

### 12.5 喜用神

- 需事主八字才计算；未提供事主出生信息时计 **0**，并在详情注明“日课与事主八字无明显冲突”。

### 12.6 神煞得分

- 唯一来源：`事项标准.SHENSHA_SCORES` 注册键 + `神煞配置表.SHEN_SHA_WEIGHT`。
- 双通道去重：神煞通道与建除/宜忌通道同源项**只计一次**（H1 红线）。
- 分值显著项示例：岁德 +20、鸣吠日 +15、三合/六合 +8~+10、鲁班煞 -20、土王用事 -20、太岁堆黄 -15。

### 12.7 黄道 / 太阳太阴

见第 10 章；黄道综合分直接进总分，太阳太阴未到山到向为 0。

### 12.8 三煞与向方（两个独立扣分通道）

**通道一：三煞扣分 `sansha_penalty`**（`评分器.py` L1770–1883，写入 `sansha_info['sansha_penalty']`）

| 形态 | 分值 | 否决 |
| --- | --- | --- |
| 年三煞·坐山/修方 | — | **是**（归零，走硬门槛） |
| 年三煞·向方 | -25 | 否 |
| 月三煞·坐山/修方 | -20 | 否（§63） |
| 月三煞·日柱临方 | -20 | 否 |
| 月三煞·时柱临方 | -15 | 否 |
| 月三煞·向方 | -20 | 否 |
| 日三煞·坐山/修方 | -15 | 否 |
| 日三煞·时柱临方 | -10 | 否 |
| 日三煞·向方 | -15 | 否 |
| 月、日三煞同时犯时柱 | 另加 -15（叠犯加重） | 否 |

**通道二：向方扣分 `xiangfang_penalty`**（`评分器.py` L1772–1776、L1834–1886，写入 `sansha_info['xiangfang_penalty']`）

| 形态 | 分值 | 否决 |
| --- | --- | --- |
| 向方月破 | -20（PENDING 档，待轻重层专项规范） | 否 |

- 两通道**分账独立**：三煞(向方) 记入 `sansha_penalty`，向方月破记入 `xiangfang_penalty`；两者互不覆盖。
- 口径：**向侧一律重扣分、不否决**（`(向方)` 项已被硬过滤排除在否决之外），呼应“可向不可坐”。
- 出行/开业对两个通道整体旁路（`sansha_applicable=False`），填报坐山不影响分数。

示例（247 分课）：仅三煞通道“年向 -25、月向 -20、日向 -15”合计 **-60**，当日未触向方月破，故 `xiangfang_penalty = 0`。

### 12.9 相主得分 / 坐山分

- 相主：按年命/生肖/日柱冲刑分档加减；硬冲 → 否决。
- 坐山/克山运：仙命纳音 × 坐山五行；「坐山克仙命」→ 等级封顶 `❌ 凶`，不改总分（§59.9）。

### 12.10 玄空飞星

- 仅“正五行+玄空飞星”模式计入。

## 第 13 章 等级映射与封顶规则

### 13.1 等级 = 总分纯函数

| 总分 | 等级 |
| --- | --- |
| ≥ 105 | ★★★★★ 上吉 |
| 100–104 | ★★★★ 大吉 |
| 85–99 | ★★★ 吉 |
| 75–84 | ★★ 中吉 |
| 60–74 | ★ 平 |
| < 60 | ❌ 凶 |

### 13.2 三条例外（优先于上表）

1. **五行评分 < 60** → 直接判凶（五行根基不稳，不许靠月令/黄道抬级）。
2. **坐山克仙命** → 等级封顶 `❌ 凶`；有制化时标注“有制化：X”，但**仍为凶**（制化只解除否决、不改凶性）。
3. **硬否决** → `final_score = 0`、`❌ 凶`，忌项同步显示否决原因。

## 第 17 章 口径红线与实现边界

1. **双通道去重（H1）**：神煞与建除/宜忌同源项只计一次，禁止重复加分。
2. **无证据不放宽**：三库无明文者，不得新增豁免或降档；只能标“待证”或“仅展示”。
3. **展示 ≠ 计分**：`score=0` 的识别展示项必须写明原因，不得暗中参与总分。
4. **硬门槛优先于宜项**：相主、三煞、山家封禁、建除当日之忌优先；通书宜项不得覆盖硬禁忌。
5. **分值唯一来源**：分值只允许来自 `SHENSHA_SCORES` / `SHEN_SHA_WEIGHT`，规则文件不得内联分值。
6. **等级不改总分**：坐山克仙命只封顶等级、不篡改总分（排序仍反映真实分）。
7. **禁止以“验证通过”迁就表源**：不得改表去迎合实现；表源改动须先取证、后拍板。
