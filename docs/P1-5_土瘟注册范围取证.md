## 一、概念辨析（重要前置）

"土瘟"在三库中存在**同名异实**：

| 来源 | 土瘟含义 | 定性 |
|------|---------|------|
| 协纪卷四义例、卷三十四 | "满为土瘟，为四利丧门，又为天富，**小吉**" | 建除十二神之"满"日，**小吉** |
| 考原卷五 | "满为土瘟，为四利丧门，又为天富，小吉" | 同上 |
| 陈书 p1021 | "丧门煞又即土瘟煞...不可动土行丧" | 凶煞，忌动土 |
| 陈书 p748 | "土禁土府土瘟土符止忌破土不忌安葬" | 忌破土，不忌安葬 |
| 软件 `_is_tuwen` | 四季土旺日（寅月丑日、卯月辰日…） | 凶煞 -20 |

**结论**：软件中土瘟的推排法（四季土旺日）与陈书一致，与协纪/考原的建除满日不同。协纪/考原的"土瘟=满日小吉"不能直接否定软件的土瘟凶煞定性，但说明该词存在概念混淆，需以陈书（推排法一致）为土瘟宜忌的主参照。

## 三、判定汇总

- **有载（3项）**：修造、动土、作灶
- **无载（10项）**：拆舍、入宅、移徙、嫁娶、开业、出行、安床、入学、求医、签约
- **语义等价（1项，明确不忌）**：安葬（陈书明言"止忌破土不忌安葬"）

## 四、概念混淆风险

1. 协纪/考原的"土瘟=满日小吉"与软件"土瘟=四季土旺日凶煞"推排法不同，属同名异实。
2. 软件将土瘟作为14事项通用凶煞(-20)，但陈书仅忌动土类事项。
3. 安葬为明确反例（陈书明言不忌），软件注册-20属误判。

## 六、概念卡：土瘟（四季土旺日）与土瘟小吉（建除满日）分名对照（2026-10-18 正名批）

> 拍板（2026-10-18）：批准正名，但必须"分名不合并"。只改名称/文档，不改分值、不改判。

### 6.1 两个同名异实的概念

| | 土瘟（四季土旺日） | 土瘟小吉（建除满日） |
|---|---|---|
| 推排法 | 四季土旺用事之日（寅月丑日、卯月辰日、巳月辰日、午月未日、申月戌日、酉月亥日、亥月丑日、子月寅日……即三合土局前一位） | 建除十二神轮值之"满"日（月建起建，顺数至第七位） |
| 典据 | 陈书 p1021「丧门煞又即土瘟煞……不可动土行丧」、p748「土禁土府土瘟土符止忌破土不忌安葬」 | 协纪卷四·义例二（279222）引《选择宗镜》「除为四利太阳小吉 **满为土瘟** 为四利丧门 又为天富小吉」；协纪卷三十四·利用（279252）同；考原卷五·月建十二神（359080）「满为土瘟，为四利丧门，又为天富，小吉」 |
| 定性 | 凶煞，忌动土类 | 别名体系中的一环，**小吉**（又为天富小吉） |
| 软件状态 | 已注册（修造/动土/作灶有陈书载；其余事项 P2 待证；安葬已删） | **未注册，本批亦不引入**（建除满日另有"建星吉日"通道按事项承载） |

### 6.2 正名方案（分名不合并）

**约束查证**：显示名与分值键强耦合——`_add_shensha`（神煞基类）内部按 name 调 `shensha_score(_std_event, name)`，若把注册名改为"土瘟（四季土旺日）"将连锁 `SHENSHA_SCORES` 12+ 个分值键（('修造','土瘟')、('动土','土瘟')……及 ('*','土瘟') 通配）并破坏既有键锁定测试。故正名采用**最小改动**：

1. **注册名 '土瘟' 锚不动**（分值键零变化、分值零变化、判定零变化）；
2. **描述串（UI 文案）加限定词"四季土旺日"+ 明示"忌动土"**，共 5 处发射点：
   - 神煞基类.py（通用链）：「土瘟（四季土旺日），忌动土」
   - 修造神煞.py :82：「土瘟（四季土旺日），忌动土修造，犯之主病」
   - 修造神煞.py :283：「土瘟（四季土旺日）忌动土修造」
   - 通用神煞.py :254：「土瘟（四季土旺日）临日，大忌动土」
   - 安床神煞.py :115：「土瘟（四季土旺日）不宜安床」
3. **"土瘟小吉（建除满日）"另立概念**：软件当前不注册该概念；如未来按典据引入，应使用独立名称"土瘟小吉（建除满日）"并走建除满日体系，**不得**与"土瘟（四季土旺日）"合并，也**不得**因正名把"小吉"属性带入忌动土的土瘟。

### 6.3 分名不合并的三条禁令

1. 禁止把"满为土瘟小吉"的吉性并入"土瘟（四季土旺日）"的评分或文案；
2. 禁止把四季土旺日土瘟的"-20"套用到建除满日；
3. 禁止合并两个概念的注册键、谓词与文档表述。
