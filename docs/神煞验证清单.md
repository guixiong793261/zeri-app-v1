> 本清单跟踪每个神煞规则的穷举验证状态。
> **验证框架**：`tests/shensha_verify_engine.py`（公共引擎）+ `tests/verify_<神煞名>.py`（每神煞独立文件：仅声明权威真值表 + 入口适配器）。

## 验证框架说明

每个 `verify_<名>.py` 结构：
1. 硬编码权威真值表（经典规则）
2. `expected(inp)` — 真值函数
3. `adapter(inp)` — 调用软件真实实现
4. 构造 `ShenShaCase` 并交给 `run_cli`

引擎输出：命中数 / 误命中 / 漏命中 / 值不等 / 不可用，退出码 0=通过 1=失败。
