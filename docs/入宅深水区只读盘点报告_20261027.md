## 二、Q1｜事主生肖/年命 冲 大门朝向（向首）判定

### 2.1 结论

**"年命 × 大门朝向（向首）"这条判定根本不存在。** 现有与"向"相关的判定只有三类，且全部与事主年命无关：

1. **向首 × 太岁**：向首正对太岁方 → 一票否决（`评分器.py` L3084-3087，须填山向）；
2. **向首 × 三煞/月破**：向方判定层 `xiangfang_*`，重扣分不否决（`评分器.py` L1727-1779，须填山向）；
3. **向首 × 日课四柱**：仅通过"冲坐山"等价承接（日支临坐山＝临向首之冲），在规则层文本（`修造规则.py` L643-660）。

事主年命这一侧只与**日课四柱**发生关系（日支/月支/时支/流年支），**不与坐山、也不与向首发生任何关系**。

### 2.2 实测量化（2026-06-18，子山午向）

| 事主年命 | 与向首/坐山关系 | score | 相主/神煞焦点 | veto |
|---|---|---|---|---|
| 亥（无关） | 无 | 8 | 刑宅主 -12、相主 -20 | 无 |
| **午（＝向首）** | 年命临向首 | **30** | 无 | 无 |
| **子（＝坐山）** | 年命临坐山 | 19 | 相主 0（无明细） | 无 |

> 年命"临向首"比"无关"反而高 22 分——差异全部来自相主/流年档，**没有任何向首专项扣分或警示**。即用户担心的"事主生肖冲大门"在系统里既没有否决、也没有扣分、也没有提示。

### 2.3 顺带查出的相主链三处口径分裂（同属 Q1）

**(a) 年命六冲双通道重复计分（冲宅主 -25 ＋ 相主 -30）**

- `入宅神煞.py` L334-341：取 `owners[0]` 的 `生肖`，`日支 == 冲(生肖)` → `冲宅主 -25`（**无注册键**，硬编码兜底）。
- `评分器.py` L5177-5178：`owner_year_zhi = owner['生肖']`；L5208-5214：同年命六冲 → 相主 **-30** 并打 `[硬性门槛]` → L2322 一票否决。
- 实测（2026-06-18，事主年支巳）：两笔同落 **-55**，否决由相主承担，冲宅主纯粹重复。

**(b) 多事主降级不否决**

`评分器.py` L5309-5310：非首位事主按"辅助/半权重"处理（`_zaozhu_weight<1`），六冲降为 **-15、不否决**；`入宅神煞.py` L334 只取 `owners[0]`，第 2+ 人连 `冲宅主` 都没有。
实测 owners=[申, 巳]（第二人事主年支巳冲日支亥）：score 13，**veto 为空**，明细「乙生肖巳与日课日支亥六冲（年命六冲）（辅助，半权重不否决），-15分」。

> 入宅是"全家迁入"，第二事主（配偶/子女）年命冲日支却只 -15 不否决，与"宅主一票否决"的传统口径明显不对称。

**(c) 外部 `生肖` 传中文字时静默死链**

- `check_liuchong('亥','蛇')` → `False`（只有地支表）。
- 若调用方以"蛇/马/猪"这类**中文字**传 `生肖`，相主年命链全部失效，只剩 `冲宅主 -25`（非否决）。
- GUI 现行路径传的是地支（`主程序.py` L3962、L4773 `'生肖': year_zhi`），故**当前 GUI 不触发**；但批量/外部接口/历史数据回放会命中。

### 2.4 未填山向＝向首判定直接消失，且零警示

- `入宅` 画像 `need_shan=True`，但评分器对 `shan_xiang=None` **不产生任何校验警告**。
- 实测 2026-06-18：无山向 → **62 ★平**，`warnings=无`；同日填「子山午向」→ **0 ❌** ＋ 3 条否决（犯年三煞／向首正对太岁／犯岁破）。
- 无山向时仍有三煞日柱扣分 -50（年三煞(日柱)-30＋月三煞(日柱)-20），会掩盖"向首从未被审"的事实。

## 四、Q3｜入宅吉神：天德、月德是否被吞没/给分不足

### 4.1 结论：**未被吞没，给分足**（现状正常）

| 吉神 | 2026 命中天数 | 发射分 | 注册键 | 判定 |

- 基类与子类同日发射同名（`神煞基类.py` L1782-1788 vs `入宅神煞.py` L167-181），经 `_add_shensha` 先到先得去重，**值相同**，无吞没、无双计。
- 天德/月德同时是"克山运"制化关键词（`修造规则.py` L878），入宅继承后制化链有效。

### 4.2 但"吉神给分足"反而放大了 Q2 的凶煞失灵

- 入宅 74 个神煞名中正向项占多数，叠加空间大；受死日仅 -15 时仍可冲到 102 大吉（§3.2）。
- 结论：**问题不在吉神给分不足，而在凶煞否决力度不足**，两者叠加造成"凶日大吉"。

### 4.3 吉神侧的一处双计（抬分）

- `合宅主 +15`（`入宅神煞.py` L343-344，年支六合/三合）与 `相主 +15`（`评分器.py` L5240-5248，年支六合）对**同一关系各算一次**。
- 实测 2026-06-18 事主年支寅：score 65，`合宅主 15` ＋ 相主明细「年支合 +15」两笔同落（合计 +30）。
- 与 §2.3(a) 的负向双计同源：**入宅没有像 §187 修造那样把相主收口为唯一事实源**。
