## 四、生搬硬套嫌疑点

### 🔴 嫌疑点 1（高优先级）：开业三煞(月柱)否决——"出行坐山伪逻辑"同类问题

**现象**：开业 `mountain_center=False`、`need_shan=False`，无固定坐山。但评分器按"事主中心"口径（[L1759-1763](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L1759-L1763)）对开业执行"年三煞犯月柱→一票否决"，2026 年触发 **43 天**，占开业否决天数的 25.6%。

**对比出行**：出行同样 `mountain_center=False`、无坐山，但已于 2026-10-30（001 §201）通过 `_TRAVEL_SANSHA_KEYS` 旁路表（[评分器.py L150-157](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L150-L157)）将全部三煞判键置空，旁路应用于 [L1729-1732](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L1729-L1732)。出行否决率因此降至 16.71%。

**典据依据**（出行取证报告 §四）：协纪/考原/陈书全卷「出行三煞/坐山三煞」命中 0 处；三煞本为"可向不可坐"的修方禁忌，无固定坐山的事项无"坐煞"可言。

**结论**：开业与出行同属"无坐山"事项，三煞月柱否决属生搬硬套——把嫁娶（事主中心·四柱论命）的三煞口径套到开业上。开业否决率 46.03% 对比出行 16.71%，差值 29.3pp 主要由此项贡献。**建议立项对勘**：开业是否应同步三煞旁路。

### 🟡 嫌疑点 2（中优先级）：作灶 mountain_center=True 与 need_shan=False 分类矛盾

**现象**：作灶画像 `mountain_center=True`（[事项标准.py L226-227](file:///d:/自编择日软件/专业级正五行择日软件/modules/事项标准.py#L226-L227)）但 `need_shan=False`。作灶实际无坐山输入，却被归入"山向中心"组，导致：
- 三煞四柱临方不否决（`_pillar_veto_mode=False`，[评分器.py L1755](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py#L1755)）——这恰好使作灶免于三煞月柱否决，**结果上合理但分类逻辑自相矛盾**。
- 坐山三煞否决（年三煞(山向)）因无坐山永不触发。

**对比**：安床同样 `mountain_center=True` + `need_shan=False`，相同矛盾。

**结论**：分类标签与实际输入不匹配。作灶/安床本质是"事主中心+方位辅助"（灶向/床位朝向），非真正"坐山修方"。建议重新审视 `mountain_center` 定义，或拆出"方位辅助"子类。

### 🟡 嫌疑点 3（中优先级）：安床无月破/四离四绝否决——与作灶/嫁娶口径不一

**现象**：安床规则层无 veto，月破日仅扣 -30 分、四离四绝仅扣 -35 分，不作一票否决。而同档大事（作灶、嫁娶）月破/四离四绝均为规则层一票否决。

**传统口径**：月破"诸事不宜"、四离四绝"大事不宜"，通书层面属普适硬忌。安床作为大事，仅扣分不否决可能偏宽。

**结论**：安床否决率 33.15%（低于作灶 50.41%）部分源于此口径缺失。**建议立项对勘**：安床是否应补月破/四离四绝规则层否决。

### 🟢 嫌疑点 4（低优先级）：作灶 veto_keywords 含死链"岁破日"

**现象**：作灶 `veto_keywords` 含 `'岁破日'`（[作灶规则.py L283](file:///d:/自编择日软件/专业级正五行择日软件/modules/rules/作灶规则.py#L283)），但实际 ji 文本为 `与{name}岁破，忌作灶`（[L344](file:///d:/自编择日软件/专业级正五行择日软件/modules/rules/作灶规则.py#L344)），子串"岁破日"永不匹配。该关键词为死链。

**影响**：无实际行为影响（岁破日课普适已在岁破批删除，仅保留本命语境"与事主岁破"，由评分器 `_HARD_VETO_KEYWORDS` 的"岁破"兜底）。建议清理死链关键词。

## 五、是否需要深水区大修的结论与建议

### 结论

| 通道 | 是否需要大修 | 理由 |
|------|------------|------|
| **开业** | **需要（P0）** | 三煞月柱否决属"出行伪逻辑"同类生搬硬套，否决率虚高约 29pp，必须立项对勘三煞旁路 |
| **作灶** | **需要（P1）** | 否决率偏高（50.41%）但主因为作灶专属规则（逐月忌日/灶君朝天），典据待核；mountain_center 分类矛盾需澄清；死链需清理 |
| **安床** | **需要（P1）** | 无月破/四离四绝否决与作灶/嫁娶口径不一；否决率偏低可能漏否决；mountain_center 分类矛盾同作灶 |

### 总体判断

三通道**未达到深修通道的否决权口径清晰度**。核心问题不是"否决率异常"（数值在 33%-50% 区间，与修造 46.58%/入宅 32.6% 可比），而是**否决权来源的典据正当性**：
1. 开业三煞月柱否决缺乏典据（同出行已证伪），属"拿来主义"套嫁娶口径。
2. 安床缺月破/四离四绝否决，与通书"诸事不宜"普适硬忌矛盾。
3. 作灶/安床 `mountain_center` 标签与 `need_shan=False` 自相矛盾。

**不建议**直接按否决率数值高低做"偏高/偏低"判断——三通道否决率数值本身不离谱，但**否决权的构成需要逐项典据对勘**。

### 建议优先级

1. **P0-开业三煞旁路对勘**：复用出行取证结论，判定开业是否同步 `_TRAVEL_SANSHA_KEYS` 旁路。预计否决率从 46% 降至 ~25%。
2. **P1-安床月破/四离四绝否决补全**：对勘通书"月破诸事不宜"是否覆盖安床，决定是否补规则层 veto。
3. **P1-作灶/安床 mountain_center 分类澄清**：重新定义"山向中心"判定条件（以 need_shan 为准？或以实际坐山输入为准？）。
4. **P2-作灶死链清理 + 逐月忌日/灶君朝天典据复核**：清理"岁破日"死链；对勘逐月作灶忌日（《居家必用事类全集》）与灶君朝天（太微宫五日）的适用边界。
