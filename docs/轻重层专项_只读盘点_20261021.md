## 1. 判据冻结承诺（P0，先承诺后裁断）

> 目的：防止「先看软件现状再倒推典据」。本判据在逐项裁断之前冻结，下列裁断不得越界。

### 1.1 证据级别（L 级，按力度证据强度）

| 级 | 定义 | 可支撑的结论 |
|---|---|---|
| **L1** | 比较级／同级明文：「甚於Ｘ」「次於Ｘ」「不若Ｘ」「与Ｘ同」「下一等」「皆上吉」「义同Ｘ」 | 可定**相对序位**与**等值对齐** |
| **L2** | 定性力度词（无比较对象）：最凶／大凶／重／中／轻／不甚凶／其力轻微／凶曜 | 只能定**档**，不能定绝对数值 |
| **L3** | 仅忌项范围（无任何力度词） | 仅可校正**明显倒挂**，不得主动改档 |
| **L4** | 三库零力度载（有起例、有用忌，无轻重语） | **不得**作为扣分依据；须降档或标注「推定值」 |

### 1.2 动作档（A/B/C/D）

- **A 维持**：L1/L2 支持现分值的方向与级差。
- **B 调档**：L1 明确同级或序位不符，或 L3 明确倒挂。
- **C 降 0 展示**：L4 且忌项面窄／无民事通道。
- **D 移交其他层**：问题实为口径层／制化层／表源层，轻重层不动（只标注）。

### 1.3 六条硬约束（冻结）

1. **不新增刻度**：仅在现有刻度 `0 / 8 / 10 / 12 / 15 / 18 / 20 / 22 / 25 / 30 / 40` 内取值。
2. **单条幅度 ≤ 一档**（±3～5），除 L1 明文「同级」或「倒挂」外不得跨档。
3. **L4 不得维持高扣分**：凡三库零力度载者，不得以「看起来合适」为由保留原值。
4. **L1 优先**：有比较级明文者，一律以明文序位为准，不以忌项多寡反推。
5. **哨兵不可破**：2026-11-04 入宅 = 221/上吉。任何建议若改变该日分值，须单列并给出替代方案。
6. **本轮只出建议**：不改 `SHENSHA_SCORES`、不改发射、不改口径、不改制化。

### 1.4 三库层级沿用

协纪为主锚 → 考原互校 → 陈书第三参照；分歧仅标注，不自行取舍、不择优放宽（沿用 v1.0）。

### 1.5 附带发现：协纪自带的「六等」分级（仅作语义参照）

> 卷十 279228 表例附后按语：
> 「今参互较量……余分为六等：其上吉足胜凶从宜不从忌；上次吉足抵凶遇德从宜不从忌不遇从宜亦从忌；
> 中等吉不抵凶遇德则吉胜从宜不从忌不遇从忌不从宜；中次凶胜於吉遇德始相抵从宜亦从忌不遇从忌不从宜；
> 其下凶又逢凶遇德从忌不从宜不遇诸事皆忌；最下凶叠大凶遇德仍诸事皆忌。」

该六等的**分级对象是「吉凶并日」**（含德神并临后的整日吉凶），不是单个神煞的分值。
故本轮**只借其语义档位**（从事/不忌 → 从宜从忌 → 诸事皆忌）作为「轻/中/重/最重」的语义校准，
**不据以推导任何数值**，避免把「整日分级」误用为「单煞计分」。
