## 1. 目标与范围

**目标**：回答四问——
1. 建除十二神（建除满平定执破危成收开闭）当前**表源（起例）**是否有误；
2. 制化矩阵依赖「建日/除日/平日」的行，**谓词缺什么**、依据何在；
3. 建除十二神的**吉凶等级与所忌核心事项**；
4. 现有触发与扣分，与**轻重层冻结集**对账是否「超范围」或「分值倒挂」。

**范围内**：`modules/`、`modules/rules/`、`modules/shensha/` 中一切建除判定与计分路径；
协纪卷四/卷十、考原、陈书三库对勘。
**范围外**：任何代码修改、分值调整、六副本同步、评分公式重构。

## 4. 典据对勘（已取证部分）

### 4.1 卷四·义例二·建除十二神（`C:\Temp\xj_full\279222.txt` L43-101, L108-110）

- **起例**：「历家以建除满平定执破危成收开闭凡十二日周而复始，观所值以定吉凶，每月交节则叠两值日，其法从月建上起建，与斗杓所指相应，**如正月建寅则寅日起建顺行十二辰**是也。」
- **吉凶主锚（考原）**：「除危定执成开为吉，建破平收满闭为凶，历书所谓『建满平收黑，除危定执黄，成开皆可用，闭破不相当』者也。」
- **力度互校（选择宗镜）**：「平成开危最吉，定除次吉，破大凶」；又「建破平收俗之所忌，惟破日最凶，建日吉多可用，平日甚吉，收日吉多无妨」。
- **逐星同位与核心忌**：
  - 建【兵福 小时 土府】——忌结姻亲、开仓库；不利行师（J6 条「建日吉多可用」为相对条款）
  - 除【吉期 兵宝】——吉期宜会亲姻、出军行师
  - 满【福德 天巫 天狗】——福德宜祀神祗求福愿修宫室献封章；天巫宜合药请医；戌日满为天狗，忌祷祀
  - 平【天罡/河魁 死神】——死神忌请医服药、出师征讨、种植树木、进人纳畜
  - 定【时隂 官符 死气】——时隂宜运谋算画计策、睦子孙、会亲友；官符忌拜官视事、上表章、陈词讼；死气忌战鬬、疗病求医
  - 执【枝德 小耗】——枝德宜修造筑垣；小耗忌经营种莳、纳财交易、开市
  - 破【大耗】——忌营库藏、出财物、远经求取债负
  - 危——宗镜称极富星/谷将星/龙德吉，但「无其义」，今历家不用
  - 成【天医 天喜】——天医宜请药避病、寻巫祷祀
  - 开【时阳 生气】——时阳宜叙婚姻、行宴乐；生气宜修筑城垒、开道沟渠、起土修营
  - 闭【血支】——忌针刺出血
