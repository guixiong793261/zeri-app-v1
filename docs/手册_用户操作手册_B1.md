## 1. 三分钟上手

**最短路径（出一张吉日红帖）**

1. 事项类型选「嫁娶」（默认）。
2. 填开始/结束日期。
3. 点「开始择日」。
4. 在结果表里挑评分最高、等级最高的一行，双击看详情。
5. 点「择日贴」→ 选日期与时辰 → 预览 → 打印或发手机。

> 提示：不填事主信息也能出结果，但**相主（生肖冲、日柱冲刑）不会参与计算**，重要事项建议填全。

## 3. 输入参数逐项说明

### 3.1 事项类型（16 个下拉项）

| 下拉项 | 归入规范事项 | 是否需要坐山 | 说明 |
| --- | --- | --- | --- |
| 嫁娶 / 订婚 / 纳采 | 嫁娶 | 否 | 事主中心，男女命平权 |
| 修造 | 修造 | **是** | 坐山三煞、扶山补龙 |
| 动土 | 动土 | **是** | 破土类，重土府/土王 |
| 拆舍 | 拆舍 | **是** | 拆除类，宜忌收窄 |
| 入宅 / 移徙 | 入宅 | 是（向首） | 受死日、红嘴朱雀、年命冲大门 |
| 开业 | 开业 | 否 | 已旁路三煞月柱否决 |
| 出行 | 出行 | **否（禁止填坐山）** | 看出发方向，不看坐山 |
| 安床 | 安床 | 否 | 看床位朝向 |
| 作灶 | 作灶 | 否 | 灶向、灶位、主事人 |
| 安葬 | 安葬 | **必选** | 仙命、旺命、重丧、四大凶日 |
| 入学 / 求医 / 签约 | 通用 | 否 | 走通用检查器 |

> 关键差别：**出行不看坐山**；**安葬必须选坐山**；其余坐山事项只影响山家相关分项。

#### 「📖 择日通关指南」面板（3.1 附）

面板位置：**主界面「特殊选项」下方**（默认折叠）与**「条件择日」设置窗顶部**（默认展开）。
切换事项下拉框时，面板**自动展开并按该事项刷新**，无需手动查询。

面板分两栏，绿字为加分要诀、红字为绝对红线：

| 事项 | 🌟 最优条件（择要） | 🚫 一票否决（择要） |
| --- | --- | --- |
| 嫁娶 | 德神、不将日、三合六合、大利月 | 月破、四离四绝、受死日、冲新人年命 |
| 修造 | 德神、扶山补龙、太阳太阴到山/到向 | 年三煞 × 坐山、山家封禁、双干正阴府、冲事主年命 |
| 入宅 | 德神、三合六合、太阳到山/向、天赦母仓 | 受死日、红嘴朱雀、年三煞 × 坐山、年命冲大门 |
| 安葬 | 德神、太阳太阴到山、生气、天赦 | 复日/三丧、四离四绝、年三煞 × 坐山、冲事主年命 |
| 出行 | 德神、三合六合、出行吉日吉时 | 月破、四离四绝、往亡、冲事主年命 |
| 作灶 | 德神、三合六合、天赦王日 | 月破、四离四绝、冲主妇/宅主、灶君朝天 |
| 安床 | 德神、三合六合、天赦王日 | 月破、四离四绝、冲安床人、红嘴朱雀（方位门控） |
| 开业 | 德神、三合六合、天赦王日生气 | 冲事主年命（本事项无专属凶煞否决） |

> 面板文案是**静态说明表**（`modules/事项标准.py` 的 `EVENT_OPTIMAL_RULES`），
> 只解释「该看什么」，不参与计分与否决；某一天到底吉凶几分，仍以日课详情为准。

面板不只用来读，还能直接当工具用：

- **点蓝字即勾选**：绿栏中被标成蓝色下划线的吉神名（如「天德贵人」「不将日」）可单击，
  下方「吉神条件」里的同名复选框立即打钩，不用再逐行找。
- **🌟 一键选中最优吉神**：把该事项指南提到、且下方确有复选框的吉神一次性全部勾选，
  并自动勾选「所勾吉神满足任意一项即可」；弹窗会列出实际勾选了哪几项。
- **吉神条件的两种口径**：「吉神条件」区顶部新增开关——勾上「满足任意一项即可」时，
  命中其中任一吉神即入选（一键选中会自动勾上）；不勾则为原有的「全部命中」求交口径，
  适合自己手工叠加严条件。多项吉神若按求交，几乎无日可中（嫁娶实测全年为 0），
  因此多选时建议开启「任一命中」。
- **互斥吉神只取其一**：同一农历月不可能既是「大利月」又是「小利月」，两者同时勾选会让
  吉神条件求交后无结果。因此点选或一键勾选利月时，系统只保留一个（优先「大利月」），
  自动取消另一个。
- **🚫 一键避开绝对红线**：勾选「排除凶日」与「排除有忌项的日课」。三煞×坐山、岁破、月破、
  四离四绝、重丧、受死日、红嘴朱雀、双干正阴府、山家封禁、相主冲命这些红线由评分层直接判否决，
  本来就不会进入可选结果，无需手工重复设置。
- 红栏「一票否决」是底层自动拦截项，只作提示，不可点击。

> 💡 需要按「旺相得令、五行相生、山向大利」等复杂条件自动挑日子？
> 这些条件无法在静态筛选里穷举，请前往【精准择时】使用智能反推。

### 3.2 日期与时间

- 开始/结束日期决定扫描区间，区间内**每一天**独立评分。
- 时辰用于单日精算与红帖；区间扫描默认取推荐时柱（系统择定），详情里会注明。

### 3.3 宅型与山向

| 字段 | 取值 | 适用事项 |
| --- | --- | --- |
| 宅型 | 阳宅 / 阴宅 | 修造、动土、拆舍、入宅 |
| 山向 | 二十四山（如「坤山艮向」） | 同上 |
| 兼向 | 正中 / 兼左 / 兼右 | 同上，影响分金 |
| 坐山 | 二十四山单字（如「坤」） | 修造、安葬等 |
| 罗盘 | 弹窗点选 | 不确定山向时 |

> 填错坐山会直接改变三煞、扶山、分金的结论，**比填错日期更严重**。

### 3.4 事主信息

- 每个方案可填：姓名、性别、公历/农历、出生年月日（时辰可选）。
- 只填姓名不填生日：该事主**不参与相主计算**，结果照常出。
- **空事主的代价（001 §238）**：未填任何事主时，核验列「相主」项判 **N/A 不计 ✓**，永远不可能出现全✓。想要真实的全✓评估，务必先填事主年命与生日——否则高分会是「缺一维核验」的假繁荣。
- 多个事主：系统按「平权」逐人校验，取**最严**结论（详见白皮书第四部分）。

### 3.5 输出模式

| 模式 | 结果表表现 | 用途 |
| --- | --- | --- |
| 正常平分（含扣分） | 显示总分与各分项，凶日保留 | 日常挑选 |
| 不合格输出（仅显示否决/凶日） | 「核心吉神」列改为「不合格原因」 | 复盘“为什么这天被否” |

### 3.6 结果表的 13 列

| 列 | 含义 | 读法 |
| --- | --- | --- |
| 日期/四柱 | 公历 + 年/月/日/时四柱两行 | 先看四柱是否与事主相冲 |
| 评分 | 综合总分 | 排序主键 |
| 等级 | ★ 档位或「❌ 凶」 | 一票否决会归零 |
| 核验 | 满分核验「N/维数 ✓」，达标项数 | **全✓整行金底高亮；悬停出逐项明细** |
| 五行得分 / 月令 / 喜用 / 黄道 | 分项分 | 定位“分从哪来”；嫁娶的黄道分已并入五行评分，该格显示「已并入」 |
| 地支关系 | 四柱内的合冲刑害（前 2 条） | 看合局与刑冲 |
| 核心吉神 | 命局贵人 + ≥10 分高权重神煞，最多 4 个 | **悬停出完整列表** |
| 利月 | 嫁娶利月标记：大利月 / 小利月 / 普通月份 | 嫁娶专用，条件择日同样显示 |
| 事主信息 | 参与计算的事主摘要 | 核对是否漏填 |
| 玄空 | 飞星信息（开启时） | 可选 |

`核心吉神` 列的口径：命局贵人（天乙/文昌等）在前，其后按神煞分值降序；≤5 分的点缀型杂神不显示；被截断时列尾有「…」，鼠标悬停弹出「命局贵人」与「神煞吉神（≥10分）」两段完整列表。

`核验` 列的口径（001 §234/§238，2026-11-09 修订）：与反推榜「满分核验」同一判据（modules/排序键.py 的 perfect_profile）。专属事项（修造/动土、嫁娶/订婚/纳采、入宅/移徙、安葬、出行）为 **6 维** = 得令、合局、德神、事项专属核心、**相主**、硬忌；其他事项为 **5 维** = 得令、合局、相主、德神、硬忌。事项专属核心随事项切换（修造/动土→扶山补龙，嫁娶/订婚/纳采→利月与吉日，入宅/移徙→全家相合，安葬→仙命相合，出行→出发方向）。显示「N/维数 ✓」；**未填事主时「相主」判 N/A 不计入 ✓**，不会再出现空事主全✓；从文件导入的历史结果无评分明细，显示「—」。核验只做展示，不改变评分与排序。

**核验筛选下拉**（结果表上方「清空结果」旁）：四档过滤——`全部` / `极品(无警告)` / `大吉(≥4✓)` / `优吉(2-3✓)`。选中即重渲染，随时切回「全部」；**极品 = 日课校验无警告**（详情页【日课校验】结论为 ✅ 通过，ERROR=0 且 WARN=0），极品行整行金底（#FFE680）高亮。档位口径与反推面板「④ 优吉」「⑤ 大吉」页签一致：大吉 = ≥4✓，优吉 = 2–3✓；满分核验 ✓ 数只用于分档与展示，不再决定极品。

## 4. 开始择日与读结果

1. 选事项 → 填区间 → 需要时填山向/事主 → 点「开始择日」。
2. 结果按评分从高到低排序，星级色带区分。
3. 先看**等级**，再看**评分**，最后看分项是否异常（例如五行分很高但黄道 -10）。
4. 双击一行打开日课详情。
5. 需要复核时点「日课评分」把该课带入评分系统。

**读表三条经验**

- 总分高 ≠ 能用：先看等级是否「❌ 凶」、忌项是否有硬门槛。
- 分项为 0 不一定是漏算：可能是当天未触发（如喜用神需事主八字才计）。
- 三煞扣分不否决：月/日三煞柱级是扣分，年三煞犯山向才否决。

## 6. 精准择时（反推）

> 配图 6-1：精准择时窗口（条件区 + 榜单 + 动作时序）

1. 点「精准择时」打开反推面板。
2. 设条件：事项、时间窗、事主、山向/方向（按事项出现）。
3. 生成榜单（Top-N），每行含：日期、评分、等级、推荐时柱、**满分核验**、**慎用**标记、入选理由。
4. 展开「动作时序」：如嫁娶的发轿/进门时刻编排。
5. 点「带入红帖」把选中日带入择日贴。

**三个概念**

- **慎用日**：有微瑕但仍在榜，红帖会加黄底警示。
- **全否**：窗口内无可用户外日，榜单为空或全为凶。
- **推荐时柱**：系统择定的最优时辰，可在详情里用十二时辰表复核。

嫁娶民俗时段为**软加权**（不硬排除）：发轿优先辰/巳时（8–11 点），进门优先未/申时（13–16 点），命中者排序加分。

**满分核验（专科专家体检单）**

满分核验是「通用底线 + 事项专属核心 + 相主」的三重考核。不同事项的体检单不同——修造看扶山补龙，嫁娶看利月吉日，安葬看仙命相合，各查各的专科项。

专属事项（修造/动土、嫁娶/订婚/纳采、入宅/移徙、安葬、出行）为 **6 项**：1–3 位通用，第 4 位按事项动态替换，**第 5 位固定为相主**，第 6 位硬忌：

| 位次 | 维度 | 判据 |
| --- | --- | --- |
| 1 | 得令（底线） | 日主在月令处于旺/相（月令旺衰得分 > 0） |
| 2 | 合局 | 四柱地支出现三合 / 六合 / 半合 / 拱合 |
| 3 | 德神 | 命中天德 / 月德 / 岁德 / 天赦等核心德神 |
| 4 | 事项专属核心 | 见下表，随事项切换 |
| 5 | 相主 | 事主年命/日支未受冲刑且获生合（**未填事主判 N/A，不计入 ✓**） |
| 6 | 硬忌（底线） | 无一票否决，且神煞负分合计未达慎用阈值（> -20） |

其他事项（开业、入学等）仍为通用 **5 项**：得令 · 合局 · 相主 · 德神 · 硬忌。

第 4 位「事项专属核心」对照表：

| 事项 | 专属核验 | 判定口径 |
| --- | --- | --- |
| 修造 / 动土 | 扶山补龙 | 扶山 / 补龙 / 山家三合任一有加分（> 0） |
| 嫁娶 / 订婚 / 纳采 | 利月与吉日 | 命中大利月 / 小利月 / 周堂吉日 / 不将日其一 |
| 入宅 / 移徙 | 全家相合 | 所有事主相主得分均 ≥ 0 且无冲命 |
| 安葬 | 仙命相合 | 仙命与坐山无冲无克 |
| 出行 | 出发方向 | 出行方位得分 > 0 或未犯煞 |
| 其他事项（开业、入学等） | 相主 | 事主年命或日支获得生合加分（须先填事主），即原通用五维 |

- 鼠标悬停该列，弹出逐项说明；缺哪项、为什么缺，一眼可见（如「✗扶山补龙（未生扶坐山）」）。
- **相主是硬门槛，也计分**（001 §235/§236，2026-11-08）：嫁娶 / 订婚 / 纳采通道已对**男女双方**同时校验「日课日支冲事主年命（生肖）」与「日课日支 / 月支（提纲）冲事主日支（夫妻宫）」——任一方被冲即一票否决、总分归零。相主得分（生合加分、刑冲破害扣分）已并入嫁娶总分；年命伏吟 -15 分、事主日支伏吟 -15 分（均不否决）；时支冲夫妻宫只禁用该时辰，不否决整日。
- 反推面板顶部与分档页（大吉/优吉）的图例会随事项下拉框实时切换，显示当前事项的核验维度顺序（专属事项 6 项、其他事项 5 项）。
- 全部维度 ✓ 即「极品日课」，整行金底高亮；导出/打印榜单时同样带核验行。
- **没有全 ✓ 是正常的**：大部分日子里能占上 3 个 ✓ 已非常难得，4 个 ✓ 通常已是当期前列；全 ✓ 可遇不可求。
- **⚠️ 五行偏枯警示（001 §238）**：四柱八字中火系（丙丁巳午）或水系（壬癸子亥）占到 4 字及以上，详情页会弹出黄底红字警示：「本课五行极度偏枯（过燥/过寒），请结合山家与事主命理三思，切勿迷信高分。」该警示**在精准择时同样生效**——榜单双击的日课详情、详情文本（保存/打印）、红纸帖注意事项区都会显示；纯提示、不改分，但意味着即便分数很高也不宜直接采用。
- **分档榜不会漏掉 6/6 全✓日**：优吉档固定 2–3✓，大吉档 4✓ 起、上限自动取当前事项的核验维度数（专属 6 / 其他 5）。
- **分档页「状态」列与页签标题一致**：显示本档分档名（大吉 / 优吉）；神煞重扣日在后面标「·慎用」（如「大吉·慎用」），黄底保留，扣分主因列同时写明「慎用：…」。顶层 Top-N 榜单的「状态」列仍是吉日 / 慎用。
- **排序依据可切换（001 §238.10，2026-11-09）**：反推面板顶部「排序:」默认「吉日优先（推荐）」——先把吉日层排完，慎用高分日一律置后（安全降权红线）。切到「纯总分排序」会弹二次确认（提示鲁班煞 / 土王用事 / 重丧等重煞日可能排在吉日之前）；确认后按总分排序，慎用日仍保留黄底并改用红字标出扣分合计（如「⚠ 合计 -55 分（鲁班煞、土王用事、太岁堆黄）」）。把这类日再排到前面只改变**展示顺序**，不改变评分、不收窄否决，详情页顶部会显示「💡 降权说明」写明被置后的原因。
- 核验只做展示（数据取自评分分项），不改变评分与排序。

## 9. 完整实战示例

**需求**：2025 年 10 月修造，坤山艮向兼未，用未时。

1. 事项「修造」→ 填区间 → 宅型阳宅 → 山向「坤山艮向」→ 兼向「兼左/兼右（未）」。
2. 开始择日，定位 2025-10-28（农历九月初八）。
3. 读结果：纯正五行评分 **288**，等级 **★★★★★ 上吉**（若启用「正五行+玄空飞星」加权，则综合 **218**）。
4. 双击详情，核对公式：

```text
五行评分 307 + 月令 10 + 喜用 0 + 黄道 -10 + 三煞 -19 = 288
三煞构成：年三煞(向方) -10、月三煞(向方) -6、日三煞(向方) -3
```

5. 看「核心吉神」列：天乙贵人、岁德、日贵人时、时与坐山三合…（悬停可见 11 项）。
6. 看修造段：扶山 +5、补龙 +8、山家六合 +12、山家贵人 +10；时辰吉凶里癸未时 +15 为推荐。
7. 生成红帖。

> 要点：这天总分 288 却仍为上吉，是因为山家吉神与时辰吉神把扣分拉了回来；**三煞是“方道扣分”而非整日否决**。

## 10. 常见问题（FAQ）

| 问题 | 答案 |
| --- | --- |
| 为什么吉神显示不全？ | 结果表只显示命局贵人 + ≥10 分高权重神煞，最多 4 个；悬停看完整列表，详情页看全量 |
| 为什么总分与五行评分不同？ | 五行评分是子分；总分 = 五行 + 月令 + 喜用 + 相主 + 黄道 + 太阳太阴 + 三煞 + 向方 + 出行/坐山等 |
| 为什么三煞扣了 60 分还不判凶？ | 月/日三煞柱级是扣分；只有年三煞犯山向等硬门槛才否决 |
| 为什么填了山向，出行分数没变？ | 出行不看坐山，只看出发方向；填坐山不参与计算 |
| 为什么有吉神仍判凶？ | 硬门槛优先（三煞山向、山家封禁、相主冲命、受死日等），吉神不能抵硬否决 |
| 为什么等级显示「❌ 凶」但还有分数？ | 否决会归零；个别封顶仍保留原分展示。以等级为准 |
| 为什么「日课校验」有「跳过」？ | 跳过表示该规则不适用于当前路径（如非嫁娶），不是失败 |
| 红帖为什么拒绝生成？ | 时辰冲关键事主命，属红线拒绝，换时辰即可 |
| 不填生日会怎样？ | 该事主不参与相主；结果仍出，但少了冲命校验 |
| 玄空飞星为什么不显示？ | 当前为纯正五行模式；切换到「正五行+玄空飞星」 |
