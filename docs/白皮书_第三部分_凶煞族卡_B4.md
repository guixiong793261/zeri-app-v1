## 4.0 否决与扣分的分界线

| 判定 | 结果 | 用户可见表现 |
| --- | --- | --- |
| **一票否决（HARD_VETO）** | 该日总分归零，从结果榜剔除；红帖拒绝生成或生成否决帖 | “不合格原因”列显示否决项；详情标红 |
| **重度扣分** | 扣 25～40 分，通常落为“凶”或“平” | 仍在榜内，详情列“凶煞”段 |
| **中度扣分** | 扣 10～20 分 | 仍在榜内 |
| **轻度扣分** | 扣 1～9 分 | 仍在榜内，作提示 |

> **铁律**：否决只能来自**代码显式否决点**（`_check_veto_items`、`_HARD_VETO_KEYWORDS`、`get_shansha_info`、`_check_owner_xiangshou_chong`、`_check_xianming_relations`），不能由“分数扣到 0 以下”自动产生。分数为负仍是“凶”，不是“否决”。

## 4.1 三煞族（年三煞 / 月三煞 / 日三煞 / 劫煞 / 灾煞 / 岁煞）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——仅限「年三煞 × 坐山/修方」。向方、月柱、日柱一律不否决。</span>

> **一句话**：三煞是择日第一凶煞，但“凶”的边界被严格限定在**空间层**；柱层与向层只扣分。

### 4.1.1 起例

| 三合局 | 三煞方位 | 所煞之山 |
| --- | --- | --- |
| 申子辰 | 巳、午、未 | 巳山、丙山、午山、丁山、未山 |
| 寅午戌 | 亥、子、丑 | 亥山、壬山、子山、癸山、丑山 |
| 亥卯未 | 申、酉、戌 | 申山、庚山、酉山、辛山、戌山 |
| 巳酉丑 | 寅、卯、辰 | 寅山、甲山、卯山、乙山、辰山 |

> 三煞**只用地支**，不含天干。三合局的对冲之方即三煞。

### 4.1.2 三层 × 三态矩阵（核心）

| 层 | 坐山/修方 | 向首 | 日柱/时柱临方 |
| --- | --- | --- | --- |
| **年三煞** | <span style="color:#c00000">**⛔ 一票否决**</span> | -25（不否决） | **不判**（§211 四柱级旁路） |
| **月三煞** | -20（不否决，§63） | -20（不否决） | 日柱 -20 / 时柱 -15（不否决） |
| **日三煞** | -15（不否决） | -15（不否决） | 时柱 -10（不否决） |

**叠犯加重**：月、日三煞同时犯时柱，另加 -15。

### 4.1.3 适用

修造、动土、拆舍、入宅、移徙、安葬等**有坐山**的事项。
**整体旁路**：出行、开业不信三煞（详见 B6）。

### 4.1.4 制化豁免

| 条件 | 结果 | 边界 |
| --- | --- | --- |
| 德神并（占方层） | 可减（止忌军事、疗病） | 仅“占方”可制 |
| 坐山层 | **不可制** | 坐山犯三煞，德神不能解 |
| 本命层（造葬天罡四煞） | **不制** | 与占方三煞同层不同源，并列 |

### 4.1.5 典据

- 《协纪辨方书》卷十一·用事卷（三煞用事条目）。
- 《协纪》卷三十六·辨讹（三煞名义辨正）。
- 《御定星历考原》互校。
- 三层框架见白皮书 §1.4；年三煞四柱旁路见 §211。

### 4.1.6 边界与坑

1. **年三煞只否决坐山/修方**：向首只扣 -25，不能误判为否决。
2. **年三煞不判月柱**：§211 已全面旁路，任何“月柱年三煞→否决”的旧逻辑都已删除并留墓碑。
3. **三煞 ≠ 劫煞/灾煞/岁煞**：后三者在神煞通道**仅展示、不计分**（score=0），不要重复扣。
4. **出行/开业无坐山**：三煞整体旁路，填报坐山不影响分数。

## 4.2 月破族（月破 / 月破日）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——嫁娶、安床、作灶、出行四通道；其余通道按 -30 扣分。</span>

> **一句话**：月破是“月建对冲”，月家第一凶；德神只能“止不忌”，不能全解。

### 4.2.1 起例与分值

| 项 | 内容 |
| --- | --- |
| 起例 | 日支 = 月建所冲之支（如寅月申日、卯月酉日） |
| 分值 | 通用 **-30**；修造/安葬类另有通道值 |
| 否决通道 | 嫁娶、安床、作灶、出行 |
| 不否决 | 修造类（只扣分）、入宅/移徙（月破旧否决已删） |

### 4.2.2 制化豁免

| 条件 | 结果 |
| --- | --- |
| 天德/月德/天德合/月德合并 | **犹忌**（仅“止不忌”15 项） |
| 德并 + 子午月灾煞 / 未申月月刑 | 不忌祭祀等，仍忌解除、疗病、破屋 |
| 天赦/天愿并 | **结构禁止**（不得并论） |

### 4.2.3 典据

《协纪》卷五·义例三「月破」；制化条款见卷五按语。

### 4.2.4 边界与坑

1. **月破 ≠ 建除“破日”**：破日 -15，月破 -30。
2. **德神不解月破**：报告不得写“有天德可解月破”。
3. 入宅/移徙的月破否决已在 2026-10-20 批删除，只保留扣分。

## 4.3 四离四绝族（四离日 / 四绝日）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——嫁娶、安葬、出行、安床、作灶。</span>

> **一句话**：节气交变前一日，天地气绝，诸事不宜。

### 4.3.1 起例

| 项 | 内容 |
| --- | --- |
| 四离 | 春分、秋分、夏至、冬至**前一日** |
| 四绝 | 立春、立夏、立秋、立冬**前一日** |
| 分值 | 通用 -30 |
| 否决 | 嫁娶、安葬、出行、安床、作灶 |

### 4.3.2 制化豁免

**不制**。德神不能解四离四绝。

### 4.3.3 典据

《协纪》卷五·义例三「四离」「四绝」；《考原》互校。

### 4.3.4 边界与坑

1. 四离四绝按**节气日**推，不按公历月日；交节时刻在当天晚间的，前一日仍算。
2. 四离四绝是“日级”否决，不是“时级”；不要只避时辰。

## 4.4 重丧族（日重丧 / 年重丧 / 三丧 / 复日）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——安葬通道的复日、三丧日。</span>

> **一句话**：重丧是“重复哭丧”之忌；软件按“墓库派”统一口径，安葬重扣/否决，嫁娶已解禁。

### 4.4.1 族内差异表

| 神煞 | 起例 | 分值 | 否决 | 适用 |
| --- | --- | --- | --- | --- |
| **日重丧** | 墓库派：按月建取重复之辰（详见 `神煞基类._is_zhongsang`） | -30 | 安葬（叠加规则） | 安葬 |
| **年重丧** | 年支查日干双干：寅/申→庚甲、卯/酉→乙辛、辰/戌/丑/未→戊己、巳/亥→丙壬、午/子→丁癸 | **-30** | **不否决** | 安葬 |
| **三丧日** | 春辰、夏未、秋戌、冬丑（季月辰戌丑未） | -30 | <span style="color:#c00000">**⛔ 安葬**</span> | 安葬 |
| **复日** | 协纪正法单干·节气月建：月支查日干（寅甲、卯乙、辰戊、巳丙、午丁、未己、申庚、酉辛、戌戊、亥壬、子癸、丑己） | -30 | <span style="color:#c00000">**⛔ 安葬**</span> | 安葬 |

> **重丧口径变更**：旧“重丧日”多派混用，现统一为**墓库派**；嫁娶通道已解禁（0 发射），安葬保留严判。

### 4.4.2 制化豁免

- 年重丧 -30 **不否决**，德神不另解。
- 日重丧与三丧、复日叠加时按安葬硬门槛处理。

### 4.4.3 典据

- 《协纪》卷五·义例三「重丧」。
- 《陈子性藏书》p54：「重丧凶事，吉事俱忌者非」——明确重丧主凶事，嫁娶不忌。原文见 B6。
- 安葬四大凶日升硬否决见白皮书 §4.2。

### 4.4.4 边界与坑

1. **嫁娶不再忌重丧**：这是 §212 的核心裁断之一，报告不得再写“重丧日嫁娶大凶”。
2. **年重丧只扣不否**：不要与日重丧、三丧混为一谈。
3. 重丧起例必须用墓库派唯一表，旧多派表已删。

## 4.5 受死日族（受死日）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——入宅通道；嫁娶亦列入整日否决清单。</span>

> **一句话**：受死日是“日辰无气”之凶日；入宅按硬否决，其他事项按 -15 扣分。

### 4.5.1 起例与分值

| 项 | 内容 |
| --- | --- |
| 起例 | 逐月六日（正月戌、二月辰……以典表为准，详见 `受死日.py`） |
| 分值 | 安葬/修造类 **-15**；嫁娶/入宅 **0**（改硬否决） |
| 否决 | <span style="color:#c00000">**⛔ 入宅**</span>；嫁娶整日否决清单内含“受死日”关键词 |

### 4.5.2 制化豁免

**不制**。受死日无制化条款。

### 4.5.3 典据

- 《陈子性藏书》“凶曜”条：无比较级，故轻重层由 -22 调至 **-15**（不夸大）。
- 《协纪》卷六相关条互校。
- 入宅升硬否决见 §190 C1；白皮书 §4.3。

### 4.5.4 边界与坑

1. **入宅与安葬不同级**：入宅是硬否决，安葬是 -15（安葬另有四大凶日硬门槛）。
2. 受死日分值从 -22 调至 -15，是“按典不夸大”，不是“放宽”。
3. 不要把“受死”与“受死日”以外的“死气日”混用。

## 4.6 红嘴朱雀族（红嘴朱雀）

<span style="color:#c00000">**⛔【一票否决 HARD_VETO】**——入宅/移徙；安床为“方位门控否决”。</span>

> **一句话**：红嘴朱雀是“朱雀临中宫”之凶，三库仅《陈书》有载；入宅从严，安床看床位方位。

### 4.6.1 起例与分值

| 项 | 内容 |
| --- | --- |
| 起例 | 逐月九宫起例，朱雀所值之宫；详见 `红嘴朱雀.py` |
| 分值 | 通用 **-30**（按典力度，拒绝 -12 弱化档） |
| 否决 | <span style="color:#c00000">**⛔ 入宅/移徙**</span>；安床“床位朝向临朱雀所值之宫（乾方）”即禁 |
| 仅扣分 | 嫁娶、作灶 -30 |

### 4.6.2 制化豁免

**不制**。红嘴朱雀无制化条款。

### 4.6.3 典据

- 《陈子性藏书》p96：「切不可犯紅嘴朱雀入中宮」。
- 《协纪》《考原》无载，属第三参照孤例；软件按“从严”保留并升否决。
- 判据冻结与取证见《判据冻结提案_入宅两项按典取证_20261028.md》。

### 4.6.4 边界与坑

1. **入宅与安床判定不同**：入宅看日，安床还要看床位朝向；同一日可能“入宅禁、安床不禁”。
2. **不是所有朱雀日都叫红嘴朱雀**：黄道“朱雀”是黑道凶神，与红嘴朱雀同名不同源。
3. 红嘴朱雀只 -30 不 -12，弱化档已拒。

## 4.7 月凶族（月厌 / 月刑 / 月害 / 月煞）

> **一句话**：月厌、月刑、月害、月煞是“月家四凶”，只扣分不否决（月破另有硬否决）。

### 4.7.1 族内差异表

| **月刑** | 月支刑日支：子刑卯、卯刑子、寅刑巳、巳刑申、申刑寅、丑刑戌、戌刑未、未刑丑、辰辰、午午、酉酉、亥亥 | **-20** | 条件性可解（见 B5） | 卷五·义例三（“所忌与三煞同”） |

### 4.7.2 制化豁免（月刑矩阵）

| 条件 | 结果 |
| --- | --- |

3. 月害 -12 是“害不甚凶”按典调档，不是随意淡化。

> **一句话**：六凶族主要影响“军事、疗病、词讼”类用事，现代择日多作扣分；厌对可被五德全解。

### 4.8.2 边界与坑

3. **四废属犹忌族**：不要误以为德神可解。
4. 八专 -12 是按“忌 5 项 < 大时 ~30 项”的倒挂修正。
