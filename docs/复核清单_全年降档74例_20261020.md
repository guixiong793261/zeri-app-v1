## 三、专项深核：2 例「上吉 → ❌ 凶」（受死日表A 收敛负面波及是否合理）

### 3.1 2026-09-30 动土 106→64（-42）

- **四柱实测**（hour=10）：**酉月 未日**。
- 受死日：表A 八月→**未日** ✅命中；表B 秋→辰日 ❌不命中 → **表A 收敛新命中**（陈书 p152 逐月表，本日确为受死日）。
- 土符：正表 酉月→**未日** ✅命中 → 同为**正表新命中**（旧错表本日不命中，属错表清退后的正确回补）。
- 致因：受死日 -22 + 土符 -20 = -42，无对冲项，与 Δ 全等。

### 3.2 2026-10-31 修造 116→76（-40）

- **四柱实测**（hour=10）：**戌月 寅日**。
- 受死日：表A 九月→**寅日** ✅命中；表B 秋→辰日 ❌不命中 → **表A 收敛新命中**。
- 土符：正表 戌月→亥日，本日寅日 ❌不命中（排除土符因素）。
- 土王用事 -18：修造通道扩项（先行批次拍板，非本回扫范围的新增误判）。
- 致因：受死日 -22 + 土王用事 -18 = -40，无对冲项，与 Δ 全等。

### 3.3 典据本意核对（结论：合理，属纠偏后正确判定）

1. **受死日在动土/修造两通道为有载保留项**（§138.2 逐通道典据确认表）：陈书 p152 主条「受死 上官起造嫁娶等凶宜安塟」——「起造」即动土/修造语境，另有 p580/p122/p578/p585/p622 多处互证；两通道不在删除候选之列。
2. **表A 为唯一正表**（§144.2）：陈书 p152 逐月表 12/12 全等 + 页内 10 处月表互证；旧表B「春戌夏丑秋辰冬未」系天喜/四击/死别口诀误植，已废弃。两例日支（未日/寅日）均严格落在表A 对应月份上，扣分是**典据本意的正确命中**，非收敛误伤。
3. **土符正表命中**（09-30）：酉月未日在正表之内，属错表修正后的正确回补。
4. **风险面可控**：全年 5475 格中「上吉→凶」仅 2 例（0.037%），且均可逐条归因到有典据的保留项，无"来源不明"降档。

**复核结论：2 例降档归因属于典据本意，判定合理，予以维持。**
