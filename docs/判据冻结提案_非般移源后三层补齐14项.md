## 一、总则（机制与通用判据，取证前冻结）

### 1.1 三库互校层级（沿用既有口径）
- 主锚：《协纪辨方书》（官方主锚）；
- 互校：《御定星历考原》；
- 第三参照：《陈子性藏书》；
- 三库分歧**仅标注不自行取舍**；主锚无载而第三参照有载者，规则标注
  「依据系第三参照，协纪考原歧异留档不取」（入宅同源复核先例）。

### 1.2 五档四分法（逐项对勘结论档位）
- ✅ 全等：典载与软件注册（事项×煞×触发×力度）一致；
- ⚠️ 语义等价：表述异而义同（正名候选，附语境判定）；
- ⚠️ 部分匹配：典载范围与注册范围交而不全（评估影响面后定）；
- ❌ 不符：典载与注册相违（按典修候选）；
- — 无载：三库均无对应明文（**不放宽**：无证据不注册/不扩面；
  已注册者列删除候选，按「标注隔离→快照→删除」三步走）。

### 1.3 五层过/不过通用定义（对齐五层总表 §1）
| 层 | 过（✅） | 不过 |
|----|---------|------|
| 表源 | 起例表与主锚一致（考原互校、陈书参照），且全项目唯一正表 | 起例与主锚不符→按典修；多表不一致→先收敛 |
| 触发 | 12 月建×12 日支全遍历（或锚点穷举）与典载起例逐日一致 | 错漏逐日清单入对勘稿 |
| 口径（白名单） | 所忌事项逐条有「入宅/归火条目逐字明文」（同 x4 判据）；白名单内注册 | 白名单外注册标「待证」；零明文者列删除候选 |
| 轻重 | 扣分/否决力度有典据分层（忌/大忌/不宜/否决） | 无典据者登记「—无」，不擅自调分 |
| 制化 | 制化神煞成立与适用有明载 | 无明载不自动延伸，登记「—无」 |

### 1.4 产出格式（对齐 B-b 四轨五段）
每项取证成稿须含：①典载原文（含卷页）②语境判定 ③软件现状
④五档判定 ⑤影响面；附**穷尽性证明**（检索过但无记载的典籍/卷次
清单），确保无遗漏。

### 1.5 闭环纪律（每批）
取证成稿 → 停下待拍板 → 拍板后改码 → 回归（verify 0/1）→ 部署同步
三层 SHA → 单独 commit。**不跨批混提**；取证、改码、记账各单独
commit；改码禁顺手改分值（分值调整须独立拍板）。

### 1.6 冻结纪律（v1.0 拍板三项，2026-10-19）

1. **不得临时扩项/改判据**：取证中发现新问题，只入「待议清单」
   （§1.7），不直接影响本批判据；确需修改判据，须**单独提案、单独
   拍板**，不与本批取证混提。
2. **版本号与变更记录**：本判据自 2026-10-19 冻结为 **v1.0**；任何后续
   变更须「版本号＋变更记录＋变更理由」三者齐备，登记 §六，旧版
   留档不覆盖。
3. **取证成稿后停止待拍**：每批取证成稿即停，**不自动进入改码**；
   改码须另行拍板（本件不构成第一批取证授权）。

### 1.7 待议清单（冻结后新问题的唯一入口）

- 取证中发现判据未覆盖的新问题（口径/归属/力度等），一律登记
  「待议清单」并注明所属批次与发现日期，**本批不裁断、不改判据**；
- 待议项达到需决断程度时，另起提案单独拍板，拍板后按 §1.6-2 记版本。

### 第一批（主力 4）

**1. 十恶大败**（-30，60 天/-1800；活链＝基类日块 神煞基类.py:1711 通用发射）
- 主锚：协纪——起例（十干大败日）见日家凶煞族；宜忌卷看用事范围；
  辨讹卷看馆臣判定（十恶大败在辨讹卷有专条，须逐字取原文）。
- 取证范围：协纪日家煞起例卷＋宜忌卷＋辨讹卷；考原日家对应条；
  陈书神煞例/月凶方族对应页。穷尽性清单随稿附。
- 五层要点：表源（十日柱起例是否=典载）；触发（60 天/年是否与起例
  一致）；口径（「入宅大忌」有无逐字明文——注意活链为通用发射，
  入宅系经通用链占位，白名单须单独立）；轻重（-30 层级典据）；
  制化（有无明载制化神）。

**2. 受死日**（-22，59 天/-1298；活链＝子类月块 入宅神煞.py:109）
- 主锚：协纪月家煞「受死」起例（月建×日支）；宜忌卷用事范围。
- 取证范围：协纪月家起例卷＋宜忌卷；考原月家对应；陈书月凶方/
  神煞例族。基类日块 :1717 同名行（对其余事项活链）的谓词
  _is_shousi_day 与子类 _is_shousi 是否同源同表——表源层须先判
  两谓词是否同一正表（多实现口径收敛，同 zeri-shensha-audit）。
- 五层要点：起例一致（59 天/年）；「受死日不宜入宅」逐字明文；
  -22 层级；制化明载。
- **拍板附判定标准（2026-10-19，纳入第一批表源层）**：
  ①先判「同源同表」——两谓词推排表是否完全一致：一致则归并为单一
  谓词或明确主从；不一致则按表源层裁断哪表为正，另一表列入「异表
  裁断」；
  ②**不得只改谓词名不改发射链**——两谓词若都挂发射链，须同步清理
  死链/重复发射，带「多链同拦」回归；
  ③与 7 条同名重加死链同族，处理沿用 §120.3/§123.4/§127 拦截模式。

**3. 岁破**（-30，31 天/-930；活链＝子类年块 入宅神煞.py:58 唯一链）
- 主锚：协纪卷首岁神族「岁破」条（岁破大耗同宫）；宜忌卷经典明文
  「岁破日忌兴造」族——入宅是否被「兴造/移徙」口径涵盖须语境判定
  （不得自动延伸）。
- 取证范围：协纪岁神起例卷＋宜忌卷＋辨讹；考原岁破条；陈书岁神族。
- 五层要点：起例（岁破=日支冲太岁，31 天/年）；「岁破日诸事不宜，
  入宅大忌」描述与典载用事范围对勘；-30 层级；制化。

**4. 红嘴朱雀**（-30，30 天/-900；活链＝子类月块 入宅神煞.py:98 唯一链）
- 主锚：协纪——红嘴朱雀日起例（月家朱雀族）；重点判「入宅大忌」
  有无主锚明文（红嘴朱雀×入宅在民间口径重，须防「民间口径当典据」，
  同三煞正名研究教训）。
- 取证范围：协纪朱雀/月家煞起例卷＋宜忌卷＋辨讹；考原朱雀条；
  陈书神煞例朱雀族。
- 五层要点：起例一致（30 天/年）；口径逐字明文；-30 层级；制化。

### 通用链占位形态·白名单单独立法（2026-10-19 拍板通过，附边界）

**涉及项**：十恶大败（基类日块 :1711）、丧门/五鬼/官符/吊客/病符
（基类年块 :1489/:1478/:1485/:1491/:1493）——入宅经**通用链占位**发射
（≠入宅专属注册），与专属链的发射/分值逻辑不同。

- **边界①「占位形态」须先定义清楚**：本批定为**三分类必判**——
  (a) 仅展示不计分；(b) 条件触发占位；(c) 待激活键。定义不清则白名单
  无法建；各项须在取证稿中先归入其一。
- **边界②与专属链白名单分开建、共用五档**：通用链白名单独立成表，
  但「有载/无载/语义等价/部分匹配/不忌」五档标准与专属链一致
  （§1.2 同口径）。
- **边界③不得因「占位」跳过轻重/制化**：占位形态若最终激活，仍须过
  轻重层与制化层；白名单阶段只解决「所忌事项范围」，不解决「扣多少」。
- **对照样本**：病符已验表源/触发（A5），可作通用链白名单的对照样本，
  但**不因已验跳过白名单**（同 §二 病符条）。
