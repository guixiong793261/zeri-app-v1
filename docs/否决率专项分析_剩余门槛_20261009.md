### 1.2 五行兜底拆解（最大桶的真实构成）

`五行严重不合格，犯大忌，坚决不用（…）`（[评分器.py](file:///d:/自编择日软件/专业级正五行择日软件/modules/评分器.py) L1546-1588）有**两支完全不同的触发路径**：

| 子桶 | 天数 | 文案特征 | 真实根因 | 事项分布 |
|---|---|---|---|---|
| **① 纯低分兜底** | **11,448** | `五行总分X分（0~29，最低-110），未达60分合格门槛；忌项均为临方扣分不否决项或已有吉神制化项，不单独构成大忌` | **§63 降级回弹**：三煞占月/月破犯坐山等已降级为扣分，扣分累积把总分压穿 30 分线，换文案继续否决 | 山向类为主：动土 1,883 / 拆舍 1,856 / 修造 1,684 / 装修 1,684 / 入宅 1,188 / 安葬 1,160 / 安床 1,076 |
| **② 硬煞列举** | **12,429** | `大忌：年三煞(日柱)/月三煞(时柱)/岁破…`（内含年三煞 9,316 / 月三煞 5,650 / 岁破 2,079 / 其他 990，多词文案多重计数故合计>12,429） | **事主中心类四柱临三煞方**（`sansha_pillar_veto=True`，L1553-1559）经五行评语通道否决 | 事主类为主：开业 1,737 / 求医 1,600 / 签约 1,574 / 入学 1,565 / 安床 1,059 / 订婚 1,010 / 纳采 1,010 / 安葬 1,008 |

> **要点**：子桶①的文案自证"忌项均为临方扣分不否决项或已有吉神制化项，不单独构成大忌"——否决依据只剩"分数<30"。这是 §63 释放效果的**技术性回收**：否决改扣分后，分数被压穿兜底线。子桶②则是 §62/§63 口径不对称的产物：山向类四柱临方已改"只扣分"（`_spv=False`），事主中心类仍否决（`_spv=True`）。

### 1.3 相主硬门槛（叠加型）

`veto_reasons=[忌事]+相主硬门槛`（L1729）。六冲 8,052 / 自刑 7,260，solo 仅 3,306——绝大多数日子同时叠加五行兜底/三煞/规则通道。**它更多是"压死骆驼的最后一根稻草"，单独处理收益有限**。

### 1.4 校准与残差说明（数据可信度）

- **管线同构验证**：2024 订婚/纳采/修造/作灶/出行 pop1 与 §63 基线（veto_audit_new.json）**逐日精确对齐**（diff=0）。
- **残差结构**：全量 256 组比对 mismatch=221，残差 **min=1 / max=6 / avg=3.1 天/组**（<2%），双向翻转（baseonly≈mineonly），集中在 60 分合格线边缘。根因：§63 基线跑批脚本已散佚（全盘无存），owner dict 精确结构（角色/生肖键/时辰/§62 半权重交互）不可考；本审计以脚本内 SEED（全员 role=事主，实训残差最小配置）为权威口径。
- **影响评估**：残差 <2%/组，远小于门槛结构占比差异（最大桶 32.2% vs 最小 1.0%），不影响本报告任何结论。

## 四、推荐组合与预估

**低风险推荐组合：D2（作灶次级神煞降级）+ E1/C1/F1 维持其余。**
- 释放：约 3,500 单元（作灶事项 ~4-5pp），全局否决率 79.2% → ~78%
- 风险：低；回归范围仅作灶全年

**若用户接受口径对称化，追加 B3（四柱临三煞按柱分级）：**
- 释放：日/时柱临方部分，预估 8,000-12,000 单元（全局 -10~-13pp，否决率降至 ~65%）
- 风险：中低；回归范围全部事主中心事项（嫁娶/订婚/纳采/开业/出行/签约/入学/求医/安床/作灶/安葬）

**若用户进一步拍板"无硬煞不否决"，追加 A2：**
- 释放：预估 6,000-11,000 单元（山向类纯低分大头），全局再 -6~-12pp
- 风险：中高（正五行合格线根基）；建议单独作为一轮改码+回归，不与 B3 同轮

**三步走预估**：D2 → ~78%；+B3 → ~65%；+A2 → ~55-60%。均执行后全局否决率量级回到用户 §64 指令中"专项报告粗估 50-70%"区间。
