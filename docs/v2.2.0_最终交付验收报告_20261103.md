## 1. 交付范围（功能全景）

### 1.1 评分引擎

- 四柱计算：高精度农历转换 + 真太阳时 + 节气月柱（交节日按节气时刻翻转，非公历月号）。
- 评分核心：通道甲（神煞/月建）+ 通道乙（建除/宜忌），双族去重门控，输出分数 / 等级 / 吉神 / 忌项 / 否决原因 / 分项明细，全程可追溯。
- 一票否决体系：月破、受死日、四大凶日、四离四绝、岁破、仙命六冲等硬门槛；伪神煞已全部剥离。

### 1.2 典据治理（本次重构最大资产）

- 三库主锚：以《协纪辨方书》为主锚，《星历考原》互校，《陈子性藏书》第三参照；分歧只标注不擅取舍。
- 神煞五层验证：表源层 → 触发层 → 口径层 → 轻重层 → 制化层，逐层取证、逐层留痕。
- 五大场景深水区（修造 / 安葬 / 入宅 / 嫁娶 / 出行）全部完成裁断与修复。

### 1.3 精准择时反推（§210 / §211）

- 输入事项、日期范围、山向、事主，自动扫描并输出 Top-N 最优日。
- 三层视图：热力日历（一眼看全月吉凶）、Top-N 列表（得分/吉神契合/最优时辰）、最优时间轴。
- 零候选不伪造：无可用日时明确提示「请扩大日期范围或调整山向」，绝不拿低分日凑榜。

### 1.4 动作时序编排（§213）

- 嫁娶三段序列：起轿·发轿 → 迎娶·进门 → 交拜·合卺，逐段择吉时。
- 四态状态：`full`（三段齐全）/ `partial`（有缺段）/ `insufficient`（仅 1 段）/ `none`。
- 民俗时间偏好：发轿优先 8–11 点、进门优先 13–16 点（软加权排序，不硬排除）。

### 1.5 红纸帖三态交付（§205 / §214）

| 帖型 | 用途 | 视觉识别 |
| --- | --- | --- |
| 吉帖 | 正常可用日 | 红底 + 吉语 + 吉日信息表 |
| 慎用帖 | 有软忌但仍可用 | 深红底 + 「本日多煞 建议慎用」 |
| 否决帖 | 一票否决日 | 深红底 + 明黄「不可使用」牌 + 原因清单 |

**安全红线**：任何来源的时辰（自动排程或手动修改）只要命中禁用清单（日破时/冲新娘/冲新郎/冲阴胎/冲阳气）一律**拒绝生成**，不存在越权后门。
